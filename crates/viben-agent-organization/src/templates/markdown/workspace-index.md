## Session Template

When recording a session, include:

```markdown
## Session N: Title

**Date**: YYYY-MM-DD HH:MM
**Commits**: `hash1`, `hash2`

### Summary

Brief description of work done.

### Files Changed

- `path/to/file.ts` - Description

### Status

[OK] **Completed** / [WIP] **In Progress**
```

## Notes

- Max 2000 lines per journal file
- New journal created automatically when limit reached
