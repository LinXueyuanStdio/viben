# Getting Started

Welcome to Viben! Viben lets you chat with AI coding agents — like Claude Code, Gemini CLI, or Copilot — directly from Telegram, Discord, or Slack. No browser tab switching, no terminal babysitting.

- **[What is Viben?](what-is-viben.md)** — New here? Start with the big picture.
- **[Quick Start](quick-start.md)** — Install Viben, set it up, and chat with an AI agent in ~10 minutes.
- **[For Contributors](for-contributors.md)** — You want to hack on Viben, add a feature, or fix a bug.
