# Vibe Trading 核心用户故事

## 架构前提

```
┌─────────────────────────────────────────┐
│       外部侧边栏（Agent + 对话）          │
└──────────────┬──────────────────────────┘
               │ 工具调用
               ▼
┌─────────────────────────────────────────┐
│  Trading App（单页面，无跳转）            │
│                                         │
│  ┌─ TopNav ──────────────────────────┐  │
│  ├─ PlayerBar（回放模式时出现）────────┤  │
│  ├─ StatCards（6 张指标卡片）─────────┤  │
│  ├─ ChartArea ───────────────────────┤  │
│  │   tabs: 行情图表 | 净值曲线         │  │
│  │   K线嵌入 TradingView              │  │
│  ├─ DataPanel（可拖拽高度 / 折叠）────┤  │
│  │   tabs: 持仓 | 历史 | 订单         │  │
│  └───────────────────────────────────┘  │
│                           ┌───────────┐ │
│                           │ SidePanel │ │
│                           │ tabs:     │ │
│                           │  决策日志  │ │
│                           │  Agent    │ │
│                           └───────────┘ │
└─────────────────────────────────────────┘
```

- **单页应用，不会有页面跳转**
- 所有交互通过：切换 tab、展开/折叠 panel、弹出 dialog/overlay、数据刷新
- Agent 在外部侧边栏，通过工具调用操控 app 内的面板状态

## 目标用户

**懒研究员**：可能不懂交易，也可能懂但懒得操作。会一直盯着 app 看 Agent 干活，在外部侧边栏跟 Agent 交流，认知不断变化，随时冒出想法。

---

## App 布局区域定义

| 区域 | 组件 | Agent 可操控的内容 |
|------|------|-------------------|
| A. 顶栏 | TopNav | session 状态、控制按钮状态 |
| B. 回放条 | PlayerBar | 进度、倍速、播放/暂停 |
| C. 指标卡片 | StatCards | 数值刷新（带动画） |
| D. 图表区 | ChartArea | tab 切换、币种切换、时间周期 |
| E. 数据面板 | DataPanel | tab 切换、展开/折叠、行高亮 |
| F. 侧面板 | SidePanel | tab 切换、决策日志追加、Agent 状态 |
| G. 弹窗层 | Dialog/Overlay | 下单确认、策略设置、账户管理 |

---

## 核心故事 1：给个目标就启动

> 用户在外部侧边栏说"帮我投 5000U"，Agent 在 app 内操控：弹出配置面板、填入参数、启动策略。用户全程看着同一个页面上的变化。

**App 内发生的（无跳转）：**

1. 策略设置弹窗(G)滑出 → 字段逐个被填入
2. StatCards(C) 初始化：本金数字滚入
3. ChartArea(D) 加载对应币种 K 线
4. TopNav(A) 状态灯亮绿
5. SidePanel(F) 决策 tab 出现第一条"session 启动"

**工具调用 → UI 变化：**

| 工具调用 | App 区域 | 视觉效果 |
|---|---|---|
| `open_strategy_dialog()` | G | 策略弹窗从右侧滑入 |
| `set_param("symbols", ["BTC","ETH"])` | G.字段 | 字段蓝框 → 值打入 → 蓝框消退 |
| `set_param("amount", 5000)` | G.字段 | 数字滚动填入 |
| `set_param("risk", "moderate")` | G.字段 | 选项高亮选中 |
| `confirm_start()` | G → A,C,D | 弹窗关闭，整体初始化 |

**关键约束：**
- 配置弹窗里 Agent 填完后**不自动提交**——等用户确认或 Agent 请求确认
- 用户可以在弹窗里修改任何 Agent 填的值
- 弹窗打开期间，背后的主页面不可交互（标准 modal 行为）

## 核心故事 2：看着 Agent 实时操盘

> 策略运行中，用户看着同一个页面——图表自动切币种、指标面板展开、数据表高亮新成交。所有变化都在一个固定布局里发生。

**Agent 一轮操作的典型序列（全在主页面内）：**

```
D.tab切到行情 → D.切币种 → D.图表刷新
     → F.决策tab追加思考条目
          → E.展开（如果折叠了）→ E.tab切到持仓 → E.某行高亮
               → G.下单弹窗滑出 → 字段填入 → 成交
                    → C.指标卡数值跳动 → E.持仓表更新 → F.追加决策条目
```

**工具调用 → UI 变化映射：**

| 工具调用 | 目标区域 | 视觉效果 |
|---|---|---|
| `switch_chart_tab("kline")` | D | tab 切换动画 |
| `switch_symbol("ETH")` | D | 币种下拉切换，K 线重新加载 |
| `switch_chart_tab("nav")` | D | 切到净值曲线 tab |
| `expand_data_panel()` | E | 面板从折叠态展开（拉高动画） |
| `switch_data_tab("positions")` | E | tab 切换 |
| `switch_data_tab("history")` | E | tab 切换 |
| `highlight_row("position", "BTC")` | E | BTC 行短暂蓝色底色(2s) |
| `open_order_dialog(params)` | G | 下单弹窗滑出，字段已填 |
| `append_decision(entry)` | F | 决策 tab 顶部插入新条目（滑入动画） |
| `update_metrics(data)` | C | 对应卡片数值跳动更新 |
| `flash_stat("pnl")` | C | 某张卡片短暂辉光 |

### 活动指示（始终可见）

TopNav(A) 右侧或底部，一行文字显示 Agent 当前状态：

```
运行中状态：  🤖 正在分析 ETH 行情...          下轮 4m22s
观望状态：    🤖 观望中                        下轮 2m10s
执行中状态：  🤖 正在下单 BTC 买入...
```

### 思考过程展示

Agent 的推理不在图表上浮窗，而是体现在 **SidePanel(F) 的决策日志**里：

```
┌─ 决策日志 ─────────────────────────────┐
│                                         │
│  🔵 #24 · 刚刚 · 分析中                 │ ← 实时追加，打字机效果
│  │ 查看 ETH 15m K线                     │
│  │ RSI=78 超买，MACD 死叉               │
│  │ → 决定减仓 30%                       │
│  │ 📄 卖出 0.3 ETH @ 市价              │
│  │ ✓ 成交 @ 3,842                      │
│                                         │
│  ⚪ #23 · 5分钟前 · 观望                 │
│  │ BTC 1h 横盘，无信号，不操作           │
│                                         │
│  🟢 #22 · 10分钟前 · 买入               │
│  │ BTC 回调到支撑位                      │
│  │ → 加仓 10%                           │
│  │ 📄 买入 0.01 BTC @ 61,200           │
│  │ ✓ 成交                              │
└─────────────────────────────────────────┘
```

### 视觉区分

| 视觉元素 | 含义 |
|----------|------|
| 蓝色边框(2s) | Agent 正在操作此元素 |
| 淡蓝底色闪烁 | Agent 刚更新的数据行 |
| Tab 自动切换 | Agent 切换了关注区域 |
| 弹窗滑入 | Agent 发起了需要确认的操作 |
| 数值跳动 | 数据被 Agent 操作更新 |

### 用户"在场"交互

用户虽然主要在看，但可以：
- **点击决策日志里的任何条目** → 图表跳转到那个时间点的 K 线
- **hover StatCard** → tooltip 显示最近一次变化原因
- **点击持仓表的某行** → SidePanel 自动切到该币种最近的决策
- **折叠 DataPanel** → Agent 需要时会自动展开（带动画提示）

## 核心故事 3：用户纠偏（侧边栏对话 → App 变化）

> 用户在外部侧边栏说了想法，Agent 响应后操控 app 做出改变。用户在 app 上看到对应的面板/数据变化。

**用户输入 → App 内可见变化：**

| 用户说的（侧边栏） | Agent 工具调用 | App 区域变化 |
|---|---|---|
| "我觉得要跌了" | `adjust_risk("conservative")` | C: 持仓卡片数值变化 |
| "保守一点" | `open_strategy_dialog()` + 修改参数 | G: 策略弹窗打开，参数被调整 |
| "平掉一半 BTC" | `open_order_dialog({sell,BTC,50%})` | G: 下单弹窗滑出，字段已填 |
| "先停一停" | `pause_session()` | A: 状态灯变黄，活动指示变为"已暂停" |
| "继续" | `resume_session()` | A: 状态灯变绿 |
| "切到看 ETH" | `switch_symbol("ETH")` | D: 图表切换到 ETH |
| "看看净值曲线" | `switch_chart_tab("nav")` | D: 切到净值 tab |
| "看看历史成交" | `switch_data_tab("history")` | E: DataPanel 切到历史 tab |
| "晚上别操作" | `add_rule(...)` + `append_decision(...)` | F: 决策日志追加规则变更条目 |
| "追加 1000U" | `add_funds(1000)` | C: 余额卡片数值跳动 |

**涉及资金的操作流程：**

```
用户在侧边栏说"平掉一半 BTC"
  → Agent 调用 open_order_dialog({side:"sell", symbol:"BTC", quantity:"50%"})
  → App: 下单弹窗(G)滑出，字段已填好
  → 弹窗底部按钮："确认卖出" / "取消"
  → 用户在 App 内点击确认（或在侧边栏说"确认"）
  → 成交 → 弹窗关闭 → E持仓更新 → C指标跳动 → F日志追加
```

**关键约束：**
- 涉及资金操作**弹出 dialog 等用户确认**
- 不涉及资金的操作（切 tab、切币种、展开面板）直接执行
- 用户正在操作某个面板时，Agent 不操控该面板（等用户完成）

## 核心故事 4：复盘（含回放）

> 用户想回看 Agent 的历史操作。切到回放模式后，PlayerBar 出现，拖动进度条，整个 app 的所有面板恢复到历史某一刻的状态并可播放。

**触发：** 用户在侧边栏说"看看昨天的操作" 或 在 TopNav 点"回放"按钮。

**App 进入回放模式时的变化：**

```
正常模式                          回放模式
┌─ TopNav ───────────────┐      ┌─ TopNav (标注"回放中") ──┐
│                        │      ├─ PlayerBar ◀ ▶ ▶▶ 1x2x4x┤  ← 出现
├─ StatCards ────────────┤      ├─ StatCards (历史快照) ────┤
├─ ChartArea ────────────┤      ├─ ChartArea (历史K线) ────┤
├─ DataPanel ────────────┤      ├─ DataPanel (历史持仓) ───┤
└────────────────────────┘      └──────────────────────────┘
```

### PlayerBar 控制（已实现）

```
┌──────────────────────────────────────────────────────────────┐
│  ◀  ▶/⏸  ▶  │  ═══════════●═══════════  │ 15/42 │ Cycle 8 │ 1x 2x 4x 8x │ 🟢实时 │
└──────────────────────────────────────────────────────────────┘
```

- **逐步 ◀▶** — 前进/后退一个事件
- **播放 ▶/⏸** — 自动播放，按倍速推进
- **进度条** — 拖动到任意事件位置
- **倍速 1x/2x/4x/8x** — 回放速度
- **实时按钮** — 切回实时模式

### 回放时各区域的行为

| 区域 | 回放行为 |
|------|----------|
| C. StatCards | 恢复到该时间点的指标值 |
| D. ChartArea | 恢复到该时间点 Agent 正在看的币种/周期 |
| E. DataPanel | 恢复到该时间点的持仓/订单 |
| F. SidePanel | 决策日志滚动到对应条目并高亮 |
| G. Dialog | 如果当时有下单，重放弹窗过程 |

### 回放时的视觉效果

播放中，每一步工具调用和实时模式一样映射到 UI：
- 图表切换有过渡动画
- 指标数值跳动更新
- 持仓行高亮变化
- 决策日志当前条目高亮

暂停时，整个 app 冻结为那个时刻的快照——用户可以自由浏览所有面板。

### 时间轴增强（决策日志 + 颜色标注）

SidePanel(F) 的决策日志在回放模式下增加颜色标注：

```
🔴 #28 · 6/13 14:22 · 止损卖出 (亏 ¥85)
🟢 #27 · 6/13 11:30 · 获利卖出 (+¥42)
🔵 #26 · 6/13 09:15 · 调仓买入
⚪ #25 · 6/13 08:01 · 观望
⚪ #24 · 6/13 07:00 · 观望
🔵 #23 · 6/12 22:30 · 调仓卖出
```

颜色：⚪ 观望 │ 🔵 调仓 │ 🟢 获利 │ 🔴 亏损

### 用户评论

回放暂停时，用户可以在侧边栏对当前决策评论：
- "这步不该买" → Agent 记录反馈，关联到该决策
- "做对了" → 正面反馈，Agent 强化该模式
- 评论在决策日志条目下方显示为用户标注

## 工具调用设计

### 分类

Agent 操控 app 的工具按**目标区域**组织，而非按"功能类型"：

```typescript
// ── 面板控制 ──
switch_chart_tab(tab: "kline" | "nav")
switch_symbol(symbol: string)
switch_data_tab(tab: "positions" | "history" | "orders")
expand_data_panel()
collapse_data_panel()
switch_side_tab(tab: "decisions" | "agent")

// ── 弹窗触发 ──
open_order_dialog(params: OrderParams)
open_strategy_dialog()
open_account_dialog()
close_dialog()

// ── 数据更新 ──
update_metrics(partial: Partial<Metrics>)
update_positions(positions: Position[])
append_decision(entry: DecisionEntry)
append_trade(trade: TradeRecord)

// ── 视觉标注 ──
highlight_row(table: string, key: string)
flash_stat(card: string)
annotate_chart(type: "price_line" | "marker", params: any)

// ── 状态控制 ──
pause_session()
resume_session()
enter_replay(startIndex?: number)
exit_replay()
```

### 工具调用的 UI 表现规则

| 工具类别 | 动画时长 | 是否需要确认 | 被打断行为 |
|----------|----------|-------------|-----------|
| 面板控制 | 200ms | 否 | 立即停止 |
| 弹窗触发 | 300ms滑入 | 涉及资金的需要 | 不可被打断(modal) |
| 数据更新 | 数值跳动600ms | 否 | 不需要（瞬时） |
| 视觉标注 | 2s后自动消退 | 否 | 立即消退 |
| 状态控制 | 200ms过渡 | 否 | — |

### 用户优先级

- 用户正在操作的面板区域，Agent 不操控（排队等待）
- 用户点击/输入 > Agent 动画（动画立即完成，不阻塞）
- 弹窗打开时，Agent 不能打开另一个弹窗
- 用户关闭了 Agent 打开的弹窗 = 拒绝该操作

---

## 设计原则

1. **单页面，零跳转** — 所有变化在 tabs/panels/dialogs 内发生
2. **全自动，有节奏** — Agent 按周期自主操作，用户看着节奏感
3. **操作可见** — Agent 操控面板时有视觉标记（蓝框/闪烁）
4. **随时可打断** — 用户操作优先级始终高于 Agent
5. **两层信息** — 同一界面服务小白（看数字变化）和研究员（看完整面板数据）
6. **弹窗=确认点** — 涉及资金的操作一定通过弹窗让用户确认
7. **决策日志=历史** — SidePanel 的决策 tab 是理解 Agent 行为的核心入口
8. **回放=重放 UI** — 不是看日志文字，而是整个 app 重演当时的面板状态
