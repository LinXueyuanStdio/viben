# Vibe Trading 用户故事

核心体验：**用自然语言表达交易意图，AI 负责执行和汇报，用户保持最终决策权。** 像雇了一个 7x24 的交易员——你看着他操作你的界面，随时可以叫停。

核心差异化：**Agent 的每一步操作都实时映射到 UI 上。** 用户不是在看后台日志，而是看着 AI "亲手"操作页面——跳转、填表、点按钮、拖滑块——如同屏幕共享一个真人交易员的桌面。

---

## 1. 一句话开策略

> 用户输入"用 5000U 在 BTC 和 ETH 之间做网格，保守一点"，系统自动创建 session、配置参数、开始运行。不需要填表单。

**场景细节：**
- 用户打开页面，看到一个简洁的输入框，像聊天一样
- 输入意图后，AI 反问关键信息："要设止损吗？建议 -10% 自动平仓"
- 用户说"行"，策略立刻启动，页面切换到运行仪表盘
- 整个过程 < 30 秒，零表单、零下拉菜单

**UI 联动：**
- 用户说完，页面自动跳转到"创建 session"表单
- 表单字段逐个高亮填入：交易对 → BTC/USDT, ETH/USDT；资金 → 5000；风格 → 保守
- 每个字段填入时有轻微动画（typewriter 效果），让用户看到 AI 在"替你填"
- 最后"启动"按钮高亮闪烁，AI 问"确认启动吗？"，用户点击或说"确认"
- 页面平滑过渡到仪表盘

**边界情况：**
- 意图模糊时 AI 追问，表单保持半填写状态等待补充
- 资金超过账户余额时，金额字段标红，AI 提示并建议调整
- 用户可以随时说"等等，改成 3000U"，金额字段动画回退并更新

## 2. 盯盘焦虑转移

> 用户看到持仓浮亏，问侧边栏"现在要不要止损？"，AI 结合当前市场数据和策略逻辑给出建议，用户点"同意"即执行。

**场景细节：**
- 侧边栏是持续对话，不是一次性问答
- AI 的回复带数据支撑："当前浮亏 3.2%，距离你设的止损线还有 6.8%。RSI 超卖区间，历史上类似形态 72% 概率反弹。建议再观察 2 小时。"
- 用户可以追问："如果继续跌呢？"
- AI 给出条件计划："如果 2 小时内跌破 58000，我会平掉 50% 仓位锁定损失。"
- 用户说"好的"，这个条件就生效了

**UI 联动：**
- AI 回复时，主区域图表自动标注相关价位线（止损位、当前价、支撑位）
- 提到"RSI 超卖"时，图表下方 RSI 指标面板自动展开并高亮
- 用户同意条件计划后，止损线在图表上动态添加，带标注"条件单：<58000 平 50%"
- 新条件生效时，策略面板中对应规则高亮闪烁一下

**核心感受：** 不是冰冷的参数设置，而是跟一个懂行的人商量——他一边说一边在图上指给你看

---

## 3. 睡前托管

> 用户说"我去睡了，如果 BTC 跌破 60000 就全部平仓，否则继续持有"，agent 接管。

**场景细节：**
- 用户说"晚安"或"我去睡了"，AI 理解为托管意图
- 主动确认："好的，我帮你盯着。总结一下今晚的规则：① BTC < 60000 全平 ② 其他情况持有不动。对吗？"
- 第二天早上，用户看到晨报摘要：
  - "昨晚 BTC 最低触及 60,200，未触发平仓线。当前持仓 +1.2%。"
  - "执行了 0 笔交易，观察了 12 轮。"
  - "建议：早盘波动率上升，要不要收紧止损？"

**UI 联动：**
- 用户确认托管后，界面进入"夜间模式"：背景变暗，信息密度降低，只保留核心指标
- Agent 在夜间每一轮执行时，时间轴上静默记录小圆点（绿=观察，黄=接近阈值，红=触发）
- 早上用户回来，页面自动切回"日间模式"，顶部展开一张晨报卡片
- 晨报卡片可以点击展开，跳转到夜间任意时间点的快照

**核心感受：** 安心睡觉，醒来一切尽在掌握

---

## 4. 复盘回放（Agent 操作可视化）

> 用户点"回放"，看着 agent 像真人一样操作界面——切标签页、看 K 线、调参数、下单。

**场景细节：**
- 时间轴滑块，可以拖动到任意时间点
- 每一轮决策是一段"UI 操作录像"：
  1. **Agent 打开行情面板** — 图表自动切到当时的 K 线
  2. **Agent 查看指标** — RSI、MACD 面板依次展开，关键数值高亮
  3. **Agent 思考** — 侧边栏显示推理气泡："RSI 超买 + 资金费率转负 → 可能回调"
  4. **Agent 操作** — 下单面板打开，字段逐个填入（方向：卖出，数量：30%），最后"确认"按钮被点击
  5. **结果反馈** — 持仓面板更新，收益曲线标注这一笔

**交互细节：**
- 支持倍速播放：1x / 2x / 4x / 跳过无操作轮次
- 暂停时，用户可以看到当时的完整界面快照
- 用户看到某一步，可以直接评论："这里追涨不对"
- AI 回应："收到，我会在策略里加入'连续上涨 3 根 K 线后不追多'的规则。"
- 评论会标注在时间轴上，成为策略改进的锚点

**核心感受：** 不是看交易日志，而是"看着 AI 操盘"的录像带

---

## 5. 实时执行可视化

> 策略运行中，用户随时能看到 agent 当前在做什么——就像看着同事的屏幕。

**场景细节：**
- 页面底部有一个"Agent 活动条"（类似 PlayerBar），显示当前状态：
  - 空闲："等待下一轮 (3m22s)"
  - 执行中："正在分析 BTC 15min K 线..."
  - 下单中："正在提交限价买入 0.05 BTC @ 61,200..."

**UI 联动（实时工具调用 → UI 映射）：**

| Agent 工具调用 | UI 反映 |
|---|---|
| `fetch_kline(BTC, 15m)` | 图表自动切到 BTC 15m，加载动画 |
| `calculate_indicator(RSI)` | RSI 面板展开，数值刷新 |
| `analyze_market()` | 侧边栏显示思考气泡（打字机效果） |
| `place_order(buy, 0.05, 61200)` | 下单面板弹出，字段填入，进度条 |
| `check_balance()` | 账户余额数字闪烁刷新 |
| `update_stop_loss(59000)` | 图表上止损线平滑移动到新位置 |
| `switch_symbol(ETH)` | 图表切换到 ETH，带过渡动画 |

- 所有 UI 动作都有微妙的"AI 操控"标记（如元素周围的淡蓝色辉光）
- 用户可以随时点击任何被 AI 操作的元素，弹出"为什么？"tooltip
- 点击后 AI 解释："我切到 ETH 是因为 BTC 波动率降低，想看看 ETH 有没有机会"

**核心感受：** AI 不是黑箱，你在"看着它工作"

---

## 6. 多策略对比

> 用户同时开两个 session：一个激进、一个保守，并排看收益曲线。

**场景细节：**
- 用户说"再开一个激进版本，同样的币种，杠杆 3x"
- 两个 session 并排显示在仪表盘，收益曲线叠加对比
- 一周后，用户问"哪个表现好？"
- AI 总结："保守版 +4.2%，最大回撤 -2.1%。激进版 +8.7%，但最大回撤 -9.3%。风险调整后收益（Sharpe）保守版更优。"
- 用户说"关掉激进的，钱并到保守版"

**UI 联动：**
- 用户说"再开一个"时，界面分屏，右侧出现新 session 的创建面板
- AI 自动复制当前配置并修改参数，用户看到差异高亮
- 运行后，双收益曲线在同一图表上叠加，用颜色区分
- "关掉激进的"时，右侧面板执行平仓流程（可视化），资金数字动画滚动到左侧

## 7. 意外兜底

> Agent 遇到异常波动，自动暂停并推送通知。

**场景细节：**
- 触发条件不是简单的阈值，而是 AI 判断"这个波动不正常"
- 推送内容简洁有力："BTC 5分钟内跌了 8%，我已暂停交易。你的仓位安全。要我继续还是等你？"
- 如果用户不回应，agent 保持暂停状态，不会自作主张

**UI 联动：**
- 异常触发时，整个页面边框变为红色脉冲（持续 2 秒）
- PlayerBar 变为橙色警告态，显示"已暂停 - 异常波动"
- 图表上异常区域用红色底色标注
- 侧边栏自动弹出 AI 的情况说明，带三个操作按钮：
  - 「继续原策略」→ 恢复运行，图表恢复正常色
  - 「缩小仓位」→ 弹出仓位调整滑块，AI 推荐值预填
  - 「全部平仓」→ 确认对话框，显示预估平仓损益

**核心感受：** AI 永远是执行者，不是决策者。紧急时刻保护优先。

## 8. 渐进式信任建立

> 新用户第一次使用，系统从模拟盘开始，逐步建立信任。

**场景细节：**
- 首次使用不需要绑定交易所，先用模拟资金跑
- AI 说"我先用虚拟的 10000U 跑一周给你看看效果？"
- 一周后出报告："模拟收益 +3.1%，执行了 23 笔交易，胜率 61%。要用真钱试试吗？"
- 用户绑定交易所后，AI 建议"先用 10% 的资金跑实盘，其余继续模拟对照"

**UI 联动：**
- 模拟模式下，页面顶部有醒目的"模拟交易"横幅（非侵入式）
- Agent 操作界面时一切相同，但下单确认面板标注"模拟"
- 切换到实盘时，有一个"从模拟到实盘"的引导动画：横幅消失，界面微妙变化（如余额颜色从灰色变为绿色）
- 首次实盘下单时，额外弹出确认："这是你的第一笔实盘交易，确认使用真实资金？"

**核心感受：** 不催用户上真金白银，用结果说话

## 9. 策略进化

> 随着时间推移，AI 从用户的反馈中学习，策略越来越贴合用户风格。

**场景细节：**
- 用户多次在回撤 5% 时手动平仓 → AI 学到"这个用户对回撤容忍度低"
- 下次 AI 主动建议："我注意到你一般在 -5% 左右会平仓，要不要我自动在 -4% 止损？"
- 用户说"好的"，规则生效
- 策略有版本历史："v1: 初始配置 → v2: 加入追涨限制 → v3: 止损收紧到 4%"

**UI 联动：**
- AI 学到新规则时，策略面板中对应条目出现"NEW"标记并高亮
- 策略版本历史可视化为时间线，每个版本标注触发原因
- 用户说"退回到上周的策略"时，策略面板动画回滚，变更字段逐个恢复
- 规则冲突时（如"追涨"和"动量跟踪"矛盾），冲突字段标红，AI 在侧边栏解释并建议

**核心感受：** AI 不是一成不变的工具，它在理解你

---

## 10. 透明的成本感知

> 用户随时能看到 AI 运行的成本，心里有数。

**场景细节：**
- 页面角落显示："本月 AI 调用费用：$2.3 | 交易手续费：$12.5"
- 每笔交易标注 AI 推理消耗的 token 成本
- 用户可以设定预算上限："每月 AI 费用不超过 $10"
- 超出预算时，AI 降低调用频率或切换到更轻量的判断模式，而非直接停止

**UI 联动：**
- Agent 每次调用工具时，活动条右侧实时滚动 token 消耗（如"+120 tokens"）
- 预算接近上限时，成本指标从绿色渐变为黄色、红色
- 点击成本指标展开详细面板：按日/按策略/按工具类型拆分

## 11. 一键分享战绩

> 用户想炫耀收益，一键生成好看的分享卡片。

**场景细节：**
- 用户说"帮我生成一张本周战绩图"
- 系统生成精美卡片：收益曲线 + 核心指标 + 策略简述（脱敏）
- 不暴露具体资金量，只显示百分比收益
- 可选择分享到 Twitter / 保存为图片
- 支持"匿名模式"：隐藏策略细节，只展示结果

**UI 联动：**
- AI 调用截图工具，界面切换到"展示模式"（隐藏敏感信息，美化布局）
- 生成卡片预览在侧边栏中显示，可实时编辑文案
- 点击分享后显示各平台入口

## Agent 工具调用 ↔ UI 映射规范

这是整个产品的核心机制。Agent 不直接操作 DOM，而是通过**工具调用**表达意图，前端监听工具调用事件并映射为 UI 动作。

### 映射架构

```
Agent (LLM)
    │
    ▼ 调用工具
Tool Layer (后端)
    │
    ▼ SSE 事件流
Frontend Event Bus
    │
    ▼ 映射为 UI 动作
UI Components (动画、跳转、高亮)
```

### 工具类别与 UI 效果

| 类别 | 工具示例 | UI 效果 |
|------|----------|---------|
| 数据获取 | `fetch_kline`, `get_orderbook` | 图表加载/切换/刷新 |
| 分析计算 | `calculate_indicator`, `analyze_sentiment` | 指标面板展开，数值高亮 |
| 思考推理 | `think`, `plan_next_action` | 侧边栏气泡，打字机效果 |
| 交易执行 | `place_order`, `cancel_order` | 下单面板弹出/填入/提交 |
| 状态变更 | `update_stop_loss`, `adjust_position` | 图表标注线移动，数值更新 |
| 导航切换 | `switch_symbol`, `open_panel` | 页面/面板切换过渡动画 |
| 通知反馈 | `alert_user`, `request_approval` | 弹窗/toast/操作按钮 |

### UI 动作原则

1. **可见但不打扰** — 动画轻量（150-300ms），不阻塞用户操作
2. **可追溯** — 每个 UI 动作都关联到具体工具调用，点击可查"为什么"
3. **可打断** — 用户随时可以点击/输入打断 Agent 的操作流
4. **有区分** — AI 操作的元素有淡蓝色辉光/虚线框，与用户操作视觉区分
5. **可关闭** — 用户可以关闭"操作可视化"，只看结果不看过程

## 用户旅程总览

```
发现 → 模拟试跑 → 建立信任 → 小资金实盘 → 逐步放权 → 长期陪伴
  │         │          │           │            │          │
  │         │          │           │            │          └─ 策略进化、风格学习
  │         │          │           │            └─ 多策略、自动托管、睡前交接
  │         │          │           └─ 一句话开策略、实时对话、看着 AI 操作
  │         │          └─ 看到模拟收益，决定试试
  │         └─ 零成本体验，看 AI "演示"如何交易
  └─ "用自然语言交易？看着 AI 帮我操作？试试看"
```

## 设计原则

1. **操作可见** — Agent 的每一步都映射为用户可见的 UI 动作，消除黑箱感
2. **对话优先** — 一切操作都可以通过自然语言完成，按钮和表单是快捷方式
3. **渐进披露** — 新手看简洁界面 + Agent 操作动画；进阶用户关闭动画看原始数据
4. **AI 是助手不是老板** — 所有关键决策需要用户确认，AI 永远给建议而非命令
5. **可解释性** — 每一笔交易都能追溯到 AI 的推理过程和工具调用链
6. **安全兜底** — 宁可错过行情，不可意外亏损。异常时暂停是默认行为
7. **成本透明** — 用户随时知道 AI 花了多少钱，交易花了多少手续费
8. **用户可打断** — 任何时候用户操作优先级 > Agent 操作，用户点击即接管
