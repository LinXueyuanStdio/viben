Marketplace 发布流程

MCP Market 和 Skills Market 页面中"Publish My MCP"和"Publish My Skill"功能的规范。

概述​

MCP Market 和 Skills Market 页面都应该在页面头部右上角有一个发布按钮（仅在登录后可见）。点击按钮导航到多步骤发布向导。

入口点​

MCP Market (/mcp-market)​

元素规范
按钮文本"Publish My MCP"
位置页面头部右上角
可见性仅当用户已认证时
导航/mcp-market/publish

Skills Market (/skills-market)​

元素规范
按钮文本"Publish My Skill"
位置页面头部右上角
可见性仅当用户已认证时
导航/skills-market/publish

MCP 发布流程​

流程步骤​

步骤 1: 基本信息 → 步骤 2: 代码/配置 → 步骤 3: 预览 → 步骤 4: 发布

步骤 1: 基本信息​

必填字段：

字段类型必填描述
名称text是MCP 包名称
描述textarea是简短描述（最多 280 字符）
图标file upload是方形图片（推荐 512x512）
分类select是主要分类
标签multi-select否最多 5 个标签
版本text是语义化版本（如 1.0.0）
许可证select是MIT、Apache-2.0、GPL-3.0 等
主页url否项目主页或仓库

步骤 2: 代码/配置​

  • 上传 MCP 配置文件
  • 定义入口点和命令
  • 指定依赖和要求

步骤 3: 预览​

  • 显示 MCP 在市场中的展示效果
  • 以卡片格式显示所有元数据
  • 允许编辑（返回上一步）

步骤 4: 发布​

  • 最终确认
  • 服务条款协议
  • 提交审核或立即发布

Skill 发布流程​

流程步骤​

步骤 1: 导入来源 → 步骤 2: 编辑 → 步骤 3: 预览 → 步骤 4: 发布

步骤 1: 导入来源​

三种导入方法可用：

类型 1: 上传 ZIP 文件​

规范详情
输入多个 ZIP 文件选择
验证每个 ZIP 必须在根目录包含 SKILL.md
UI拖放区域 + 文件浏览器
反馈显示每个文件的验证状态

类型 2: 选择本地目录​

规范详情
输入目录选择器（多选）
验证每个目录必须在根目录包含 SKILL.md
UI带复选框的文件夹浏览器
反馈显示每个目录的验证状态

类型 3: 从 GitHub 导入​

规范详情
认证连接 GitHub 账户（OAuth）
步骤 1列出用户的仓库
步骤 2选择仓库
检测自动检测 skills/ 文件夹或根级 SKILL.md
步骤 3列出可用技能并带复选框
选择支持多个技能选择

步骤 2: 编辑​

对于每个导入的技能：

  • 预览 SKILL.md 内容
  • 编辑元数据（名称、描述、标签）
  • 添加/修改示例
  • 配置可见性（公开/私有）

步骤 3: 预览​

  • 显示每个技能在市场中的展示效果
  • 显示技能卡片预览
  • 允许批量审核多个技能

步骤 4: 发布​

  • 所有选中技能的最终确认
  • 服务条款协议
  • 发布全部或选择性发布单个技能

自动保存（草稿模式）​

功能规范
触发字段变更时自动保存（防抖 2 秒）
存储本地存储 + 在线时同步到后端
恢复返回时显示"继续草稿？"提示
过期草稿 30 天后过期
指示器显示"草稿已保存"吐司通知

UI 组件​

进度指示器​

[1] ─── [2] ─── [3] ─── [4]
 ●      ○       ○       ○
基本   配置    预览    发布
  • 带连接线的编号步骤
  • 当前步骤高亮
  • 已完成步骤显示勾选
  • 可点击导航（如果步骤可访问）

导航按钮​

位置按钮
左下"返回"（步骤 1 时禁用）
右下"继续" / "发布"（最后一步）
右上"保存草稿" / "取消"

验证​

  • 字段失焦时内联验证
  • 继续前进行步骤完成验证
  • 提交失败时在步骤顶部显示所有错误

错误处理​

场景行为
上传失败显示重试按钮，保留其他上传
GitHub 认证失败显示重新认证选项，保留选择
验证错误高亮字段，滚动到第一个错误
网络错误指数退避自动重试
草稿保存失败显示警告，提供手动保存选项

路由​

/mcp-market/publish           # MCP 发布向导
/mcp-market/publish/:draftId  # 恢复草稿

/skills-market/publish           # Skill 发布向导
/skills-market/publish/:draftId  # 恢复草稿

实现清单​

阶段 1: 基础​

  • 在 MCP Market 页面头部添加发布按钮
  • 在 Skills Market 页面头部添加发布按钮
  • 创建发布页面的路由结构
  • 实现按钮可见性的认证检查

阶段 2: MCP 发布​

  • 步骤 1: 基本信息表单
  • 步骤 2: 代码/配置上传
  • 步骤 3: 预览组件
  • 步骤 4: 发布确认
  • 自动保存功能

阶段 3: Skill 发布​

  • 步骤 1a: ZIP 文件上传及验证
  • 步骤 1b: 目录选择及验证
  • 步骤 1c: GitHub OAuth 集成
  • 步骤 1c: 仓库浏览器
  • 步骤 1c: 技能检测和选择
  • 步骤 2: 技能编辑器
  • 步骤 3: 批量预览
  • 步骤 4: 批量发布

阶段 4: 润色​

  • 进度指示器动画
  • 步骤间过渡动画
  • 加载状态
  • 错误恢复流程
  • 移动端响应式

设计说明​

遵循设计系统：

  • 主要操作使用温暖的琥珀色调色板
  • 标题使用衬线字体
  • 步骤过渡使用交错动画
  • 预览卡片匹配市场卡片设计
