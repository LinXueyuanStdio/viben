This directory contains documentation shared across multiple audience categories.

Directory Structure​

SubdirectoryContentRelated Audiences

DocumentDescriptionRelated Audiences

Coding Conventions​

ConventionDescription
API NamingAll Gateway API query parameters and file storage use snake_case
Import StyleUse explicit import type { ... } from "..." at file top; never inline import("path").Type
BuildNever run pnpm build or pnpm typecheck from root; always cd to specific package
YAML ConfigConfiguration uses file-native YAML paradigm, stored in ~/.viben/
Module Child LoggersEvery module creates a Pino child logger with { module: "name" }
