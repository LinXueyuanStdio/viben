viben init

在当前目录初始化 Viben 工作区。

用法​

viben init [options]

选项​

选项说明
--from <template>从模板初始化

示例​

基本初始化​

创建默认配置的新工作区：

viben init

输出（人类可读）：

Initialized Viben workspace in /path/to/project
  Created .viben/config.yaml

Next steps:
  viben mcp install <name>    # Install MCP servers
  viben skill install <name>  # Install skills

输出（JSON）：

viben init --json
{
  "success": true,
  "path": "/path/to/project/.viben",
  "files": ["config.yaml"]
}

从模板初始化​

从预定义模板创建工作区：

viben init --from my-template

创建的内容​

init 命令创建以下结构：

<project>/
  .viben/
    config.yaml       # 工作区配置

默认 config.yaml​

version: 1

# 工作区设置（覆盖全局配置）
settings:
  # 从全局配置继承

# 此工作区的 MCP 服务器
mcp:
  enabled: []
  disabled: []

# 此工作区的技能
skills:
  enabled: []

行为​

  1. 检查 .viben/ 是否已存在
  2. 如果存在，打印警告并退出
  3. 创建 .viben/ 目录
  4. 创建带默认设置的 config.yaml
  5. 打印下一步操作

错误处理​

工作区已存在​

viben init
Error: Workspace already initialized at /path/to/project/.viben

JSON 输出：

{
  "success": false,
  "error": {
    "code": "WORKSPACE_EXISTS",
    "message": "Workspace already initialized at /path/to/project/.viben"
  }
}

权限被拒绝​

{
  "success": false,
  "error": {
    "code": "PERMISSION_DENIED",
    "message": "Cannot create .viben directory: permission denied"
  }
}
