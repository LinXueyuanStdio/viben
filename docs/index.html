Search academic papers from 19+ sources including arXiv, PubMed, Semantic Scholar, IEEE Xplore, and more through a unified interface.

Built on the Model Context Protocol (MCP) for seamless integration with Claude Desktop, Claude Code, and other MCP-compatible clients.

Simple installation via pip. Configure once, search everywhere. Three tools: browse_search, browse_download, and browse_read.
