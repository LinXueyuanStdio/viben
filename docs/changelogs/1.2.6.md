## 亮点

- **预发布检查增强**: 新增 9 项自动化检查，包括 CLI/Core 构建验证和 Git 推送状态检查
- **标签栏拖拽优化**: 改进 Desktop 标签栏的拖拽体验和性能

## 新功能

### 预发布检查脚本 (`pnpm check:release`)

新增全面的发布前检查系统，确保代码质量和发布流程的可靠性：

| 检查项 | 说明 |
|--------|------|
| pnpm lockfile | 确保 lockfile 与 package.json 同步 |
| TypeScript | 类型检查无错误 |
| ESLint | 代码规范检查无错误 |
| @viben/core build | 核心包编译检查 |
| viben CLI build | CLI 包编译检查 |
| Cargo check | Rust/Tauri 代码编译检查 |
| Git status | 检查是否有未提交的更改 |
| Git branch | 检查是否在 main 分支 |
| Git push | 检查本地 commit 是否已推送到远程 |

```bash
# 手动执行检查
pnpm check:release
```

## 改进

### Desktop 标签栏拖拽优化

- **DragOverlay 视觉反馈**: 拖拽时显示标签的悬浮预览
- **SortableTabItem 性能优化**: 使用 `memo()` 避免不必要的重渲染
- **固定/非固定标签边界**: 拖拽时强制分组，不能跨越边界

### 工作区类型检测简化

- 移除 `WorkspaceType` 类型，统一使用 `workspace.id === "global"` 判断
- 简化 Gateway API 响应结构

### Desktop typecheck 支持

- 添加 `typecheck` 脚本到 desktop 包，支持 turbo 统一类型检查

## Bug 修复

- 修复预发布检查误报 TypeScript 错误的问题（rollup 警告被错误识别）
