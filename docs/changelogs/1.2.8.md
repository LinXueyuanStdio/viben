# Viben v1.2.8 更新日志

## 亮点

- **Telemetry 性能优化**: 大幅提升 trace 列表加载性能，支持海量日志数据
- **Gateway 稳定性增强**: 修复 WebSocket 路由和进程管理问题

## 新功能

### Desktop 开发模式右键菜单

在开发模式下启用浏览器原生右键菜单，支持 "检查元素" 等调试功能，方便开发者调试前端界面。

## 性能优化

### Telemetry Trace 列表优化

针对大量 trace 文件场景进行了全面优化：

| 优化项 | 说明 |
|--------|------|
| 分页加载 | 新增 `limit` 参数，默认返回 100 条记录 |
| 首 Span 过滤 | 仅读取 trace 文件的第一个 span 进行路由过滤 |
| 并行 stat | 并行获取文件元信息，减少 I/O 等待 |
| 跳过计数 | 日期端点不再计算每日 trace 数量 |

这些优化使 Telemetry 面板即使在数万条 trace 的情况下也能快速响应。

## Bug 修复

### Gateway WebSocket 路由修复

- 修复 WebSocket 连接测试使用错误的路由：
  - `/api/agent/ws` → `/ws/agent/run`
  - `/api/terminal` → `/ws/terminal`
- 修复 WebSocket 测试中的竞态条件问题

### Gateway 进程管理改进

- Gateway 启动命令从 `serve` 改为 `restart --force`
- 确保在启动新进程前终止残留的旧进程

### Telemetry 健壮性增强

- 修复 `limit` 参数解析异常值（NaN/无效值）的处理
- 修复 `readFirstSpan` 函数的文件流泄漏问题
- `DateSummary` 的 `count` 和 `totalSize` 字段改为可选

## 改进

- About 页面现在从 Tauri API 获取实际应用版本号
- Chat Monitor 日期选择器移除不必要的 count 显示
