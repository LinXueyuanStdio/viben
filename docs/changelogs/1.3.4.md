# Viben v1.3.4 更新日志

<p align="center">
  <img src="https://raw.githubusercontent.com/LinXueyuanStdio/viben/main/docs/design-system/brand-preview/viben-logo-release.svg" width="400" alt="Viben Release">

## 亮点

- **路由扁平化**：`/author` → `/[user_slug]`，`/read` → `/?tab=read`，更简洁的 URL 结构
- **社区互动系统**：评论线程化回复、点赞/收藏（favorites → bookmarks）、FeedCard 内联评论
- **管理后台大扩展**：新增 10+ 管理页面，榜单重建引擎，分析仪表盘
- **React Query 集成**：接入 `@tanstack/react-query`，评论/回复数据缓存与乐观更新
- **性能全面优化**：i18n 懒加载、组件动态导入、Suspense 流式渲染、骨架屏

## 新功能

### 路由扁平化与用户空间

- `/author` 路由迁移至 `/[user_slug]`，支持用户自定义 slug
- `/read` 路由迁移至 `/?tab=read`，阅读模式通过 URL 参数控制
- 新增 GitHub 风格「概览」标签页：置顶页面、个人 README、动态流、活动热力图
- 作者/用户链接全面改用 `userSlug` 路由
- 注册 reserved slug 黑名单检查

### 社区互动系统

- **评论系统**：线程化回复支持 `parent_comment_id`，SSR 首屏预取
- **@mention 渲染**：评论中 @提及 自动渲染为可点击链接
- **点赞/收藏**：PageCard、FeedCard、McpCard、SkillCard 全面接入交互式按钮
- **favorites → bookmarks**：数据库 schema、API 路由、前端组件全面重命名
- **FeedCard 内联评论**：动态卡片支持直接评论，无需跳转
- **乐观更新**：点赞/收藏操作即时反馈 + 失败回滚 + toast 错误提示

### 管理后台扩展

- 新增页面：活动流、草稿、媒体、评分、分享、通知管理、搜索分析、API 密钥管理
- **榜单重建引擎**：加权评分算法，支持定时重建与游标分页
- **分析仪表盘**：扩展统计卡片（文件、消息、下载等维度）
- 用户管理：关注网络弹窗、详情弹窗
- 运营位：修订历史 + 包版本历史
- 页面审核：订阅数 + 更新事件历史
- 动态管理：附件列表 + 转发链详情
- 管理后台导航按功能分组重构

### React Query 集成

- 接入 `@tanstack/react-query` + `QueryProvider`
- 评论回复改用 `useQuery` 缓存 + 分页导航
- 回复分页加载 + 乐观计数
- CommentsPanel 线程化数据管理

### 内容创作

- **PageEditor**：从 markdown 编辑器升级为原始 HTML 编辑器
- **页面发布合集支持**：合集选择器组件 + 订阅按钮
- **媒体上传代理 URL**：新增 `/api/media/asset` 端点
- **Vercel Blob 存储 Provider**：官方 SDK 替换原始 fetch
- Open Graph / Twitter Card 元数据自动生成

### 个人设置

- 头像上传（扩展名检测 + 格式校验）
- 密码修改
- 账户删除
- 阅读页作者设置面板全屏渲染
- 新增 `/settings` 独立设置页

### 导航与布局

- 用户菜单重构：头像 + 空间/页面/喜欢/收藏导航
- 浏览导航新增标签和作者入口
- CreateDropdown 快速创建组件
- DashboardShell 封装组件
- 全局搜索：热搜 + 最近搜索 API

## 改进

- **性能**：i18n 语言包按需懒加载，首页组件懒加载优化，管理后台页面全部 dynamic import
- **Suspense 流式渲染**：首页、个人主页重构为 Suspense + 客户端分节组件
- **骨架屏**：页面加载骨架屏组件，提升感知性能
- **图标标准化**：Heart → ThumbsUp（点赞），Star → Bookmark（收藏），Heart → MessageSquare（反馈）
- **i18n 完善**：管理后台、社区互动、页面设置等模块全面国际化
- **代码质量**：移除不必要的事务包装，简化写入路径；提取点赞/收藏自定义 hooks

## Bug 修复

- 发布按钮在历史加载时显示 loading 状态
- 阅读页缺少 tab 参数时自动 redirect
- liked/bookmarked 页面卡片指向正确的作者 userSlug
- createComment/deleteComment 同步更新源表 commentCount
- toggleReaction/Bookmark 反范式同步 likeCount/bookmarkCount
- 头像 Avatar 宽高比修复 + 条件渲染 + 上传后刷新
- avatarUrl 校验适配代理 URL 格式
- rankings rebuild 失败时清理孤立快照
- 乐观更新保护 + props 同步修复（useToggleLike/Bookmark）
- bookmark/reaction API 输入校验和错误处理增强
- 用户详情 API count 查询语法修复
- 分享管理 API 状态筛选逻辑修复
- 通知页面 session 可选链修复
- 活动热力图空数据场景支持
- 评论/互动 API entity_id 改用 pageDbId
- 仪表盘布局 session 和搜索数据异常容错
- 审核日志实体类型和操作枚举修复
- 关注按钮对自身隐藏 + 推荐关注排除当前用户
- Dark mode 修复（8 个组件）
- stats.ts sum() 聚合结果显式转为 Number

## 破坏性变更

> 无破坏性变更。路由旧路径（`/author`、`/read`）已设置自动重定向。
