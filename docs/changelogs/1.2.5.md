## 亮点

- **预发布检查脚本**: 新增 `pnpm check:release` 命令，发布前自动执行代码质量检查
- **标签栏拖拽优化**: 改进 Desktop 标签栏的拖拽体验和性能

## 新功能

### 预发布检查脚本

新增 `check-before-release.sh` 脚本，在发布前自动执行一系列质量检查：

```bash
# 手动执行检查
pnpm check:release
```

**检查项目:**

| 检查项 | 说明 |
|--------|------|
| pnpm lockfile | 确保 lockfile 与 package.json 同步 |
| TypeScript | 类型检查无错误 |
| ESLint | 代码规范检查无错误 |
| Cargo check | Rust/Tauri 代码编译检查 |
| Git status | 检查是否有未提交的更改 |
| Git branch | 检查是否在 main 分支 |

**集成到发布流程**: 运行 `pnpm release` 时自动执行这些检查，检查不通过则阻止发布。

## 改进

### Desktop 标签栏拖拽优化

- **DragOverlay 视觉反馈**: 拖拽时显示标签的悬浮预览，提供更清晰的视觉反馈
- **SortableTabItem 性能优化**: 使用 `memo()` 优化组件，避免不必要的重渲染
- **固定/非固定标签边界**: 强制固定标签和非固定标签分组，拖拽时不能跨越边界

### 工作区类型检测简化

- 移除 `WorkspaceType` 类型定义，统一使用 `workspace.id === "global"` 判断全局工作区
- 简化 Gateway API 响应结构，移除冗余的 `type` 字段
- 相关组件统一采用新的判断方式
