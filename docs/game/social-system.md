# 洛克王国 社交系统设计文档

> 本文档拆解洛克王国的社交功能体系，覆盖好友、公会、聊天及儿童安全设计。

---

## 1. 好友系统

### 1.1 基础功能

| 功能 | 说明 | 限制 |
|------|------|------|
| 添加好友 | 搜索ID/昵称 或 场景内点击 | 上限100人 |
| 删除好友 | 单方面删除 | 无冷却 |
| 黑名单 | 屏蔽指定玩家 | 上限50人 |
| 在线状态 | 显示好友是否在线 | 可设置隐身 |
| 好友分组 | 自定义分组标签 | 最多10组 |

### 1.2 好友互动

```
互动操作:
- 送礼: 每日可给好友送1份礼物（免费，系统赠品）
- 收礼: 接收好友礼物（+5友情点/份）
- 点赞: 给好友点赞（每日1次/人，+2友情点）
- 拜访: 访问好友家园（互相获得少量金币）
- 邀请: 邀请好友一起战斗/小游戏
- 观战: 观看好友的PVP对战

亲密度系统:
- 每对好友之间有独立亲密度(0-100)
- 互动操作增加亲密度
- 亲密度高解锁特殊功能:
  30: 可互相传送
  60: 组队经验额外+5%
  100: 好友专属称号
```

## 2. 公会/社团系统

### 2.1 公会基础

```
创建条件:
- 玩家等级 ≥ 20
- 消耗 10000 洛克贝
- 设置公会名称(2-8字) + 宣言

公会规模:
- 初始: 最多20人
- 升级: 通过公会活跃度升级，每级+5人
- 最大: 50人 (Lv.6公会)

公会等级:
  Lv.1: 20人上限, 基础功能
  Lv.2: 25人, 解锁公会任务
  Lv.3: 30人, 解锁公会商店
  Lv.4: 35人, 解锁公会副本
  Lv.5: 40人, 解锁公会竞赛
  Lv.6: 50人, 全功能解锁
```

### 2.2 公会职位

| 职位 | 人数 | 权限 |
|------|------|------|
| 会长 | 1 | 所有权限 + 解散/转让 |
| 副会长 | 1-3 | 审批入会 + 踢人 + 公告 |
| 精英 | 不限 | 参与管理任务 |
| 成员 | 不限 | 基础参与 |

### 2.3 公会活动

```
公会日常:
- 公会签到: 每日签到获得公会贡献+10
- 公会任务: 全员协作完成目标（如全员累计击败1000只怪）
- 公会捐赠: 捐赠物资换取公会币
- 公会副本: 多人组队挑战专属Boss

公会战:
- 每周末开启公会对抗赛
- 公会成员代表出战
- 积分累计决定公会排名
- 排名奖励分配给全体成员

公会贡献 → 公会币:
- 签到: +10贡献
- 完成公会任务: +20-50贡献
- 捐赠: 捐赠价值/10 贡献
- 公会币兑换比: 1贡献 = 1公会币
```

## 3. 聊天系统

### 3.1 聊天频道

| 频道 | 可见范围 | 发言限制 | 记录保存 |
|------|----------|----------|----------|
| 世界频道 | 全服所有在线玩家 | 每60秒1条 | 最近50条 |
| 区域频道 | 同区域玩家 | 每10秒1条 | 最近30条 |
| 公会频道 | 公会成员 | 每5秒1条 | 最近200条 |
| 私聊 | 指定玩家 | 每3秒1条 | 最近100条 |
| 组队频道 | 队伍成员 | 无限制 | 不保存 |
| 系统频道 | 全服(只读) | 系统发送 | 最近20条 |

### 3.2 聊天安全（儿童保护核心）

```
多层过滤机制:

Layer 1: 敏感词过滤
  - 词库: 10000+ 敏感词条
  - 算法: Aho-Corasick + DFA 自动机
  - 更新: 每周更新词库
  - 处理: 敏感词替换为 "***"

Layer 2: 模式检测
  - 电话号码模式 → 屏蔽
  - QQ号/微信号模式 → 屏蔽
  - URL链接 → 屏蔽
  - 重复刷屏检测 → 禁言

Layer 3: AI内容审核
  - 语义理解层面的不良内容检测
  - 变体词/谐音词识别
  - 上下文关联分析

Layer 4: 人工审核
  - 玩家举报触发人工复审
  - 高频触发系统的用户重点监控

处罚机制:
  首次违规: 警告 + 禁言30分钟
  二次违规: 禁言24小时
  三次违规: 禁言7天
  严重违规: 永久禁言/封号
```

### 3.3 快捷聊天

```
预设快捷语:
- "你好！一起玩吧~"
- "我们组队吧！"
- "谢谢你的帮助！"
- "等等我，马上来！"
- "好厉害！"
- "再见，下次见~"

表情系统:
- 系统表情包: 30+个通用表情
- 宠物表情: 宠物主题表情（20+）
- 限定表情: 活动获取（收集性）
- 无自定义上传（安全考虑）
```

## 4. 组队系统

### 4.1 组队功能

```
组队规则:
- 队伍人数: 2-4人
- 队长权限: 邀请/踢人/开始战斗/分配规则
- 组队方式: 邀请好友 / 附近组队 / 匹配组队

组队玩法:
- 组队副本: 需要2+人才能挑战的副本
- 组队Boss: 多人协作击败强力Boss
- 组队任务: 部分任务要求组队完成
- 组队探索: 一起探索新区域（经验加成）

组队加成:
- 2人队: 经验+10%
- 3人队: 经验+15%
- 4人队: 经验+20%
- 好友组队: 额外+5%
```

### 4.2 匹配系统

```
自动匹配:
- 选择目标副本/活动
- 系统根据等级/职业自动匹配队友
- 匹配等待时间: 通常30秒-2分钟
- 匹配失败: 扩大等级范围重新搜索

匹配优先级:
1. 等级相近(±5级)
2. 宠物属性互补
3. 等待时间最短
4. 地理延迟最低
```

## 5. 玩家交互

### 5.1 场景内交互

```
点击其他玩家可执行:
- 查看信息: 查看对方等级/宠物/成就
- 添加好友: 发送好友申请
- 私聊: 直接发送消息
- 邀请组队: 邀请加入队伍
- 邀请对战: 发起PVP对战
- 赞: 点赞(每人每日1次)
- 举报: 举报违规行为

场景互动:
- 跟随: 跟随指定玩家移动
- 表情动作: 在场景中做表情(挥手/跳舞/坐下)
- 拍照: 与场景/好友合影
```

### 5.2 排行榜

```
排行榜类型:
- 等级排行: 全服玩家等级Top100
- 战力排行: 宠物总战力Top100
- PVP排行: 竞技场积分排名
- 收集排行: 图鉴收集数量排名
- 成就排行: 成就积分排名
- 公会排行: 公会综合实力排名

排行榜更新:
- 实时排行: PVP积分（每场结算更新）
- 每日排行: 等级/战力/收集（每日0:00快照）
- 每周排行: 周积分排名
- 赛季排行: 每赛季结算

排行奖励:
- Top 1-3: 专属称号+大量钻石+限定外观
- Top 4-10: 称号+钻石
- Top 11-50: 钻石+道具
- Top 51-100: 道具
```

## 6. 邮件系统

### 6.1 邮件类型

| 类型 | 发送者 | 保留时间 | 是否有附件 |
|------|--------|----------|-----------|
| 系统邮件 | 系统 | 30天 | 是(奖励) |
| 好友邮件 | 玩家 | 7天 | 否 |
| 公会邮件 | 会长/副会长 | 7天 | 否 |
| 活动邮件 | 系统 | 活动结束+7天 | 是(奖励) |
| 交易邮件 | 系统 | 3天 | 是(道具) |

### 6.2 邮件功能

```
邮件收件箱:
- 最大容量: 100封
- 满箱提醒: 超过80封提示清理
- 批量操作: 一键领取所有附件 / 一键删除已读

邮件内容:
- 标题: 最多20字
- 正文: 最多200字
- 附件: 最多5种道具/货币
- 不支持: 图片/链接/自定义格式(安全考虑)
```

## 8. 儿童安全设计

### 8.1 社交安全措施

```
隐私保护:
- 不允许公开真实姓名/年龄/地址
- 昵称审核: 创建时检查是否含有个人信息
- 无音频/视频通话功能
- 无图片分享功能
- 聊天记录不对外公开

防骚扰:
- 陌生人不能直接私聊(需要对方同意)
- 一键屏蔽: 屏蔽后无法被搜索到
- 举报后24小时内处理
- 累计被举报N次自动限制社交功能

防诱导:
- 禁止在聊天中发送任何链接
- 禁止引导加QQ/微信等外部平台
- 禁止交换任何个人信息
- 系统定期发送安全提醒
```

### 8.2 防沉迷系统

```
未成年人限制 (中国法规要求):
- 实名认证: 通过身份证验证年龄
- 时间限制:
  周五/六/日/节假日: 20:00-21:00 仅1小时
  周一至周四: 不可登录
- 充值限制:
  8-16岁: 单次≤50元，月累计≤200元
  16-18岁: 单次≤100元，月累计≤400元
- 宵禁: 22:00-08:00 强制下线

在线时长提醒:
- 每60分钟: 弹出休息提醒("已玩1小时，注意休息哦~")
- 每120分钟: 强提醒 + 经验收益减半
- 超过180分钟: 经验收益为0 + 持续提醒

家长模式:
- 家长可设置孩子的每日游戏时长
- 家长可查看孩子的消费记录
- 家长可设置聊天开关
- 家长可设置充值上限
```
