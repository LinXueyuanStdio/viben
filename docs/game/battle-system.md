# 洛克王国 战斗系统设计文档

> 本文档详细拆解洛克王国的回合制战斗系统，覆盖战斗流程、伤害公式、状态系统、PVP规则等。

---

## 1. 战斗流程

### 1.1 战斗触发

| 触发方式 | 场景 | 说明 |
|----------|------|------|
| 野外遇敌 | 草丛/洞穴/水面 | 随机遭遇，可逃跑 |
| 点击精灵 | 野外可见精灵 | 指定遭遇，可逃跑 |
| NPC对战 | 道馆/训练师 | 不可逃跑 |
| Boss战 | 副本/活动 | 不可逃跑，特殊规则 |
| PVP对战 | 竞技场 | 匹配/邀请对战 |
| 组队战斗 | 多人副本 | 2-4人协作 |

### 1.2 回合制核心流程

```
战斗开始
  → 双方派出首发宠物
  → [回合循环开始]
      → 双方选择操作（30秒倒计时）
          选项: 技能 / 换宠 / 使用道具 / 逃跑
      → 行动排序:
          1. 优先级判定（高优先级先行动）
          2. 同优先级按速度排序
          3. 速度相同则随机
      → 依次执行行动:
          → 计算伤害/效果
          → 应用伤害
          → 触发附加效果
          → 检查击倒
      → 回合结束处理:
          → 天气效果结算
          → 状态异常伤害结算（中毒/烧伤）
          → 回合数+1
      → 检查胜负条件
  → [回合循环结束]
  → 战斗结算（经验/金币/掉落）
```

### 1.3 行动优先级

```
优先级等级 (-6 到 +6):
+6: 超高优先级（几乎不存在）
+5: 保护技能（守住/看穿）
+4: 极限先制
+3: 高速先制（电光石火类）
+2: 先制攻击
+1: 普通先制
 0: 普通技能（绝大多数技能）
-1: 慢速技能
-2: 
-3: 后制技能（报复类，最后出手威力翻倍）
-6: 最低优先级

同优先级排序规则:
1. 比较速度属性（含属性等级加成）
2. 速度相同则随机50%
3. 特殊场地效果可能反转速度排序（戏法空间）
```

## 2. 伤害计算公式

### 2.1 基础伤害公式

```
基础伤害 = ((2 × 攻击方等级 / 5 + 2) × 技能威力 × 攻击属性 / 防御属性) / 50 + 2

最终伤害 = 基础伤害 × 修正系数

修正系数 = STAB × 属性克制 × 暴击 × 随机数 × 其他修正

各修正详解:
- STAB: 本系加成，使用与自身同属性技能时 ×1.5
- 属性克制: 0 / 0.25 / 0.5 / 1 / 2 / 4 (双属性叠乘)
- 暴击: 暴击时 ×1.5 (特定技能/特性可提升为×2.0)
- 随机数: ×0.85~1.00 之间的随机浮点数
- 其他修正: 天气加成/道具加成/特性加成 等
```

### 2.2 物理vs魔法

```
物理技能:
  攻击属性 = 攻击方的"攻击"(ATK) × 攻击等级修正
  防御属性 = 防御方的"防御"(DEF) × 防御等级修正

魔法技能:
  攻击属性 = 攻击方的"魔攻"(SPATK) × 魔攻等级修正
  防御属性 = 防御方的"魔抗"(SPDEF) × 魔抗等级修正
```

### 2.3 属性等级修正

```
属性变化等级范围: -6 ~ +6

修正倍率:
  +6: 4.0 (8/2)
  +5: 3.5 (7/2)
  +4: 3.0 (6/2)
  +3: 2.5 (5/2)
  +2: 2.0 (4/2)
  +1: 1.5 (3/2)
   0: 1.0 (2/2) ← 初始值
  -1: 0.67 (2/3)
  -2: 0.5 (2/4)
  -3: 0.4 (2/5)
  -4: 0.33 (2/6)
  -5: 0.29 (2/7)
  -6: 0.25 (2/8)

通用公式: 
  等级 ≥ 0: 修正 = (2 + 等级) / 2
  等级 < 0: 修正 = 2 / (2 - 等级)
```

### 2.4 暴击系统

```
暴击等级与概率:
  等级0: 1/24 ≈ 4.17%
  等级1: 1/8 = 12.5%
  等级2: 1/2 = 50%
  等级3+: 必定暴击 100%

暴击等级提升来源:
- 部分技能自带暴击+1 (如劈斩类)
- 属性变化技能提升暴击等级
- 特定特性提供暴击等级加成
- 携带道具（聚焦镜等）

暴击效果:
- 伤害×1.5
- 无视对方的增益属性等级变化（如对方+6防御，暴击时视为0）
- 无视自身的减益属性等级变化（如自身-2攻击，暴击时视为0）
```

## 3. 天气系统

### 3.1 天气类型

| 天气 | 持续时间 | 效果 |
|------|----------|------|
| 晴天 | 5回合 | 火系威力×1.5，水系威力×0.5，太阳能量不需蓄力 |
| 雨天 | 5回合 | 水系威力×1.5，火系威力×0.5，雷电100%命中 |
| 沙暴 | 5回合 | 非岩/土/钢系每回合损失1/16HP，岩系魔抗×1.5 |
| 冰雹 | 5回合 | 非冰系每回合损失1/16HP，暴风雪100%命中 |
| 大雾 | 5回合 | 所有技能命中率×0.6 |

### 3.2 天气触发

```
触发方式:
1. 技能触发: 使用天气技能（晴天术/祈雨/沙暴术/冰雹术）
2. 特性触发: 特定宠物上场自动激活天气（如日照/降雨特性）
3. 场景固有: 部分战斗场景有固有天气

天气叠加规则:
- 新天气覆盖旧天气
- 特性触发的天气在切换宠物时可能被覆盖
- 特定道具可延长天气持续至8回合
```

|------|------|------|

### 4.3 状态互斥规则

```

- 中毒 / 剧毒 / 烧伤 / 冰冻 / 麻痹 / 睡眠

次要状态（可叠加，可与主要状态并存）:
- 混乱 / 着迷 / 畏缩 / 束缚 / 寄生种子
```

## 7. 逃跑与换宠

### 7.1 逃跑机制

```
逃跑成功率 = (我方速度 × 128 / 对方速度 + 30 × 逃跑尝试次数) / 256

规则:
- 野外战斗: 可逃跑
- NPC/Boss战: 不可逃跑
- PVP: 投降（直接判负）
- 被束缚/不可逃跑特性: 逃跑失败

逃跑失败: 本回合行动浪费，对方正常攻击
```

### 7.2 换宠机制

```
换宠规则:
- 消耗本回合行动权（换宠后对方可攻击新上场宠物）
- 换下的宠物保留当前状态（HP/状态异常/属性变化）
- 新上场宠物的属性等级重置为0
- 部分技能/特性可阻止换宠（束缚/影踪/磁力）
- 追击技能: 对方换宠时优先攻击换下的宠物（双倍威力）

强制换宠:
- 当前宠物被击倒时必须换宠
- 被吹飞技能命中时强制换为随机宠物
```

## 8. Boss战特殊机制

### 8.1 Boss战特点

```
Boss与普通战斗的区别:
- Boss有巨量HP（通常是普通宠物的5-20倍）
- Boss可能有多个生命条（如3条HP条，清空一条进入下一阶段）
- Boss可能免疫部分状态异常
- Boss可能有无视属性克制的专属技能
- Boss可能一回合行动多次（2-3次行动）
- Boss可能有怒气值机制（积满释放大招）

Boss战阶段设计:
Phase 1 (HP 100%-60%): 普通攻击模式
Phase 2 (HP 60%-30%): 强化攻击，使用增益技能
Phase 3 (HP 30%-0%): 狂暴模式，攻击频率增加，释放终极技能
```

### 8.2 多人Boss战

```
协作战斗规则:
- 2-4名玩家各派出1-2只宠物
- 按速度轮流行动（混合排序）
- 队友之间可以使用增益技能
- Boss攻击可能为群体伤害（全体受伤）
- 复活规则: 队友可消耗回合为倒下的宠物使用复活道具
- 贡献计算: 根据伤害量/辅助量分配奖励
```

## 9. PVP 对战系统

### 9.1 匹配机制

```
竞技场段位:
  青铜 → 白银 → 黄金 → 铂金 → 钻石 → 大师 → 传说

匹配规则:
- ELO 积分匹配（±200分范围内搜索对手）
- 等待超过30秒扩大搜索范围
- 段位保护: 低段位有掉段保护机制

积分变化:
- 胜利: +15~+30 (对手积分越高得越多)
- 失败: -10~-25 (对手积分越低扣越多)
- 连胜加成: 连胜3+场额外+5分
```

### 9.2 PVP 规则限制

```
队伍规则:
- 每方6只宠物
- 战前各方BAN 1只对方宠物（高段位）
- 先选后手各3只上场宠物
- 禁止重复宠物（同一队伍不能带两只相同宠物）
- 禁止重复道具（同一队伍不能带两个相同携带道具）

禁用列表:
- 部分过于强力的传说宠物进入Ban List
- 部分破坏平衡的技能组合被禁用
- 每赛季更新禁用列表

操作时间:
- 选招时限: 30秒
- 超时自动: 使用第一个技能/跳过
- 总时间限制: 每方总计10分钟（超时判负）
```

### 9.3 PVP赛季

```
赛季周期: 每月一个赛季
赛季重置: 排名回退2个段位
赛季奖励:
- 排名奖励: 根据最终段位发放（钻石/技能石/专属称号）
- 梯队奖励: 每周结算当前段位奖励
- 传说特权: 传说段位玩家可购买限定皮肤
```

## 10. 经验与奖励结算

### 10.1 战斗经验公式

```
获得经验 = 基础经验 × 等级系数 × 加成系数

基础经验 = 对方宠物基础经验值 × 对方等级 / 5

等级系数 = (2 × 对方等级 + 10) / (对方等级 + 我方等级 + 10)
  → 打高等级敌人获得更多经验
  → 打低等级敌人获得更少经验

加成系数:
- VIP加成: ×1.2~×1.5
- 经验卡加成: ×2.0 (限时道具)
- 首胜加成: 每日前5场 ×1.5
- 组队加成: ×1.1
```

### 10.2 金币掉落

```
金币 = 基础金币 × 等级/5 × 随机浮动(0.8~1.2)

加成:
- 金币卡: ×2.0
- VIP加成: ×1.2~×1.5
```

### 10.3 道具掉落

```
掉落规则:
- 每个宠物/Boss有掉落表(drop_table)
- 掉落表定义: [道具ID, 数量, 概率]
- 最多掉落3种不同道具
- 稀有道具有极低概率（0.1%~5%）
- Boss掉落率通常更高且有保底机制

保底机制:
- 累计N次未掉落稀有道具后，概率逐步提升
- 天选之子系统: 概率 = 基础概率 × (1 + 失败次数/保底次数)
```

## 11. 战斗AI设计（NPC/野生宠物）

### 11.1 AI难度等级

| 等级 | 行为 | 适用场景 |
|------|------|----------|
| 简单 | 随机选择技能 | 野外低等级宠物 |
| 普通 | 优先使用克制技能 | 野外高等级/普通NPC |
| 困难 | 考虑属性克制+状态+换宠 | 道馆/精英训练师 |
| 极难 | 预判+最优策略+道具使用 | Boss/高级PVE |

### 11.2 AI决策逻辑

```python
# 困难AI决策伪代码
def ai_decide(my_pet, enemy_pet, context):
    # 1. 检查是否需要换宠
    if should_switch(my_pet, enemy_pet):
        return switch_to_best_counter(enemy_pet)
    
    # 2. 评估所有可用技能得分
    scores = []
    for skill in my_pet.skills:
        score = evaluate_skill(skill, my_pet, enemy_pet)
        scores.append((skill, score))
    
    # 3. 选择最高分技能（加入少量随机性）
    scores.sort(by=score, desc=True)
    if random() < 0.1:  # 10% 概率选次优（避免过于可预测）
        return scores[1].skill
    return scores[0].skill

def evaluate_skill(skill, attacker, defender):
    score = 0
    # 属性克制加分
    score += type_effectiveness(skill.type, defender.types) * 50
    # 威力加分
    score += skill.power * 0.5
    # STAB加分
    if skill.type in attacker.types:
        score += 20
    # 状态技能: 对方无状态时加分
    if skill.has_status_effect and not defender.has_status:
        score += 30
    # 命中率惩罚
    score *= skill.accuracy / 100
    return score
```

## 附录: 伤害计算完整流程图

```
开始计算
  │
  ├─ 命中判定
  │    命中率 = 技能命中 × 命中等级修正 / 闪避等级修正
  │    随机数 < 命中率 → 命中
  │    否则 → MISS（跳过后续计算）
  │
  ├─ 暴击判定
  │    暴击率 = 基础暴击率(等级对应)
  │    随机数 < 暴击率 → 暴击
  │
  ├─ 基础伤害计算
  │    damage = ((2×Lv/5+2) × Power × Atk/Def) / 50 + 2
  │
  ├─ 修正系数叠乘
  │    × STAB (1.0 或 1.5)
  │    × 属性克制 (0/0.25/0.5/1/2/4)
  │    × 暴击 (1.0 或 1.5)
  │    × 随机 (0.85~1.00)
  │    × 天气 (0.5/1.0/1.5)
  │    × 道具 (1.0~1.3)
  │    × 特性 (各种特性修正)
  │    × 其他 (烧伤物攻减半等)
  │
  ├─ 最终伤害 = INT(修正后伤害)
  │    最小伤害 = 1（至少造成1点）
  │
  └─ 应用伤害 → 检查击倒 → 触发附加效果
```
