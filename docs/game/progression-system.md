# 洛克王国 玩家成长与留存系统设计文档

> 本文档拆解洛克王国的玩家进度、留存机制及长期目标系统。

---

## 1. 玩家等级系统

### 1.1 等级框架

```
等级范围: 1-100
升级时间预期:
  Lv.1-10:   第1-3天 (新手引导期)
  Lv.10-30:  第4-14天 (快速成长期)
  Lv.30-60:  第15-60天 (稳定发展期)
  Lv.60-80:  第61-120天 (深度培养期)
  Lv.80-100: 第120天+ (长线追求)

经验曲线:
  每级所需 ≈ level^2.5 × 基础系数
  低等级: 快速升级，保持新鲜感
  高等级: 慢速升级，延长内容寿命

等级解锁表:
  Lv.1:  基础战斗、捕捉
  Lv.5:  花园牧场、家园
  Lv.10: 农场系统、小游戏全开
  Lv.15: 公会加入、钓鱼
  Lv.20: PVP竞技场、创建公会
  Lv.25: 宠物咖啡馆
  Lv.30: 高级副本
  Lv.40: 超进化系统
  Lv.50: 天空之城
  Lv.60: 暗黑深渊、高级PVP
  Lv.80: 星际空间、赛季内容
  Lv.100: 觉醒系统、极限挑战
```

### 1.2 等级奖励

```
每10级里程碑奖励:
  Lv.10: 初始宠物进化 + 1000金币
  Lv.20: 高级精灵球×10 + 坐骑
  Lv.30: SR宠物蛋 + 称号"成长之星"
  Lv.40: 超进化石×1 + 3000金币
  Lv.50: SSR宠物选择券 + 称号"王国精英"
  Lv.60: 觉醒材料礼包 + 5000金币
  Lv.70: 传说装备箱 + 称号"魔法大师"
  Lv.80: UR宠物碎片×50 + 专属外观
  Lv.90: 全属性训练包 + 称号"传奇旅人"
  Lv.100: 限定称号"洛克王者" + 专属光效 + 100钻

每级奖励: 体力恢复 + 少量金币 + 解锁对应等级内容
```

## 2. 宠物收集进度

### 2.1 图鉴系统

```
图鉴结构:
├── 按属性分类 (16个属性标签)
├── 按区域分类 (按获取区域)
├── 按稀有度分类 (N/R/SR/SSR/UR)
└── 按进化链分类 (进化树视图)

图鉴状态:
- 未发现: 灰色剪影，仅显示编号
- 已遇见: 显示轮廓+名称，属性信息
- 已拥有: 全彩显示，完整信息
- 已完美: 拥有满个体/满级个体(金色边框)

收集里程碑:
  10种: 称号"初出茅庐" + 100钻
  50种: 称号"小小收藏家" + 300钻
  100种: 称号"百宠达人" + 500钻 + 图鉴背景
  200种: 称号"精灵学者" + 1000钻 + 限定宠物
  300种: 称号"传说猎人" + 2000钻 + 专属光效
  全收集: 称号"图鉴大师" + 5000钻 + UR宠物
```

### 2.2 收集驱动设计

```
收集动力来源:
1. 图鉴完成度可视化(进度条+百分比)
2. 收集奖励阶梯(持续正反馈)
3. 稀有宠物的社交展示价值
4. 部分宠物需要特殊方式获取(探索乐趣)
5. 赛季新增宠物(持续更新动力)

防止挫败:
- 每个区域都有容易捕捉的宠物(保底体验)
- 极稀有宠物有保底获取途径(非纯运气)
- 图鉴提示获取方式(不让玩家无头苍蝇)
```

### 3.2 称号系统设计

```
佩戴规则:
- 同时只能佩戴1个称号
- 佩戴称号显示在角色名称上方
- 部分称号有属性加成(如PVP称号+战力)

称号稀有度:
- 普通(白): 容易获得，无特效
- 精良(绿): 中等难度，文字变色
- 稀有(蓝): 较难获得，发光效果
- 史诗(紫): 高难度，粒子特效
- 传说(金): 极难获得，全套视觉效果
- 绝版(彩): 不可再获取，最高稀有度
```

## 4. 每日登录与留存

### 4.1 签到系统

```
每日签到:
- 每日登录自动签到
- 每日奖励递增(第1天100贝...第7天1000贝+道具)
- 累计签到里程碑(7/14/21/28天额外大奖)
- 月度签到全勤奖(SSR碎片/大量钻石)

7日签到示例:
  Day1: 500贝
  Day2: 800贝 + 经验药×1
  Day3: 1000贝 + 高级球×2
  Day4: 1500贝 + 训练药×2
  Day5: 2000贝 + 技能石×1
  Day6: 2500贝 + 经验药×3
  Day7: 5000贝 + SR宠物碎片×10 + 洛克钻×20

补签机制:
- 可补签前3天(消耗少量钻石)
- 每月最多补签3次
- 不影响连续签到计数(仅补领奖励)
```

### 4.2 回流机制

```
离线7天以上回流奖励:
- 回流专属任务链(高奖励快速追赶)
- 回流礼包(免费高级道具)
- 等级追赶加速(经验×2持续7天)
- 新内容引导(自上次登录以来的更新摘要)

回流任务:
  "欢迎回来！完成以下任务领取丰厚奖励:"
  1. 进行3场战斗 → 经验药×5
  2. 捕捉1只新宠物 → 高级球×10
  3. 完成1个每日任务 → 金币×5000
  全部完成 → 回流专属SR宠物
```

### 4.3 每日循环设计

```
玩家每日核心循环 (约30-60分钟):
┌──────────────────────────────────────────────┐
│  登录 → 签到领奖                              │
│    → 每日任务(3-5个, 15分钟)                  │
│    → 体力消耗(战斗/副本, 20分钟)              │
│    → 农场收菜/牧场互动(5分钟)                 │
│    → 好友互动/公会签到(5分钟)                 │
│    → 可选: 小游戏/PVP/探索(10-30分钟)        │
│  结束 → 第二天再来                            │
│                                              │
│  关键: 核心循环30分钟可完成,                   │
│        深度玩法可延伸到2小时+                  │
│        尊重儿童用户的时间限制                   │
└──────────────────────────────────────────────┘
```

## 5. 新手引导设计

### 5.1 引导阶段

```
Phase 1: 强制引导 (Lv.1-3, 约15分钟)
  - 全程高亮+遮罩引导
  - 不可跳过核心操作教学
  - 目标: 学会移动/对话/战斗/捕捉

Phase 2: 半引导 (Lv.3-10, 约2小时)
  - 主线任务引导为主
  - 可自由探索但有明确目标
  - 新功能首次使用时弹出简短教程
  - 目标: 熟悉所有基础系统

Phase 3: 弱引导 (Lv.10-20)
  - 仅在解锁新功能时有提示
  - 玩家自主决定玩什么
  - 目标: 培养自主游玩习惯

Phase 4: 无引导 (Lv.20+)
  - 完全自由
  - 帮助系统随时可查(快捷键H)
```

### 5.2 新手保护

```
保护机制:
- Lv.1-10: 野外战斗不会全灭(保底1HP)
- Lv.1-15: 宠物中心免费恢复(高等级后收费)
- Lv.1-10: 捕捉概率提升50%
- Lv.1-20: 经验获取×1.5(追赶加成)
- 新手服务器: 首周与高等级玩家隔离(PVP保护)
```

## 7. 战力系统

### 7.1 战力计算

```
总战力 = Σ(队伍中6只宠物的单体战力)

单体战力 = 基础战力 + 属性战力 + 技能战力 + 装备战力

基础战力 = 种族值总和 × 系数 + 等级 × 10
属性战力 = (个体值总和 × 2) + (努力值总和 / 4)
技能战力 = Σ(技能威力 × 技能评级系数)
装备战力 = 装备属性加成转换

战力用途:
- 副本门槛(最低战力要求)
- PVP匹配参考
- 排行榜排名
- 玩家实力直观展示
```

### 7.2 战力提升路径

```
提升优先级(性价比排序):
1. 宠物等级(最基础，每级+10战力)
2. 技能优化(更换高威力技能)
3. 努力值训练(最大+510战力)
4. 进化/超进化(大幅提升)
5. 个体值优化(洗练/换宠)
6. 装备强化(消耗高但提升稳定)
7. 觉醒系统(后期大幅提升)
```

## 9. 留存数据参考

### 9.1 目标留存率

```
次日留存: 55-65% (新用户第2天回来)
7日留存: 30-40%
14日留存: 22-30%
30日留存: 15-22%
90日留存: 8-12%

关键节点:
- Day1→Day2: 新手体验是否足够吸引
- Day3→Day7: 核心循环是否建立
- Day7→Day14: 社交绑定是否形成
- Day14→Day30: 长线目标是否清晰
- Day30+: 社区归属感+沉没成本
```

### 9.2 留存设计策略

```
短期留存(Day1-7):
- 连续登录递增奖励(断了就重新计算)
- 新手任务链(给予明确方向)
- 每日首胜大奖(每天第一场胜利奖励×3)

中期留存(Day7-30):
- 7日/14日里程碑大奖
- 公会社交绑定(加入公会后留存+20%)
- 宠物培养进度(沉没成本)
- 主线剧情悬念(想知道后续)

长期留存(Day30+):
- PVP赛季排名(竞争驱动)
- 收集图鉴(长线目标)
- 公会活动(社交义务)
- 限定内容FOMO(错过不再有)
- 持续更新(每周有新内容)
```
