# 洛克王国 世界地图与场景设计文档

> 本文档拆解洛克王国的世界结构、区域划分、导航系统及场景交互设计。

---

## 1. 世界结构总览

### 1.3 场景层级

```
世界地图（一级）
  ├── 区域（二级）: 如"王国城堡区"
  │     ├── 场景（三级）: 如"魔法学院"、"中央广场"
  │     │     ├── 室内/副本（四级）: 如"图书馆内部"
  │     │     └── 隐藏区域（四级）: 如"密室"

  └── ...

每个场景包含:
- 背景图层（静态/动态）

- NPC 坐标与行为
- 可交互物件列表
- 野生宠物出没表
- 传送点（通往其他场景）
- BGM 配置
- 环境音效
```

## 2. 核心区域详解

### 2.1 王国城堡区（核心枢纽）

```
场景列表:
├── 中央广场 (主聚集地，NPC集中)
├── 魔法学院 (技能学习/宠物训练)
├── 皇家研究院 (图鉴/进化/科研任务)
├── 城堡大厅 (主线NPC/皇室任务)
├── 商业街 (商店集中区)
├── 宠物中心 (HP恢复/宠物管理)
├── 竞技场入口 (PVP)
├── 邮局 (邮件/好友系统)
├── 银行 (存储/仓库)
└── 传送门广场 (通往各大区域)

功能NPC:
- 洛克博士: 主线任务、新手引导
- 训练师小明: 每日挑战
- 商人老李: 综合商店
- 宠物医生: HP/状态恢复
- 进化研究员: 进化帮助
- 传送使者: 远程传送服务
```

### 2.2 宠物园（新手区域）

```
场景列表:
├── 入口花园 (Lv.1-5 宠物)
├── 小树林 (Lv.3-8 宠物)
├── 草地 (Lv.5-10 宠物)
├── 池塘边 (Lv.5-12 水系宠物)
├── 虫虫洞穴 (Lv.8-15 虫系宠物)
└── 守望者小屋 (NPC教学)

设计目的:
- 新手学习捕捉机制的安全区域
- 低等级宠物丰富，容易捕捉
- NPC引导密集，降低迷路概率
- 无强力野生宠物，不会被误杀
```

## 3. 导航系统

### 3.1 场景内移动

```
移动方式:
- 鼠标点击: 点击目标位置，角色自动寻路移动
- 键盘方向: WASD/方向键 直接控制移动方向
- 自动寻路: 点击NPC/目标后自动导航

寻路算法: A* 路径搜索
网格粒度: 20×20像素
移动速度: 200像素/秒（跑步）、100像素/秒（行走）
坐骑加速: 300-400像素/秒
```

### 3.2 场景切换

| 切换方式 | 触发 | 动画 | 加载时间 |
|----------|------|------|----------|
| 边缘传送 | 走到场景边缘 | 渐隐渐现 | 0.5-1s |
| 传送门 | 点击传送门 | 旋转缩放特效 | 0.5-1s |
| 世界地图 | 打开地图点击目标 | 飞行动画 | 1-2s |
| NPC传送 | 与NPC对话选择 | 魔法特效 | 0.5-1s |
| 快捷传送 | 使用传送道具 | 瞬移光柱 | 即时 |

### 3.3 传送系统

```
传送限制:
- 世界地图传送: 需要消耗传送石或等待冷却(5分钟)
- NPC传送: 部分需要金币费用
- VIP传送: VIP用户可免费任意传送
- 回城传送: 任何位置一键回到城堡（固定快捷键H）

传送历史:
- 记录最近访问的10个场景
- 支持收藏常去场景（最多5个）
- 一键传送到收藏位置
```

## 4. NPC 系统

### 4.1 NPC 分类

| 类型 | 功能 | 标识 | 可交互范围 |
|------|------|------|------------|
| 功能NPC | 商店/训练/恢复 | 绿色名称 | 100像素 |
| 任务NPC | 接取/提交任务 | 黄色感叹号 | 150像素 |
| 剧情NPC | 触发剧情/对话 | 蓝色对话泡 | 120像素 |
| 战斗NPC | 发起NPC对战 | 红色拳头标记 | 200像素（自动触发） |
| 守卫NPC | 区域通行检查 | 无标记 | 路径阻挡 |
| 装饰NPC | 仅提供环境氛围 | 无标记 | 50像素（点击有反应但无功能） |

### 4.2 NPC 行为模式

```
静止型: 固定位置不动，玩家靠近后可交互
巡逻型: 在2-3个预设点之间循环移动
随机型: 在指定范围内随机走动
时间型: 只在特定时段出现（如夜间NPC）
条件型: 满足特定条件才可见（任务进度/等级）

NPC数据结构:
{
  id: number,
  name: string,
  scene_id: number,
  position: {x, y},
  behavior: "static" | "patrol" | "random" | "timed" | "conditional",
  patrol_points: [{x, y}],
  dialog_tree: DialogNode[],
  functions: ["shop" | "quest" | "battle" | "heal" | "craft"],
  appearance_condition: Condition | null,
  schedule: TimeRange | null
}
```

## 5. 场景交互物件

### 5.1 交互物件类型

| 类型 | 视觉提示 | 交互方式 | 示例 |
|------|----------|----------|------|
| 采集点 | 闪光粒子 | 点击 | 矿石、草药、宝箱 |
| 机关 | 可动画按钮 | 点击/序列 | 开关、拉杆、旋转石台 |
| 传送点 | 发光光圈 | 走入/点击 | 传送门、楼梯、洞口 |
| 隐藏物 | 无提示(或微弱) | 特定条件 | 隐藏宝箱、密道入口 |
| 场景道具 | 轻微动画 | 点击 | 告示牌、书架、望远镜 |
| 触发器 | 不可见 | 走入范围 | 剧情触发、野怪遭遇 |

### 5.2 每日刷新物件

```
每日重置:
- 采集点: 每日0:00重置，每个采集点每日可采集1-3次
- 宝箱: 每日随机刷新位置（固定数量，随机坐标）
- 隐藏NPC: 每日随机出现在不同场景
- 任务道具: 每日任务相关的交互物

设计目的:
- 鼓励玩家每日探索不同区域
- 增加回访动力
- 控制资源产出速率
```

## 6. 野生宠物分布

### 6.1 遇敌规则

```
遇敌概率:
- 每步移动在可遇敌区域判定一次
- 基础遇敌率: 8-15%（因区域不同）
- 使用驱虫喷雾: 遇敌率降为0（限时30分钟）
- 使用引怪香水: 遇敌率×2（限时30分钟）

宠物等级范围:
- 野生宠物等级 = 区域基础等级 ± 随机偏差(0~3)
- 稀有宠物可能超出区域等级范围
```

### 6.2 出没表设计

```yaml
# 示例: 小树林场景出没表
scene_encounter:
  scene_id: 102
  base_level_range: [3, 8]
  encounter_rate: 0.10  # 10%
  
  normal_encounters:  # 普通草丛
    - pet_id: 001  # 小火苗
      weight: 30   # 权重30%
    - pet_id: 005  # 绿毛虫
      weight: 30
    - pet_id: 008  # 小水滴
      weight: 25
    - pet_id: 012  # 电击鼠
      weight: 15
  
  rare_encounters:  # 稀有遭遇（5%概率触发稀有表而非普通表）
    - pet_id: 066  # 火焰鸟
      weight: 50
    - pet_id: 071  # 暗影狼
      weight: 50

  time_special:  # 时段限定
    - pet_id: 099  # 月光精灵
      time: "20:00-06:00"  # 仅夜间出没
      weight: 100
```

## 7. 环境系统

### 7.1 昼夜循环

```
时间系统:
- 使用服务器实时时间
- 6:00-18:00: 白天
- 18:00-6:00: 夜晚
- 过渡时段: 各30分钟渐变

昼夜影响:
- 部分宠物仅在白天/夜晚出现
- 部分NPC仅在特定时段出现
- 场景光照/色调变化
- 部分进化条件与时间相关
- 夜间某些区域开放隐藏通道
```

### 7.2 季节与天气

```
季节系统（跟随现实季节）:
- 春: 花园区域花开，草系宠物活跃
- 夏: 海域区域活动丰富，水系宠物活跃
- 秋: 森林区域落叶，虫系/暗系宠物活跃
- 冬: 雪域区域扩展，冰系宠物活跃

天气效果:
- 晴天: 默认状态
- 下雨: 水系宠物出现率+50%，部分路径湿滑（速度降低）
- 下雪: 冰系宠物出现率+50%，部分路径结冰
- 大雾: 视野缩小，隐藏NPC概率增加
- 雷暴: 电系宠物出现率+100%，特殊稀有宠物出没
```

## 8. 场景事件

### 8.1 世界事件

```
随机世界事件:
- 宠物大迁徙: 某区域临时出现大量稀有宠物（持续2小时）
- 宝藏潮: 全地图宝箱数量翻倍（持续1小时）
- 精英入侵: 各区域出现高等级精英宠物（击败有额外奖励）
- 双倍经验: 全服经验翻倍（周末常见）

事件通知:
- 全服公告横幅
- 地图上相关区域标记特殊图标
- NPC对话提示
```

### 8.2 场景谜题

```
谜题类型:
1. 机关序列: 按正确顺序触发多个机关
2. 寻物游戏: 在场景中找到隐藏物品
3. NPC对话线索: 与多个NPC对话拼凑信息
4. 数字/符号谜题: 输入正确密码
5. 迷宫探索: 在复杂地形中找到出路

解谜奖励:
- 隐藏区域入口
- 稀有道具/宠物蛋
- 成就/称号
- 大量金币/经验
```

## 9. 家园系统

### 9.1 个人家园

```
家园功能:
- 装修: 购买/摆放家具，自定义房间风格
- 宠物展示: 设置展示柜，展示收藏的宠物
- 花园: 种植花草，产出材料
- 鱼塘: 养鱼，定期收获
- 工坊: 合成道具
- 访客系统: 好友可以参观你的家园

家园扩展:
- 初始: 1间主屋(3×3格)
- Lv.10: 解锁花园(4×4格)
- Lv.20: 解锁工坊
- Lv.30: 解锁第二层
- VIP: 解锁高级装饰/更大空间
```

## 10. 场景技术规格

### 10.1 场景数据格式

```yaml
scene_config:
  id: 101
  name: "中央广场"
  region: "王国城堡"
  size: {width: 1920, height: 1080}
  
  layers:
    - type: "background"
      asset: "scenes/castle/central_bg.jpg"
      parallax: 0  # 固定不动
    - type: "midground"
      asset: "scenes/castle/central_mid.png"
      parallax: 0.5  # 轻微视差
    - type: "foreground"
      asset: "scenes/castle/central_fg.png"
      parallax: 1.0  # 前景遮挡
  
  walkable_grid:
    cell_size: 20
    data: "base64_encoded_bitmap"  # 1=可行走 0=不可行走
  
  npcs:
    - id: "npc_001"
      position: {x: 500, y: 400}
      behavior: "static"
    - id: "npc_002"
      position: {x: 800, y: 350}
      behavior: "patrol"
      patrol_path: [{x:800,y:350}, {x:900,y:350}, {x:900,y:450}]
  
  interactables:
    - id: "portal_01"
      type: "teleport"
      position: {x: 1800, y: 500}
      target_scene: 102
      target_position: {x: 50, y: 400}
    - id: "chest_01"
      type: "treasure"
      position: {x: 300, y: 600}
      respawn: "daily"
      loot_table: "common_chest"
  
  encounters:
    enabled: false  # 城镇区域无野怪
  
  bgm: "audio/bgm/castle_theme.ogg"
  ambient: "audio/ambient/town_bustle.ogg"
```

### 10.2 资源加载策略

```
场景切换加载顺序:
1. 优先加载: 背景图(最大资源)→可行走网格→传送点
2. 次优先: NPC精灵→交互物件→UI覆盖层
3. 延迟加载: 装饰动画→环境粒子→远景细节

预加载策略:
- 玩家接近场景边缘时，预加载相邻场景背景
- 传送门附近预加载目标场景
- 任务追踪中的目标场景提前预加载
```
