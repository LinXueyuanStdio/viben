# 洛克王国 小游戏与副玩法设计文档

> 本文档拆解洛克王国的休闲小游戏及副玩法系统，覆盖农场、钓鱼、答题等子系统。

---

## 1. 小游戏概览

### 1.1 小游戏分类

| 类别 | 数量 | 目标用户 | 奖励类型 | 每日次数 |
|------|------|----------|----------|----------|
| 教育答题 | 5+ | 全等级 | 经验+道具 | 每日10次 |
| 动作类 | 8+ | 全等级 | 金币+材料 | 每日5次 |
| 益智类 | 6+ | 全等级 | 金币+道具 | 每日5次 |
| 经营类 | 3+ | Lv.10+ | 材料+宠物食物 | 无限制 |
| 竞速类 | 3+ | Lv.15+ | 竞技币+称号 | 每日3次 |
| 音乐类 | 2+ | 全等级 | 金币+装饰 | 每日5次 |
| 社交类 | 4+ | 全等级 | 友情点+金币 | 与好友数挂钩 |

### 1.2 奖励与主循环连接

```
小游戏在主循环中的位置:
┌─────────────────────────────────────────────┐
│                                             │
│  主循环: 战斗→升级→进化→挑战更难内容         │
│                    ↑                        │
│  小游戏产出: 材料/经验/金币/稀有道具         │
│              (作为主循环的辅助资源来源)       │
│                                             │
│  设计目的:                                   │
│  1. 提供战斗之外的休闲内容                   │
│  2. 教育价值（答题/逻辑）                    │
│  3. 社交互动入口                             │
│  4. 缓解战斗疲劳（节奏调节）                 │
│  5. 资源获取多样化                           │
└─────────────────────────────────────────────┘
```

## 2. 农场/花园系统

### 2.1 农场功能

```
农场基础:
- 解锁等级: Lv.10
- 地块数量: 初始4块，最多扩展到16块
- 种植周期: 30分钟~24小时(不同作物)
- 收获产出: 宠物食物/合成材料/金币

种植流程:
1. 购买种子(商店/任务获得)
2. 翻地→播种→浇水
3. 等待生长(可用化肥加速)
4. 成熟后收获
5. 产物可用于: 喂养宠物/合成道具/出售

作物列表示例:
┌────────────┬──────────┬──────────┬───────────────┐
│ 作物       │ 种子价格 │ 生长时间 │ 收获物         │
├────────────┼──────────┼──────────┼───────────────┤
│ 小麦       │ 50贝     │ 30分钟   │ 宠物面包×3     │
│ 浆果       │ 100贝    │ 1小时    │ 能量浆果×2     │
│ 魔法花     │ 200贝    │ 4小时    │ 魔力精华×1     │
│ 金苹果树   │ 500贝    │ 12小时   │ 金苹果×1       │
│ 彩虹花     │ 1000贝   │ 24小时   │ 彩虹精华×1     │
└────────────┴──────────┴──────────┴───────────────┘

特殊机制:
- 偷菜: 好友成熟的作物可以"摘取"1个(每人每日1次)
- 除虫: 作物可能生虫，需要点击除虫(否则减产)
- 施肥: 使用化肥缩短25%生长时间
- 连种加成: 同一作物连续种植3次产量+10%
```

### 2.2 牧场系统

```
牧场(宠物托管):
- 解锁等级: Lv.15
- 可放置宠物: 3-8只(随等级扩展)
- 产出: 宠物定时产出材料(蛋/毛/角等)
- 互动: 每日可互动3次(抚摸/喂食)提升心情→产出+

宠物心情值:
  开心(80-100): 产出×1.5
  普通(40-80): 产出×1.0
  低落(0-40): 产出×0.5

心情提升:
- 喂食: +10心情
- 抚摸: +5心情
- 清洁: +5心情
- 放音乐: +3心情
每日不互动: -10心情
```

## 3. 钓鱼系统

### 3.1 钓鱼机制

```
钓鱼地点:
- 各区域的水域场景(池塘/河流/海边/地下湖)
- 不同地点有不同鱼种和稀有度

钓鱼流程:
1. 到达水域 → 装备鱼竿 → 抛竿
2. 等待(3-15秒随机)
3. 鱼上钩提示(浮标下沉 + 音效)
4. 玩家点击收杆(时机判定)
5. QTE小游戏: 力度条来回摆动，按键停在绿色区域
6. 成功 → 获得鱼/道具/宠物蛋(极稀有)

鱼竿等级:
- 木质鱼竿(初始): 基础成功率
- 铁制鱼竿(Lv.20): 成功率+10%
- 金质鱼竿(Lv.40): 成功率+20%, 稀有鱼+5%
- 传说鱼竿(活动): 成功率+30%, 稀有鱼+15%

鱼饵系统:
- 蚯蚓(免费): 普通鱼
- 虫饵(100贝): 稀有鱼概率+10%
- 金饵(500贝): 稀有鱼概率+25%
- 魔力饵(限定): 可钓到宠物蛋
```

### 3.2 钓鱼产出

```
鱼类用途:
- 出售: 获得金币(10-5000贝/条)
- 料理: 制作宠物食物(+经验)
- 收集: 鱼类图鉴(成就)
- 稀有: 极稀有鱼可兑换特殊道具

稀有度分布:
- 普通鱼(白): 60% - 价值10-50贝
- 优质鱼(绿): 25% - 价值100-300贝
- 稀有鱼(蓝): 10% - 价值500-1000贝
- 珍稀鱼(紫): 4% - 价值2000-5000贝
- 传说鱼(金): 1% - 价值10000+贝 或 特殊奖励
```

## 4. 答题系统

### 4.1 答题类型

| 答题活动 | 题目类型 | 参与时间 | 奖励 |
|----------|----------|----------|------|
| 每日知识问答 | 百科/常识 | 全天 | 经验+金币 |
| 学院考试 | 游戏内知识 | 全天 | 技能点 |
| 知识竞赛 | 限时抢答 | 14:00/20:00 | 高额金币+道具 |
| 数学挑战 | 计算题 | 全天 | 经验 |
| 成语接龙 | 语文题 | 全天 | 金币 |

### 4.2 答题机制

```
单人答题:
- 每次10题
- 每题15秒作答时间
- 答对+基础分, 连对加成递增
- 全对额外奖励(金币翻倍)

评分:
- 答对1题: +100分
- 连续答对加成: ×1.1, ×1.2, ×1.3... (最高×2.0)
- 最终得分兑换奖励

多人竞赛(知识竞赛):
- 50人同时参与
- 抢答制(先答对得分更高)
- 排名前10获得额外奖励
- 每日限参2次
```

## 5. 益智/解谜小游戏

### 5.1 华容道

```
规则: 经典滑块拼图
难度: 3×3(简单) / 4×4(中等) / 5×5(困难)
时限: 60秒/120秒/180秒
奖励: 根据完成时间评级(S/A/B/C)
```

### 5.2 记忆翻牌

```
规则: 翻开配对的牌
难度: 4对(简单) / 8对(中等) / 12对(困难)
时限: 无时限，但翻牌次数越少评级越高
奖励: 完美(无错误)获得额外奖励
```

### 5.3 连连看

```
规则: 消除相同图案的配对
难度: 按图案种类和棋盘大小分级
时限: 120-300秒
奖励: 全消+时间奖励
```

### 5.4 宝石消除

```
规则: 三消玩法，消除相同颜色宝石
模式: 限时模式/限步模式/无尽模式
奖励: 根据分数兑换金币/材料
```

## 6. 动作类小游戏

### 6.1 跑酷/跳跃

```
类型: 横版自动跑酷
操作: 点击跳跃/下蹲/二段跳
障碍: 坑洞/栅栏/怪物
收集: 沿途金币/道具
评分: 距离×金币数
```

### 6.2 射击打靶

```
类型: 定点射击
操作: 瞄准+点击射击
目标: 移动靶心/气球/怪物
连击: 连续命中加分
特殊: 隐藏靶(高分)/炸弹靶(扣分)
```

### 6.3 躲避游戏

```
类型: 避开障碍物
操作: 方向控制角色移动
难度: 障碍速度递增
生命: 3次碰撞后结束
评分: 存活时间
```

## 7. 经营类小游戏

### 7.1 宠物咖啡馆

```
解锁: Lv.25
玩法:
- 经营一家宠物主题咖啡馆
- 接待NPC客人(下单→制作→送餐)
- 升级设备提升效率
- 装修店铺吸引更多客人
- 雇佣宠物当服务员(使用你的宠物)

产出:
- 经营收入(金币)
- 客人满意度奖励(材料)
- 每日经营评级(S级额外奖励)
```

### 7.2 宠物竞速

```
解锁: Lv.20
玩法:
- 选择一只宠物参加赛跑
- 赛道有障碍和加速带
- 宠物速度属性影响基础速度
- 玩家操作: 适时跳跃/加速/变道
- PVP模式: 与其他玩家实时竞速

宠物选择影响:
- 速度高: 基础速度快
- 体力高: 加速持续时间长
- 轻量(飞行系): 跳跃更高
```

## 9. 小游戏评分与奖励系统

### 9.1 统一评级

```
评级标准(所有小游戏统一):
  S级: 得分 ≥ 满分90%  → 最高奖励 + 额外道具
  A级: 得分 ≥ 满分70%  → 高奖励
  B级: 得分 ≥ 满分50%  → 中等奖励
  C级: 得分 ≥ 满分30%  → 基础奖励
  D级: 得分 < 满分30%  → 参与奖(少量金币)

首次S级: 额外获得成就勋章
全小游戏S级: 解锁称号"游戏达人"
```

### 9.2 每日产出限制

```
防止无限刷奖励:
- 每个小游戏每日有奖励次数上限(3-10次)
- 超出次数后可继续玩但无奖励(纯娱乐)
- VIP增加每日次数上限(+2~+5次)
- 每周总产出有软上限(超出递减)
```

## 10. 挖矿/采集系统

### 10.1 矿洞探索

```
解锁: Lv.12
地点: 各区域的矿洞场景
玩法:
- 消耗体力进入矿洞(10体力/次)
- 矿洞内有多个矿点可点击采集
- 采集有QTE判定(力度条)
- 可能遇到隐藏怪(战斗)
- 单次可采集5-8个矿点

矿石用途:
- 合成装备
- 出售(金币)
- 交任务
- 强化材料

矿石稀有度:
- 铜矿(普通): 50%
- 铁矿(优质): 30%
- 银矿(稀有): 15%
- 金矿(珍稀): 4%
- 钻石矿(传说): 1%
```

### 10.2 采药系统

```
地点: 各区域的草地/花丛
玩法: 点击闪光草丛采集
产出: 各类草药(用于合成药品)
限制: 每日采集次数有限(20次)
特殊: 满月夜可采集到稀有月光草
```
