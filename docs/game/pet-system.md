# 洛克王国 宠物系统设计文档

> 本文档详细拆解洛克王国的宠物系统（精灵系统），覆盖获取、属性、进化、技能等核心子模块。

---

## 1. 宠物获取方式

### 1.1 野外捕捉

| 要素 | 说明 |
|------|------|
| 触发方式 | 在野外场景中点击草丛/水面/洞穴等触发点，或直接点击可见的野生宠物 |
| 捕捉条件 | 需要消耗精灵球道具 |
| 成功率公式 | `捕获率 = 基础捕获率 × (1 - 目标当前HP/最大HP) × 精灵球加成 × 状态加成` |
| 状态加成 | 睡眠/冰冻 ×2.0，麻痹/中毒/烧伤 ×1.5 |
| 精灵球类型 | 普通球(×1)、高级球(×1.5)、超级球(×2)、大师球(必定成功) |
| 动画表现 | 投球→球体晃动1-3次→成功(星光特效)/失败(弹开) |

### 1.2 孵化系统

```
孵化流程:
1. 获取宠物蛋（任务奖励/活动/商城）
2. 放入孵化器（背包→宠物蛋→开始孵化）
3. 等待孵化时间（2小时~48小时不等）
4. 孵化期间可通过"温暖操作"加速（每日3次，每次减少30分钟）
5. 孵化完成→获得对应宠物（个体值随机）

蛋的品质:
- 普通蛋: 孵出普通宠物
- 稀有蛋: 孵出稀有宠物，个体值下限较高
- 传说蛋: 孵出传说级宠物
```

### 1.3 任务奖励

- 主线任务关键节点赠送剧情相关宠物
- 新手任务赠送初始三选一宠物（火花/喵喵/水蓝蓝）
- 每周任务可能奖励稀有宠物碎片（收集一定数量合成）

### 1.4 活动获取

- 限时活动 Boss 战掉落
- 签到累计奖励
- 节日活动专属宠物
- 充值/VIP 专属宠物
- 抽奖/扭蛋系统

### 1.5 进化获取

- 部分宠物只能通过进化低阶宠物获得
- 超进化/魔力觉醒获得全新形态

## 2. 宠物属性体系

### 2.1 种族值（Base Stats）

固定不变的基础属性，由宠物种类决定：

| 属性 | 缩写 | 范围 | 说明 |
|------|------|------|------|
| 精力（HP） | HP | 20-150 | 决定最大生命值 |
| 攻击 | ATK | 20-150 | 物理攻击伤害基数 |
| 防御 | DEF | 20-150 | 物理防御减伤基数 |
| 魔攻 | SPATK | 20-150 | 魔法攻击伤害基数 |
| 魔抗 | SPDEF | 20-150 | 魔法防御减伤基数 |
| 速度 | SPD | 20-150 | 决定出手先后顺序 |

**种族值总和分级**：
- S级: 总和 ≥ 600（传说/神兽级）
- A级: 500-599（准神级）
- B级: 400-499（主力级）
- C级: 300-399（中等级）
- D级: < 300（新手/收集级）

### 2.2 个体值（Individual Values / IV）

每只宠物随机生成的天赋属性加成：

```
范围: 0-31（每项属性独立随机）
完美个体: 31（该属性的个体值达到上限）
全满个体: 六项均为31（极稀有，概率约 1/887,503,681）

个体值对最终属性的影响:
  最终属性 = (种族值 × 2 + 个体值 + 努力值/4) × 等级/100 + 5
  最终HP = (种族值 × 2 + 个体值 + 努力值/4) × 等级/100 + 等级 + 10

个体值优化手段:
- 反复捕捉同一宠物，挑选高个体值个体
- 使用"洗练丹"重新随机单项个体值
- 活动/VIP 赠送的宠物通常有保底个体值（≥25）
```

### 2.3 努力值 / 学习力（Effort Values / EV）

通过训练积累的属性加成：

```
每项属性上限: 252
六项总和上限: 510
每4点努力值 = 1点最终属性（在满级时）

获取途径:
- 击败野生宠物获得对应属性的EV（不同宠物给不同属性EV）
- 使用训练药剂（+10 / +25 / +50）
- 果实可减少特定属性EV（重新分配用）
- 专用训练场所（经验沙漏等道具加速）

竞技常用分配方案:
- 物攻速攻: ATK 252 + SPD 252 + HP 6
- 特攻速攻: SPATK 252 + SPD 252 + HP 6
- 物耐: HP 252 + DEF 252 + 任意 6
- 特耐: HP 252 + SPDEF 252 + 任意 6
```

### 2.4 性格系统（Nature）

共25种性格，影响属性成长（+10% / -10%）：

| 性格 | 加成属性(+10%) | 减少属性(-10%) |
|------|----------------|----------------|
| 孤僻 | 攻击 | 防御 |
| 勇敢 | 攻击 | 速度 |
| 固执 | 攻击 | 魔攻 |
| 调皮 | 攻击 | 魔抗 |
| 大胆 | 防御 | 攻击 |
| 悠闲 | 防御 | 速度 |
| 淘气 | 防御 | 魔攻 |
| 无虑 | 防御 | 魔抗 |
| 内敛 | 魔攻 | 攻击 |
| 保守 | 魔攻 | 防御 |
| 稳重 | 魔攻 | 速度 |
| 马虎 | 魔攻 | 魔抗 |
| 沉着 | 魔抗 | 攻击 |
| 温顺 | 魔抗 | 防御 |
| 慎重 | 魔抗 | 速度 |
| 浮躁 | 魔抗 | 魔攻 |
| 胆小 | 速度 | 攻击 |
| 急躁 | 速度 | 防御 |
| 天真 | 速度 | 魔抗 |
| 开朗 | 速度 | 魔攻 |
| 害羞/认真/实干/坦率/浮躁 | 无 | 无 |

**性格锁定**：使用"性格转换药剂"可改变宠物性格（消耗品）。

### 2.5 最终属性计算公式

```
非HP属性 = INT(INT(INT((种族值×2 + 个体值 + INT(努力值/4)) × 等级/100) + 5) × 性格修正)

HP属性 = INT((种族值×2 + 个体值 + INT(努力值/4)) × 等级/100) + 等级 + 10

性格修正:
- 有利性格: × 1.1
- 不利性格: × 0.9
- 中性性格: × 1.0
```

## 3. 宠物等级与经验

### 3.1 等级系统

```
等级范围: 1-100
经验值公式: 所需经验 = 等级^3（近似，实际有修正系数）

经验获取途径:
- 战斗获胜（主要来源）
- 经验果实/糖果道具
- 学习力训练附带经验
- 托管训练（离线挂机）

经验分配:
- 参战宠物获得全额经验
- 队伍中未参战宠物获得 50% 经验（需携带学习装置）
- 多只宠物出战时经验均分
```

### 3.2 经验曲线类型

| 类型 | 特点 | 适用宠物 |
|------|------|----------|
| 快速型 | 前期升级快，后期慢 | 普通/常见宠物 |
| 中等型 | 均匀增长 | 大多数宠物 |
| 慢速型 | 前期慢，后期相对快 | 稀有/传说宠物 |

## 4. 宠物进化系统

### 4.1 普通进化

```
进化条件类型:
- 等级进化: 达到指定等级自动触发（如 Lv.16, Lv.36）
- 道具进化: 使用特定进化道具（进化石/进化结晶）
- 条件进化: 满足特定条件（亲密度满/白天/夜晚/特定场景）
- 多分支进化: 同一宠物可进化为不同形态（选择分支）

进化效果:
- 种族值大幅提升（通常总和 +80~+150）
- 可能改变属性类型
- 学习新技能
- 外观完全改变
- 等级不变，已有EV/IV不变
```

### 4.2 超进化系统

```
超进化条件:
- 宠物已达最终进化形态
- 等级达到 100
- 持有对应的超进化石
- 亲密度达到满值

超进化特点:
- 种族值总和额外增加 100 点
- 获得专属超进化技能
- 外观获得华丽特效
- 战斗中激活（非永久状态，每场战斗可使用一次）
- 一个队伍只能有一只宠物超进化
```

### 4.3 魔力觉醒

```
魔力觉醒（类似Mega进化的永久升级）:
- 需要收集觉醒材料（通过特定副本掉落）
- 觉醒后永久提升属性
- 可能获得新的特性（被动技能）
- 可能改变属性类型组合
- 觉醒有多个阶段（觉醒I → 觉醒II → 觉醒III）
```

### 4.4 进化树示例

```
水蓝蓝 (Lv.1)
  ├─→ [Lv.16] 水蓝蓝进化体
  │     ├─→ [Lv.36] 水蓝蓝完全体
  │     │     ├─→ [超进化石] 水蓝蓝·超进化
  │     │     └─→ [觉醒材料] 水蓝蓝·觉醒
  │     └─→ [水之石] 水蓝蓝分支进化B
  └─→ [亲密度满] 水蓝蓝分支进化A
```

## 5. 技能系统

### 5.1 技能分类

| 分类维度 | 类型 | 说明 |
|----------|------|------|
| 伤害类型 | 物理技能 | 使用攻击/防御计算 |
|          | 魔法技能 | 使用魔攻/魔抗计算 |
|          | 变化技能 | 不造成直接伤害，改变状态 |
| 属性类型 | 火/水/草/电/土/冰/飞行/普通/暗影/光/机械/龙/毒/格斗/虫/萌 共16种 | |
| 目标范围 | 单体 | 只对一个目标生效 |
|          | 群体 | 对对方全体生效（威力通常降低） |
|          | 自身 | 对自己使用 |

### 5.2 技能属性

```yaml
技能数据结构:
  id: 唯一编号
  name: 技能名称
  type: 属性类型 (火/水/草/...)
  category: 物理/魔法/变化
  power: 威力值 (0-200)
  accuracy: 命中率 (0-100%)
  pp: 技能使用次数上限 (5-40)
  priority: 优先级 (-6 ~ +6, 默认0)
  target: 单体/群体/自身
  effect: 附加效果描述
  effect_rate: 附加效果触发概率 (0-100%)
  critical_rate: 暴击率修正 (0-3级)
  description: 技能描述文本
```

### 5.3 技能学习

```
学习方式:
1. 升级学习: 达到指定等级自动学习
2. 技能石学习: 使用对应技能石教学（消耗品）
3. 遗传学习: 通过特定组合的父代遗传
4. 回忆学习: 在NPC处花费金币回忆已遗忘的技能

技能栏限制:
- 每只宠物最多携带 4 个技能
- 学习新技能时必须遗忘旧技能（玩家选择）
- 被遗忘的技能可通过回忆NPC恢复

技能石获取:
- 商城购买
- 副本掉落
- 活动奖励
- PVP 赛季奖励
```

### 5.4 技能效果类型

```
直接伤害效果:
- 固定伤害: 无视属性直接扣固定HP
- 比例伤害: 扣除目标当前/最大HP的X%
- 连击: 一回合攻击2-5次，每次独立计算

附加效果:
- 状态异常: 中毒/烧伤/冰冻/麻痹/睡眠/混乱
- 属性变化: 提升/降低自己或对方的某项属性等级 (±1~±3)
- 天气改变: 改变场地天气
- 恢复效果: 回复自身HP (固定值/比例/吸取)
- 反伤: 反弹物理/魔法伤害
- 先制: 优先级+1~+3，无视速度先出手
- 后制: 最后出手但威力提升/效果增强

特殊机制技能:
- 连锁技能: 需要前一回合使用特定技能才能发动
- 蓄力技能: 第一回合蓄力，第二回合释放
- 反击技能: 根据本回合受到的伤害反击
- 模仿技能: 复制对方上一回合使用的技能
```

### 6.2 双属性计算

```
双属性宠物的克制计算:
最终倍率 = 技能属性对第一属性的倍率 × 技能属性对第二属性的倍率

例: 火系技能攻击 草/虫 双属性宠物
   = 2.0(火→草) × 2.0(火→虫) = 4.0 (四倍弱点！)

例: 水系技能攻击 火/土 双属性宠物
   = 2.0(水→火) × 2.0(水→土) = 4.0
```

### 6.3 本系加成（STAB）

```
Same Type Attack Bonus (STAB):
当宠物使用与自身属性相同的技能时，威力×1.5

例: 火系宠物使用火系技能 → 威力×1.5
例: 火/龙双属性宠物使用火系或龙系技能 → 均有×1.5加成
```

## 8. 宠物存储与队伍管理

### 8.1 队伍系统

```
出战队伍:
- 最多携带 6 只宠物
- 第一只为首发宠物（战斗开始时出场）
- 可随时调整顺序
- 队伍中宠物共享经验（携带学习装置时）

快速切换:
- 可保存多套队伍配置（最多5套）
- 一键切换队伍（PVE队/PVP队/练级队等）
```

### 8.2 宠物仓库

```
存储空间:
- 初始仓库: 50 格
- 扩展仓库: 通过消耗道具/钻石扩展，最大 500 格
- 每格存放一只宠物

管理功能:
- 搜索: 按名称/属性/等级/稀有度筛选
- 排序: 按获取时间/等级/稀有度/战力/编号排序
- 批量操作: 批量放生（释放）换取资源
- 收藏标记: 标记重要宠物防止误操作
- 锁定功能: 锁定的宠物不可被放生/交易
```

### 8.3 宠物图鉴

```
图鉴功能:
- 记录所有曾经拥有/遇见的宠物
- 显示捕获状态: 未遇见(灰色剪影) / 遇见(轮廓) / 拥有(全彩)
- 收集进度统计: 已收集/总数
- 图鉴奖励: 达到一定收集数量解锁称号/道具
- 宠物详情: 栖息地/进化链/推荐技能配置

图鉴数据结构:
{
  pet_id: number,
  status: "unseen" | "seen" | "owned",
  first_seen_time: timestamp | null,
  first_catch_time: timestamp | null,
  catch_count: number,
  shiny_owned: boolean
}
```

## 9. 特性系统（被动技能）

### 9.1 特性概述

每只宠物拥有一个特性（Ability），在战斗中被动生效：

```
特性分类:
- 战斗触发型: 受到攻击/攻击命中时触发
- 场地影响型: 影响天气/场地状态
- 属性修正型: 修改伤害计算/命中/闪避等
- 场外效果型: 影响遇敌概率/孵化速度等

特性获取:
- 每种宠物有 1-3 种可能的特性（随机获得其中一种）
- 隐藏特性: 特殊途径获得的个体才拥有（更强但更稀有）
- 特性胶囊: 可改变宠物特性（随机切换为同种宠物的其他可用特性）
```

### 9.2 常见特性示例

| 特性名 | 效果 |
|--------|------|
| 猛火 | HP低于1/3时，火系技能威力×1.5 |
| 激流 | HP低于1/3时，水系技能威力×1.5 |
| 茂盛 | HP低于1/3时，草系技能威力×1.5 |
| 飘浮 | 免疫土系技能 |
| 坚硬 | 不会被一击必杀（保留1HP） |
| 加速 | 每回合结束速度+1级 |
| 厚脂肪 | 受到火/冰系技能伤害减半 |
| 适应力 | STAB加成从×1.5提升为×2.0 |
| 威吓 | 上场时降低对方攻击1级 |

## 附录: 属性计算完整示例

```
示例: Lv.100 火花龙王（火/龙属性）
种族值: HP 80, ATK 130, DEF 75, SPATK 120, SPDEF 80, SPD 100
个体值: HP 31, ATK 31, DEF 28, SPATK 31, SPDEF 25, SPD 31
努力值: ATK 252, SPD 252, HP 6
性格: 开朗 (+SPD -SPATK)

最终HP = INT((80×2 + 31 + INT(6/4)) × 100/100) + 100 + 10
       = INT(191 + 1) × 1 + 110
       = 302

最终ATK = INT((INT((130×2 + 31 + INT(252/4)) × 100/100) + 5) × 1.0)
        = INT((130×2 + 31 + 63 + 5) × 1.0)
        = INT(354 × 1.0)
        = 354

最终SPD = INT((INT((100×2 + 31 + INT(252/4)) × 100/100) + 5) × 1.1)
        = INT((100×2 + 31 + 63 + 5) × 1.1)
        = INT(299 × 1.1)
        = 328 (开朗性格+10%)

最终SPATK = INT((INT((120×2 + 31 + 0) × 100/100) + 5) × 0.9)
          = INT(276 × 0.9)
          = 248 (开朗性格-10%)
```
