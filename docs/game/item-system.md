## 2. 装备系统

### 2.1 宠物携带道具

每只宠物可携带1件道具，战斗中被动生效：

```
攻击强化:
  力量头带: 物攻技能威力+10%
  博学眼镜: 魔攻技能威力+10%
  生命宝珠: 所有技能威力+30%，每次攻击扣10%HP
  选择头带: 物攻×1.5，但只能用第一个选的技能
  选择眼镜: 魔攻×1.5，但只能用第一个选的技能
  属性宝石(各属性): 对应属性技能威力+20%

防御强化:
  气势头带: 满HP时受致命攻击保留1HP(一次)
  进化奇石: 未完全进化宠物防御和魔抗×1.5
  突击背心: 魔抗×1.5但不能使用变化技能
  属性果实(16种): 弱点属性攻击伤害减半(一次性)

速度相关:
  选择围巾: 速度×1.5但只能用第一个选的技能
  先制爪: 技能+1优先级(10%概率触发)
  铁球: 速度减半(用于戏法空间队)

恢复类:
  剩饭: 每回合恢复1/16最大HP
  黑色污泥: 毒系每回合+1/16HP，非毒系-1/8HP
  贝壳铃: 造成伤害时恢复1/8伤害值的HP

特殊效果:
  焦点镜: 暴击率+1级
  红线: 被异性着迷时对方也着迷
  防尘护目: 免疫天气伤害
  特性胶囊: 使用后改变宠物特性(消耗)
```

### 2.2 装备获取

```
获取途径:
- 商店购买(基础装备)
- Boss/副本掉落(高级装备)
- 合成制作(部分独有装备)
- 活动奖励(限定装备)
- PVP赛季奖励

装备不可交易，绑定到账户
```

## 3. 合成系统

### 3.1 合成规则

```
合成站: 位于城堡区"炼金屋"NPC处
合成界面: 配方列表 + 材料消耗 + 成品预览

合成要素:
- 配方: 需要先解锁(任务/商店购买/掉落获得)
- 材料: 1-5种不同材料，各需1-10个
- 金币: 部分配方需要额外金币
- 成功率: 大部分100%，高级配方有失败概率
- 失败处理: 材料返还50% + 经验补偿

配方解锁:
  基础配方: 与NPC对话自动获得
  中级配方: 任务奖励/副本掉落
  高级配方: 成就解锁/活动限定
```

### 3.2 合成配方示例

```yaml
recipes:
  - id: "recipe_001"
    name: "高级HP药水"
    materials:
      - {item: "herb_green", count: 3}
      - {item: "crystal_water", count: 1}
    gold_cost: 200
    result: {item: "hp_potion_high", count: 1}
    success_rate: 1.0
    
  - id: "recipe_015"
    name: "超进化结晶"
    materials:
      - {item: "evolution_shard", count: 10}
      - {item: "dragon_scale", count: 3}
      - {item: "star_dust", count: 5}
    gold_cost: 10000
    result: {item: "mega_crystal", count: 1}
    success_rate: 0.8
    fail_return: 0.5
```

## 4. 背包系统

### 4.1 背包结构

```
背包容量:
- 初始格数: 100格
- 最大格数: 500格
- 扩展方式: 10格/次，消耗100钻或扩展石

分页/标签:
  [全部] [消耗品] [装备] [材料] [关键道具] [技能石] [宠物蛋]

排序选项:
  - 获取时间(新→旧 / 旧→新)
  - 稀有度(高→低 / 低→高)
  - 类型分组
  - 数量(多→少)
  - 名称(拼音排序)

搜索: 支持按名称关键字搜索
```

### 4.2 道具操作

```
操作类型:
- 使用: 对宠物使用(药品/训练药/技能石)
- 装备: 给宠物携带
- 丢弃: 删除道具(二次确认)
- 出售: 卖给NPC商人(原价50%)
- 批量操作: 一键出售所有低品质材料
- 锁定: 防止误操作(锁定后不可丢弃/出售)
- 分解: 高级道具分解为材料(部分可分解)

自动整理:
  点击"整理"按钮 → 自动堆叠 + 按类型排列 + 空格整合
```

## 5. 掉落系统

### 5.1 掉落表设计

```yaml
# 掉落表数据结构
drop_table:
  id: "dt_forest_boss"
  name: "幽暗森林Boss掉落"
  
  guaranteed:  # 必定掉落
    - {item: "gold", min: 500, max: 1000}
    - {item: "exp", value: 2000}
  
  random_pool:  # 随机掉落(选1-3个)
    pick_count: {min: 1, max: 3}
    items:
      - {item: "herb_dark", weight: 40, count: {min: 1, max: 3}}
      - {item: "crystal_shadow", weight: 30, count: 1}
      - {item: "skill_stone_dark", weight: 15, count: 1}
      - {item: "evolution_shard", weight: 10, count: {min: 1, max: 2}}
      - {item: "pet_egg_shadow", weight: 5, count: 1}
  
  rare_bonus:  # 额外稀有掉落(独立概率)
    - {item: "mega_crystal", chance: 0.02}
    - {item: "master_ball_fragment", chance: 0.01}
```

### 5.2 掉落概率分层

```
掉落稀有度:
  普通(白): 基础权重高，量大
  优质(绿): 有用但不稀缺
  稀有(蓝): 有明确需求，中等概率
  史诗(紫): 合成高级道具必需，低概率
  传说(金): 极低概率，改变游戏体验

概率公示: 所有付费相关概率必须公示(合规要求)
保底机制: 连续N次未出稀有 → 概率递增(怜悯机制)
```

### 5.3 掉落影响因素

```
基础概率 × 以下修正:
- VIP加成: +5%~+20%稀有掉落率
- 幸运药水: 使用后30分钟内掉落率×1.5
- 首次击杀: 第一次击杀Boss掉落率×2
- 公会加成: 公会等级提供+5%掉落
- 难度加成: 高难度副本掉落更好
```

## 6. 道具品质系统

### 6.1 品质颜色

| 品质 | 颜色 | 边框样式 | 数值范围 |
|------|------|----------|----------|
| 普通 | 白色 | 无边框 | 基础值 |
| 优秀 | 绿色 | 绿色细边 | +10% |
| 稀有 | 蓝色 | 蓝色边+光晕 | +20% |
| 史诗 | 紫色 | 紫色边+粒子 | +35% |
| 传说 | 金色 | 金色边+闪光 | +50% |

### 6.2 道具强化（装备类）

```
强化系统:
- 消耗: 金币 + 强化石
- 等级: +1 ~ +15
- 每级提升: 装备效果+5%~+10%
- 强化成功率:
  +1~+5: 100%
  +6~+10: 80%→60% (逐级递减)
  +11~+15: 50%→20%
- 失败: 等级不变(不降级)，材料消耗
- 保底: 连续失败5次，下次必成
```

## 7. 限时道具

### 7.1 时效性道具

```
计时类:
- 经验双倍卡: 2小时有效
- 金币双倍卡: 2小时有效
- 幸运药水: 30分钟有效
- 传送石(日): 24小时10次传送

使用后开始计时(非获得后)
过期自动消失
使用中断线不暂停计时

赛季类:
- 赛季通行证: 当季有效
- 活动代币: 活动结束后7天过期
- 限时外观试穿: 3天体验

过期提醒:
- 提前24小时: 邮件提醒
- 提前1小时: 弹窗提醒
- 过期时: Toast通知
```
