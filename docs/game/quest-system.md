# 洛克王国 任务系统设计文档

> 本文档拆解洛克王国的任务/活动体系，覆盖主线、日常、成就等子系统。

---

## 1. 任务分类

| 类型 | 数量级 | 刷新规则 | 奖励级别 | 追踪方式 |
|------|--------|----------|----------|----------|
| 主线任务 | 200+ | 一次性 | 高(宠物/大量经验) | 自动追踪 |
| 支线任务 | 500+ | 一次性 | 中(道具/金币) | 手动接取 |
| 每日任务 | 5-8个 | 每日0:00刷新 | 低-中 | 任务面板 |
| 每周任务 | 3-5个 | 每周一刷新 | 中-高 | 任务面板 |
| 成就任务 | 100+ | 永久累计 | 称号/外观 | 成就面板 |
| 活动任务 | 动态 | 活动期间 | 活动奖励 | 活动面板 |
| 悬赏任务 | 3个/天 | 每日可刷新 | 中(随机) | 悬赏板 |

## 2. 主线任务

### 2.1 章节结构

```
主线叙事结构 (每章约10-15个任务):

第一章: 魔法新生 (Lv.1-10)
  → 初始宠物选择 → 学习基础 → 第一次战斗 → 初遇反派

第二章: 宠物园危机 (Lv.10-20)
  → 宠物园异变 → 调查原因 → 击败入侵者 → 获得新伙伴

第三章: 暗影侵袭 (Lv.20-35)
  → 暗影势力出现 → 收集线索 → 深入幽暗森林 → Boss战

第四章: 元素试炼 (Lv.35-50)
  → 收集五大元素印记 → 各区域挑战 → 获得圣物

第五章: 王国危机 (Lv.50-70)
  → 最终反派现身 → 集结同伴 → 攻入暗黑深渊

第六章: 终极决战 (Lv.70-100)
  → 最终Boss多阶段战 → 拯救王国 → 新篇章预告

后续更新: 每2-3个月追加1章 (持续运营内容)
```

### 2.2 任务节点类型

| 节点类型 | 描述 | 示例 |
|----------|------|------|
| 对话 | 与NPC对话推进剧情 | "前往魔法学院找洛克博士" |
| 战斗 | 击败指定目标 | "击败暗影骑士×3" |
| 收集 | 收集指定数量物品 | "收集神秘碎片×5" |
| 探索 | 到达指定位置 | "前往龙之巢穴深处" |
| 捕捉 | 捕捉特定宠物 | "捕捉一只火焰鸟" |
| 谜题 | 完成机关/解谜 | "破解古代石门的密码" |
| 护送 | 保护NPC到达目的地 | "护送小精灵回到花园" |
| 选择 | 剧情分支选择 | "帮助A还是帮助B" |

## 3. 每日/每周任务

### 3.1 每日任务列表

```
固定每日任务 (每日0:00重置):
1. 完成3场战斗 → 奖励: 1000贝 + 100经验
2. 捕捉1只野生宠物 → 奖励: 500贝 + 普通球×3
3. 完成1次小游戏 → 奖励: 300贝
4. 与好友互动1次 → 奖励: 友情点×10
5. 使用1次训练场 → 奖励: 500贝 + 训练药×1

每日活跃度:
- 完成1个: 活跃度+20, 奖励初级宝箱
- 完成3个: 活跃度+30, 奖励中级宝箱
- 完成5个: 活跃度+50, 奖励高级宝箱
- 全部完成: 活跃度+100, 奖励钻石×10

活跃度累计奖励:
- 20点: 经验药×1
- 50点: 金币×2000
- 80点: 高级球×3
- 100点: 每日终极宝箱(含稀有道具概率)
```

### 3.2 每周任务

```
每周任务 (每周一0:00重置):
1. 累计完成20场战斗 → 2000贝 + 技能石随机×1
2. 捕捉5只不同宠物 → 3000贝 + 高级球×5
3. 完成5次小游戏 → 1500贝 + 体力药×2
4. PVP对战3场 → 竞技币×200
5. 完成所有每日任务3天 → 5000贝 + 钻石×20

周活跃度最终奖励: 超级宝箱 (含SR宠物碎片概率)
```

### 3.3 悬赏任务

```
悬赏板机制:
- 每日3个悬赏任务（可花费少量金币刷新）
- 难度等级: 简单(绿)/中等(蓝)/困难(紫)/传说(金)
- 奖励与难度成正比
- 完成后立即结算

悬赏任务类型:
- "击败XX区域10只野怪"
- "捕捉一只XX属性宠物"
- "收集XX材料×5"
- "在小游戏中获得XX分以上"

悬赏奖励倍率:
  简单: 基础奖励×1
  中等: 基础奖励×2
  困难: 基础奖励×4
  传说: 基础奖励×8 + 额外稀有道具
```

## 4. 成就系统

### 4.1 成就分类

| 类别 | 示例 | 奖励类型 |
|------|------|----------|
| 收集类 | 图鉴收集50/100/200只 | 称号+钻石 |
| 战斗类 | 累计胜利100/500/1000场 | 称号+道具 |
| 探索类 | 发现所有隐藏区域 | 称号+外观 |
| 社交类 | 添加10/50/100好友 | 友情点+道具 |
| 培养类 | 培养出满个体宠物 | 称号+展示框 |
| 财富类 | 累计获得100万金币 | 称号+金币 |
| 小游戏类 | 各小游戏达到S级 | 称号+道具 |
| 特殊类 | 季节/节日限定成就 | 限定称号+外观 |

### 4.2 成就进度设计

```
阶梯式成就示例:
"宠物收藏家"系列:
  ★☆☆ 初级收藏家: 收集10种宠物 → 称号+100钻
  ★★☆ 中级收藏家: 收集50种宠物 → 称号+300钻
  ★★★ 高级收藏家: 收集150种宠物 → 称号+500钻+限定背景
  
  进度条: [██████████░░░░░░] 67/150 (44%)

设计原则:
- 低阶成就容易达成（新手正向反馈）
- 高阶成就需要长期积累（老玩家目标）
- 最高阶成就有炫耀价值（社交驱动）
- 每个成就都有对应称号可佩戴
```

## 5. 任务引导系统

### 5.1 任务追踪

```
UI表现:
- 屏幕右侧显示当前追踪的任务(最多3个)
- 显示任务名称 + 当前目标 + 进度
- 点击可展开详细信息
- 地图上显示目标位置标记

自动导航:
- 点击任务目标 → 自动寻路到目标NPC/区域
- 到达后自动触发交互
- 如果需要战斗/采集，到达目的地后提示操作

任务提示:
- 新任务可接取时: NPC头顶黄色感叹号(!)
- 任务可提交时: NPC头顶黄色问号(?)
- 任务进行中: NPC头顶灰色问号(?)
```

### 5.2 新手引导（教学任务）

```
强制引导序列 (Lv.1-5):
1. 移动教学: "点击地面移动到指定位置" (高亮+箭头)
2. NPC交互: "点击洛克博士对话" (遮罩聚焦)
3. 宠物选择: "选择你的第一只宠物" (三选一面板)
4. 战斗教学: "使用技能攻击对手" (高亮技能按钮)
5. 捕捉教学: "使用精灵球捕捉野怪" (步骤分解引导)
6. 背包使用: "打开背包使用药品" (引导打开面板)
7. 传送教学: "使用传送门前往新区域" (引导点击)

引导后解锁:
- Lv.5: 自由探索，引导变为弱提示
- Lv.10: 解锁所有基础功能
- Lv.15+: 新功能仅首次简短提示
```

## 7. 对话系统

### 7.1 对话树结构

```yaml
dialog_tree:
  entry: "node_001"
  
  nodes:
    node_001:
      speaker: "洛克博士"
      text: "你好，年轻的魔法师！王国的东边出现了异常情况。"
      next: "node_002"
    
    node_002:
      speaker: "洛克博士"
      text: "你愿意帮我去调查吗？"
      choices:
        - text: "当然愿意！"
          next: "node_003"
          effect: {accept_quest: "MQ_001_005"}
        - text: "能给我一些装备吗？"
          next: "node_004"
        - text: "我现在没时间。"
          next: "node_005"
    
    node_003:
      speaker: "洛克博士"
      text: "太好了！拿着这些精灵球，它们会派上用场的。"
      effect: {give_item: [{id: "high_ball", count: 5}]}
      next: "end"
    
    node_004:
      speaker: "洛克博士"
      text: "当然，这些可能对你有帮助。"
      effect: {give_item: [{id: "hp_potion", count: 3}]}
      next: "node_002"  # 回到选择节点
    
    node_005:
      speaker: "洛克博士"
      text: "没关系，随时欢迎你回来。"
      next: "end"
```

### 7.2 条件对话

```yaml
# NPC根据玩家状态显示不同对话
conditional_dialog:
  npc_id: "guard_01"
  conditions:
    - if: {quest_status: "MQ_002_003", state: "completed"}
      dialog: "通行吧，勇士。前方的森林已经被清理了。"
      action: {allow_pass: true}
    
    - if: {quest_status: "MQ_002_003", state: "in_progress"}
      dialog: "森林里还有暗影怪物，你完成任务了吗？"
      action: {allow_pass: false}
    
    - if: {player_level: {gte: 20}}
      dialog: "你的等级足够了，但需要先接受调查任务才能通过。"
      action: {allow_pass: false}
    
    - default:
      dialog: "前方危险，等你更强一些再来吧。需要达到20级。"
      action: {allow_pass: false}
```

## 8. 活动任务

### 8.1 活动任务框架

```
限时活动任务特点:
- 有明确开始/结束时间
- 独立的活动积分/代币
- 专属奖励（活动结束后不可获取）
- 难度分级（让不同等级玩家都能参与）

活动任务结构:
├── 基础任务(每日): 简单操作，获取基础积分
├── 进阶任务(累计): 需要多日积累，高积分
├── 挑战任务(难度): 高难度，丰厚奖励
└── 隐藏任务(彩蛋): 特殊条件触发，额外惊喜

活动积分兑换:
- 100分: 基础奖励包
- 500分: 中级奖励包
- 1000分: 高级奖励包
- 2000分: 活动限定宠物
- 5000分: 活动限定外观
```
