# 洛克王国 活动系统设计文档

> 本文档拆解洛克王国的运营活动体系，覆盖活动类型、节奏、奖励设计。

---

## 1. 活动框架

### 1.1 活动类型总览

| 类型 | 周期 | 时长 | 目标群体 | 核心奖励 |
|------|------|------|----------|----------|
| 节日活动 | 按节日 | 7-14天 | 全体 | 限定宠物/外观 |
| 周年庆 | 每年1次 | 14-21天 | 全体 | 大量福利+限定 |
| 赛季活动 | 每月 | 30天 | Lv.20+ | 排名奖励 |
| 周末活动 | 每周 | 2天 | 全体 | 双倍/折扣 |
| 限时挑战 | 不定期 | 3-7天 | Lv.30+ | 稀有道具 |
| 联动活动 | 特殊 | 7-14天 | 全体 | 联动限定 |
| 回归活动 | 持续 | 7天 | 回流玩家 | 追赶礼包 |

### 1.2 活动日历年度规划

```
1月: 元旦活动(7天) + 寒假开始特别活动(14天)
2月: 春节大型活动(14-21天) - 全年最大活动
3月: 开学季活动(7天)
4月: 愚人节彩蛋(3天) + 春季版本更新
5月: 劳动节活动(5天) + 周年庆(如适用)
6月: 儿童节大型活动(14天) - 全年第二大活动
7月: 暑假活动开始(持续整个暑假,分3期)
8月: 暑假活动中后期 + 七夕(友情主题)
9月: 开学季活动(7天) + 中秋节(7天)
10月: 国庆活动(7-10天) + 万圣节主题(7天)
11月: 感恩节(好友主题, 3天)
12月: 圣诞/元旦跨年大型活动(14天)

每月固定:
- 月初: 新赛季开启
- 月中: 中期限时挑战
- 月末: 赛季结算 + 预告

每周固定:
- 周五晚: 周末活动开启
- 周日晚: 周末活动结算
```

## 2. 节日活动设计

### 2.1 春节活动模板

```
活动名: "洛克新春嘉年华"
时长: 14-21天
结构:

Phase 1 (Day 1-7): 集福气
  - 每日任务获得"福气值"
  - 福气值兑换阶梯奖励
  - 好友之间可互赠福气

Phase 2 (Day 7-14): 新春挑战
  - 特殊Boss登场(年兽)
  - 多人协作击败
  - 排名奖励

Phase 3 (Day 14-21): 抽福袋
  - 累计福气值可抽取福袋
  - 福袋含限定宠物"年兽宝宝"(SSR)
  - 保底200次必出

全程:
  - 登录送红包(每日金币/钻石)
  - 场景换装(全地图春节主题)
  - 限定商城上架春节外观
  - 烟花小游戏(社交互动)
```

### 2.2 暑假活动模板

```
活动名: "暑期大冒险"
时长: 45天 (分3期,每期15天)
特点: 长线活动，奖励丰厚，面向学生用户

第一期: 探索篇
  - 开放新地图(暑期限定区域)
  - 新宠物30只登场
  - 探索任务链

第二期: 挑战篇
  - 竞技对抗赛(积分制)
  - 难度递增副本
  - 排名奖励

第三期: 收获篇
  - 活动积分总兑换
  - 限定SSR宠物可通过累计获得
  - 大结局Boss战(全服协作)

暑期特权:
  - 每日在线时长奖励翻倍
  - 经验获取+50%(全期)
  - 新玩家7天快速成长礼包
```

## 3. 活动奖励设计

### 3.1 奖励层级

```
活动奖励分层(确保各付费层级都有收获):

免费玩家可获得:
  - 活动专属材料/道具
  - 活动外观(基础版)
  - SR级宠物(通过累计)
  - 金币/经验大礼包

低付费玩家(月卡级):
  - 以上全部
  - 活动通行证额外奖励
  - SR/SSR宠物碎片加速获取
  - 专属头像框

中付费玩家(100-300元):
  - 以上全部
  - SSR宠物直接获得(抽奖/兑换)
  - 高级外观
  - 专属称号

高付费玩家(300+元):
  - 以上全部
  - UR级宠物
  - 绝版外观/坐骑
  - 排名冲刺加速

设计原则:
- 免费能拿到80%内容
- 付费主要加速和获取装饰品
- 核心战力差距控制在15%以内
- 绝不出现"不付费玩不了"的情况
```

### 3.2 积分兑换商店

```
活动积分获取:
  每日任务: 100-200积分/天
  活动副本: 50-100积分/次
  活动小游戏: 30-50积分/次
  充值赠送: 每充1元送10积分

活动商店兑换:
  100分: 普通材料包
  300分: 高级材料包
  500分: SR宠物碎片×10
  1000分: 活动限定外观
  2000分: SSR宠物碎片×30
  3000分: SSR宠物直接获得
  5000分: 活动限定UR碎片×50

F2P玩家14天预期积分: 约2000-3000分 (可获得外观+SR)
月卡玩家14天预期积分: 约3500-4500分 (可获得SSR)
```

## 4. 限时挑战活动

### 4.1 挑战类型

```
个人挑战:
  - 限时Boss Rush: 连续击败N个Boss，计时排名
  - 单挑王: 使用指定条件(单只宠物/指定属性)通关
  - 速通挑战: 最快完成指定副本
  - 生存挑战: 坚持最多回合数

多人挑战:
  - 协作Boss: 全服玩家累计伤害击败超级Boss
  - 公会竞赛: 公会之间的积分对抗
  - 组队竞速: 4人组队限时通关

排名规则:
  - 个人排名: 按完成时间/分数排序
  - 实时更新: 每5分钟刷新排行
  - 奖励区间: Top1%/5%/10%/25%/50%

防作弊:
  - 服务器权威验证战斗数据
  - 异常成绩人工审核
  - 排行榜冻结期(活动结束前2小时不可超越)
```

## 5. 活动专属宠物

### 5.1 限定宠物设计原则

```
限定宠物特点:
- 独特外观(节日主题/联动主题)
- 种族值与同稀有度宠物相当(不过强)
- 专属技能1-2个(有特色但不破坏平衡)
- 获取后可永久使用
- 活动结束后不可再获取(制造稀缺性)

复刻规则:
- 普通限定: 6个月后可能复刻
- 联动限定: 通常不复刻
- 周年庆限定: 每年周年庆可能回归
- 绝版限定: 明确标注永不复刻
```

### 5.2 限定宠物获取途径

```
保证获取(F2P友好):
- 累计登录N天直接获得
- 活动积分兑换(需要肝但免费)
- 活动任务链完成后获得

概率获取:
- 限定抽奖池(需要钻石/活动货币)
- 保底机制(100-200次必出)
- 碎片积累(抽奖副产品换碎片,碎片合成)

混合模式(最常用):
- 免费可获得SR版本(基础外观)
- 付费/深度参与可获得SSR版本(华丽外观+略强属性)
```

## 7. 活动数值设计

### 7.1 活动产出控制

```
原则: 活动是"额外奖励"，不应破坏日常经济

活动产出上限(14天活动):
- 金币: 日常产出的150%（即活动提供额外50%收入）
- 经验: 日常产出的200%（加速成长但不爆炸）
- 稀有道具: 限量（如进化石最多获得2-3个）
- 限定宠物: 每次活动1-3只新宠物

防止老玩家囤积过多:
- 活动货币不跨期(本期不用下期作废)
- 活动道具有使用期限
- 高价值兑换有限购
```

### 7.2 参与度设计

```
目标: 80%活跃玩家完成60%以上活动内容

任务难度分布:
- 简单(所有人可做): 40%内容
- 中等(需要一定投入): 35%内容
- 困难(核心玩家): 20%内容
- 极限(硬核/付费): 5%内容

每日活动时间投入:
- 最低参与: 5分钟(签到+简单任务)
- 标准参与: 15-20分钟(大部分奖励)
- 深度参与: 30-60分钟(全部奖励)
```

## 8. 协作/全服活动

### 8.1 全服协作Boss

```
设计:
- 超级Boss有海量HP(如: 10亿HP)
- 全服玩家每次战斗贡献伤害
- 实时显示Boss剩余HP进度条
- Boss被击败后全服获得奖励

个人贡献:
- 根据累计伤害排名
- Top贡献者额外奖励
- 但所有参与者都有基础奖励

社交效果:
- 全服目标感("我们一起打败了它!")
- 世界频道实时播报进度
- 击败瞬间全屏烟花+公告

每周1次,通常周末举行
```
