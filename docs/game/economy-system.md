# 洛克王国 经济系统设计文档

> 本文档拆解洛克王国的虚拟经济体系，覆盖货币、商店、资源循环及付费模型。

---

## 1. 货币体系

### 1.1 货币类型

| 货币 | 获取方式 | 用途 | 是否付费 |
|------|----------|------|----------|
| 洛克贝 | 战斗/任务/日常 | 基础消费（商店/技能/训练） | 免费 |
| 洛克钻 | 充值/少量活动 | 高级消费（稀有道具/加速/外观） | 付费为主 |
| 竞技币 | PVP胜利 | 竞技商店兑换 | 免费(PVP) |
| 公会币 | 公会活动贡献 | 公会商店兑换 | 免费(社交) |
| 活动代币 | 限时活动 | 活动商店兑换 | 活动获取 |
| 友情点 | 好友互助/赠送 | 友情商店兑换 | 免费(社交) |

### 1.2 洛克贝（主货币）经济循环

```
产出源 (Faucet):
─────────────────────
战斗胜利:         50-500/场（根据对手等级）
每日任务:         2000-5000/天
主线任务:         1000-10000/次
小游戏:           100-1000/次
采集售卖:         50-300/次
NPC挑战:          500-2000/次
签到:             500-3000/天

消耗池 (Sink):
─────────────────────
商店购买道具:      100-50000/件
技能学习费用:      500-5000/次
宠物训练费用:      200-2000/次
传送费用:          100-500/次
装备强化:          1000-20000/次
进化消耗:          2000-10000/次
合成材料:          500-5000/次

平衡目标:
- 新手期(Lv.1-20): 日均产出 5000-8000，消耗 3000-5000
- 中期(Lv.20-60): 日均产出 10000-20000，消耗 8000-15000
- 后期(Lv.60-100): 日均产出 20000-50000，消耗 15000-40000
- 保持玩家始终有"需要但暂时买不起"的目标
```

### 1.3 洛克钻（付费货币）

```
获取方式:
- 充值购买（主要来源）: 1元 = 10洛克钻
- 每日签到: 5-10钻/天（连续签到加成）
- 成就奖励: 一次性10-100钻
- 活动奖励: 限量发放

充值档位:
  6元    → 60钻 + 赠送10钻
  30元   → 300钻 + 赠送60钻
  68元   → 680钻 + 赠送180钻
  128元  → 1280钻 + 赠送420钻
  328元  → 3280钻 + 赠送1200钻
  648元  → 6480钻 + 赠送2600钻

首充奖励: 首次任意金额充值赠送SSR宠物+专属称号
月卡: 30元/月，每日领取50钻（总计1500钻）+ VIP特权

洛克钻消费方向:
- 高级精灵球: 30钻/个
- 性格重置药: 50钻/个
- 经验翻倍卡: 20钻/张(2小时)
- 仓库扩展: 100钻/10格
- 限定外观: 200-500钻
- 抽奖/扭蛋: 50-300钻/次
```

## 2. 商店系统

### 2.1 商店类型

| 商店 | 位置 | 货币 | 刷新规则 | 特色 |
|------|------|------|----------|------|
| 综合商店 | 城堡商业街 | 洛克贝 | 永久库存 | 基础消耗品 |
| 高级商店 | 城堡商业街 | 洛克钻 | 永久库存 | 高级道具 |
| 技能商店 | 魔法学院 | 洛克贝 | 永久 | 技能石 |
| 竞技商店 | 竞技场 | 竞技币 | 每周刷新 | PVP奖励兑换 |
| 公会商店 | 公会大厅 | 公会币 | 每日刷新 | 团队道具 |
| 活动商店 | 活动NPC | 活动币 | 活动期间 | 限定道具 |
| 友情商店 | 社交中心 | 友情点 | 每日刷新 | 辅助道具 |
| 神秘商人 | 随机出现 | 洛克贝 | 随机刷新 | 折扣/稀有品 |
| 跳蚤市场 | 特定时段 | 洛克贝 | 每周六开放 | 玩家寄卖(间接) |

### 2.2 商品定价原则

```
定价公式依据:
- 恢复类: 价格 = 恢复量 × 基础系数
  HP药: 恢复50HP = 100贝, 恢复200HP = 500贝, 全满 = 2000贝
- 球类: 价格与捕获率正相关
  普通球 200贝, 高级球 600贝, 超级球 1200贝
- 训练类: 价格与效率正相关
  努力值+10: 500贝, +25: 1500贝
- 进化类: 价格与稀有度相关
  普通进化石: 3000贝, 稀有进化石: 10000贝/50钻

价格层级（洛克贝）:
  极低: 50-200  (基础消耗品)
  低:   200-1000 (常用道具)
  中:   1000-5000 (重要道具)
  高:   5000-20000 (稀有道具)
  极高: 20000-100000 (顶级道具)
```

### 2.3 限时折扣

```
折扣机制:
- 每日特惠: 1-3件道具半价(每日0点刷新)
- 周末折扣: 指定品类8折
- 节日大促: 全场7-8折 + 专属礼包
- 累计消费奖励: 消费满X送Y

限购机制:
- 部分高价值道具每日/每周限购
- 防止通货膨胀/资源滥用
- VIP提升限购上限
```

## 3. 资源循环设计

### 3.1 核心资源循环

```
┌─────────────────────────────────────────────────────────┐
│                    经济循环图                              │
│                                                         │
│  [战斗] ─→ 经验+金币+材料                               │
│    ↓                      ↓                             │
│  [升级] ─→ 解锁新区域 ─→ 更强野怪 ─→ 更多产出          │
│    ↓                                                    │
│  [训练] ←── 消耗金币+材料                               │
│    ↓                                                    │
│  [更强宠物] ─→ 挑战更难内容 ─→ 更好奖励                 │
│    ↓                                                    │
│  [PVP/Boss] ─→ 排名/稀有掉落 ─→ 炫耀/收集动力          │
│                                                         │
│  金币循环: 战斗产出 → 训练/商店消耗 → 需要更多战斗      │
│  材料循环: 采集产出 → 合成/强化消耗 → 需要更多采集      │
│  钻石循环: 充值/活动 → 加速/限定消耗 → 感受价值         │
└─────────────────────────────────────────────────────────┘
```

### 3.2 通胀控制机制

```
防止货币贬值:
1. 战斗收益随等级递减（反复刷同一区域收益降低）
2. 高级道具持续推出新消耗品
3. 强化系统有失败概率（消耗但无产出）
4. 限时道具过期（无法囤积转卖）
5. 赛季重置部分货币（竞技币等）

防止新手追赶无望:
1. 追赶机制: 低等级玩家经验/金币获取有额外加成
2. 新手礼包: 提供初期关键资源
3. 平民玩法: 核心玩法不需要大量付费货币
4. 天花板设计: 付费提升有上限（不能无限堆叠）
```

## 4. 交易系统

### 4.1 交易方式

```
洛克王国采用有限交易模式（面向儿童的安全设计）:

允许:
- 好友之间赠送特定道具（每日限额）
- 公会内部资源共享
- 活动期间的限定交换

不允许:
- 玩家之间直接金币交易（防RMT）
- 宠物直接交易（防盗号损失）
- 自由市场（防止操控经济）

安全考虑:
- 儿童用户防诈骗
- 防止账号盗取后财产损失
- 防止外部金币交易(RMT)
```

### 4.2 间接交易

```
寄卖系统（如有）:
- 将道具以固定价格寄售到公告板
- 其他玩家以洛克贝购买
- 系统收取5%手续费
- 只限特定类别道具
- 价格范围限制（不可低于/高于系统价的50%-200%）
```

## 5. VIP 系统

### 5.1 VIP等级

| VIP等级 | 累计充值 | 特权 |
|---------|---------|------|
| VIP1 | 30元 | 经验+10%，每日签到翻倍 |
| VIP2 | 100元 | 经验+15%，金币+10%，额外背包格 |
| VIP3 | 300元 | 经验+20%，金币+15%，免费传送 |
| VIP4 | 500元 | 经验+25%，金币+20%，专属坐骑 |
| VIP5 | 1000元 | 经验+30%，金币+25%，专属宠物 |
| VIP6 | 2000元 | 经验+40%，金币+30%，全特权 |
| VIP7 | 5000元 | 经验+50%，金币+40%，最高等级 |

### 5.2 VIP特权详情

```
通用特权:
- 经验加成（根据等级10%-50%）
- 金币加成（根据等级10%-40%）
- 每日免费体力恢复次数+1~+3
- 背包/仓库额外空间
- 免费传送（无需消耗传送石）
- 日常任务额外奖励
- 离线经验（托管训练加速）

专属内容:
- VIP专属外观/坐骑/称号
- VIP专属宠物（每个VIP等级一只）
- VIP专属任务线（额外剧情+奖励）
- VIP专属场景（高产出区域）
- VIP客服通道

限制（对非付费玩家友好）:
- VIP不提供属性数值碾压
- 核心PVP平衡不受VIP影响
- 所有宠物均可通过免费方式获取（VIP仅提供便利加速）
```

## 6. 抽奖系统

### 6.1 扭蛋/抽奖机制

```
抽奖类型:
1. 普通扭蛋（每日免费1次 + 洛克贝购买）
   - N级物品: 60%
   - R级物品: 30%
   - SR级物品: 9%
   - SSR级物品: 1%

2. 高级扭蛋（洛克钻购买）
   - R级物品: 50%
   - SR级物品: 35%
   - SSR级物品: 12%
   - UR级物品: 3%

3. 限定扭蛋（活动期间）
   - 包含活动专属宠物/道具
   - 概率公示（符合国家规定）
   - 保底机制: 100次内必出SSR

保底机制:
- 10连抽保底1个SR
- 50次保底1个SSR
- 100次硬保底（未出SSR则第100次必出）
- 天井系统: 200次可选择兑换任意SSR
```

## 7. 经济数值参考

### 7.1 各等级阶段的经济节奏

```
Lv.1-10 (新手期, ~3天):
  日均金币产出: 3000
  主要消费: 精灵球(200×5=1000) + 药品(500)
  目标: 学会基础消费概念

Lv.10-30 (成长期, ~2周):
  日均金币产出: 8000-12000
  主要消费: 训练(2000) + 技能石(3000) + 装备(3000)
  目标: 感受"赚与花"的循环

Lv.30-60 (发展期, ~1月):
  日均金币产出: 15000-25000
  主要消费: 进化(5000) + 强化(5000) + 高级道具(5000-10000)
  目标: 有明确的存钱目标

Lv.60-100 (成熟期, 持续):
  日均金币产出: 30000-50000
  主要消费: 极品培养(10000-20000) + 收集(10000+)
  目标: 长期收集动力
```

### 7.2 付费参考指标

```
ARPPU (付费用户月均消费): 30-80元
付费率: 5-8% (儿童游戏偏低)
首充转化率: 15-20%
月卡购买率(付费用户中): 40-60%

收入构成:
- 月卡/VIP: 35%
- 限定抽奖: 25%
- 直购道具: 20%
- 礼包/促销: 15%
- 其他: 5%
```
