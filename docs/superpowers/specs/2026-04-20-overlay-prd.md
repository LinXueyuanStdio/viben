# Overlay 演示系统 - 产品需求文档 (PRD)

> 创建时间: 2026-04-20
> 更新时间: 2026-04-20

## 概述

为 Viben Desktop 应用添加全局透明遮罩层，用于显示演示辅助元素，包括弹幕、字幕、鼠标点击指示器和按键可视化。

## 目标用户

- 录制教程和产品演示的内容创作者
- 进行直播或屏幕共享的用户
- 需要按键/鼠标操作可视化的日常用户

## 使用场景

| 场景 | 描述 |
|------|------|
| 录屏演示 | 录制教程、产品演示时显示操作提示 |
| 直播/会议 | 实时直播或屏幕共享时的字幕和互动 |
| 个人使用 | 日常使用时的按键/鼠标可视化 |

## 功能需求

### F1: 弹幕系统

**描述**: 在屏幕顶部区域显示从右向左滚动的弹幕文字。

**功能点**:
- 发送单条或批量弹幕
- 自定义弹幕颜色、字体大小、滚动速度
- 自动轨道分配避免重叠
- 暂停/恢复弹幕滚动
- 清空所有弹幕

**验收标准**:
- 同屏支持 500+ 弹幕，保持 60fps
- 弹幕不重叠、不遮挡

### F2: 字幕系统

**描述**: 在屏幕底部/中部/顶部显示字幕文字。

**功能点**:
- 显示/隐藏字幕
- 支持多种位置: 顶部、中部、底部
- 支持多种样式: 普通、对话框、旁白
- 支持动画效果: 淡入淡出、打字机效果、滑入
- 支持说话人标识（为 Galgame 风格对话预留）
- 流式输入支持（配合 AI 实时对话）

**验收标准**:
- 打字机效果流畅无卡顿
- 流式输入实时更新

### F3: 鼠标点击指示器

**描述**: 鼠标点击时在点击位置显示视觉反馈效果。

**功能点**:
- 启用/禁用点击指示器
- 支持多种效果样式: 涟漪、聚光灯、圆环
- 自定义颜色和大小
- 区分左键/右键/中键点击

**验收标准**:
- 点击反馈即时响应（< 16ms）
- 动画流畅无卡顿

### F4: 状态波浪指示器

**描述**: 在屏幕顶部显示半透明炫彩波浪动画，用于指示 AI 对话状态。

**状态定义**:

| 状态 | 触发场景 | 视觉效果 |
|------|----------|----------|
| `idle` | 默认状态 | 无波浪 / 微弱呼吸 |
| `listening` | 进入倾听模式 | 柔和蓝紫渐变波浪，缓慢起伏 |
| `speaking-calm` | 播报中：平缓 | 稳定绿色渐变波浪，规律波动 |
| `speaking-excited` | 播报中：激动 | 橙红渐变波浪，快速起伏，振幅大 |
| `speaking-happy` | 播报中：幸福 | 粉金渐变波浪，轻快跳跃，带粒子 |
| `ending` | 结束倾听/播报 | 波浪渐隐消散 |

**状态转换规则**:

```
idle ──startListening()──► listening ──startSpeaking(mood)──► speaking-*
                                                                   │
                           idle ◄──(300ms 自动)── ending ◄──stopSpeaking()──┘
```

- `reset()` 可从任意状态直接回到 `idle`
- `ending` 状态 300ms 后自动转换为 `idle`

**功能点**:
- 启用/禁用状态波浪
- 状态切换时平滑过渡动画
- 自定义波浪高度、透明度
- 支持自定义颜色主题

**验收标准**:
- 状态切换过渡流畅（< 300ms）
- 波浪动画保持 60fps
- 不遮挡主要 UI 内容

### F5: 按键可视化

**描述**: 显示用户按下的键盘快捷键。

**功能点**:
- 启用/禁用按键可视化
- 可选显示位置: 四个角落
- 可选只显示带修饰键的组合
- 自定义显示时长

**验收标准**:
- 按键显示即时响应
- 符号显示正确（⌘⇧⌃⌥ 等）

### F6: 全局控制

**描述**: 统一控制 Overlay 系统的显示和行为。

**功能点**:
- 显示/隐藏整个 Overlay
- 设置全局透明度
- 快捷键控制

**快捷键**:

使用 Tauri 风格快捷键格式，Mac 显示为符号，Windows 显示为文字。

| 快捷键 | Mac 显示 | Windows 显示 | 功能 |
|--------|----------|--------------|------|
| `CommandOrControl+Shift+O` | ⌘⇧O | Ctrl+Shift+O | 切换 Overlay 显示/隐藏 |
| `CommandOrControl+Shift+D` | ⌘⇧D | Ctrl+Shift+D | 切换弹幕显示 |
| `CommandOrControl+Shift+K` | ⌘⇧K | Ctrl+Shift+K | 切换按键可视化 |
| `CommandOrControl+Shift+C` | ⌘⇧C | Ctrl+Shift+C | 切换点击指示器 |
| `CommandOrControl+Shift+S` | ⌘⇧S | Ctrl+Shift+S | 切换字幕显示 |

### F7: 设置页面

**描述**: 在设置中新增 "Overlay 演示" Tab，集中管理所有配置。

**配置项**:
- 快捷键自定义
- 弹幕设置（轨道数、速度、字体、透明度）
- 字幕设置（位置、字体、背景色、动画）
- 点击指示器设置（样式、颜色、大小）
- 按键可视化设置（位置、过滤规则、时长）
- 状态波浪设置（高度、透明度、颜色主题）

## 非功能需求

### 性能要求

| 指标 | 目标值 |
|------|--------|
| 同屏弹幕数 | 500+ @ 60fps |
| 点击响应延迟 | < 16ms |
| 内存占用 | < 50MB |
| CPU 占用（空闲时） | < 1% |

### 兼容性

- macOS 12+
- Windows 10+
- 支持高 DPI 显示器

## 交互约束

### 点击穿透行为

采用双层架构实现灵活的交互控制:

| 层 | 行为 | 用途 |
|---|---|---|
| Animation Layer (PixiJS) | 完全穿透 | 弹幕、点击涟漪、按键提示等纯动画 |
| Interactive Layer (DOM) | 可交互 | 按钮、选择列表、输入框等需要用户操作的元素 |

### 可交互元素类型 (预留)

为未来功能预留完整的交互元素接口:

| 元素类型 | 用途 | 预留场景 |
|----------|------|----------|
| `button` | 单个按钮 | 确认/取消操作 |
| `button-group` | 按钮组 | 多选一操作 |
| `choice-list` | 单选列表 | Galgame 风格对话选项 |
| `multi-select` | 多选列表 | 多选问卷、设置 |
| `text-input` | 文本输入 | 用户输入内容 |
| `voice-input` | 语音输入 | 语音交互、语音识别 |
| `slider` | 滑块 | 数值调节 |
| `custom` | 自定义组件 | 扩展用 |

### 覆盖范围

- 仅覆盖 Viben 主窗口内部
- 不覆盖其他应用窗口

## 扩展性预留

为未来功能预留扩展接口:
- Live2D 角色显示
- Galgame 风格对话交互 (含选项选择)
- 语音交互 (语音输入、语音识别)
- 自定义 Overlay 层

## 数据来源

字幕和弹幕支持多种数据输入方式:
- 手动 API 调用
- 实时流式输入（AI 对话）
- 预定义脚本播放

### 流式字幕 API

为配合 AI 实时对话，提供专门的流式字幕接口:

```typescript
// 基础流式输入
subtitle.startStream({ speaker: "AI" });
for await (const chunk of aiResponse) {
  subtitle.appendStream(chunk);
}
subtitle.finishStream();

// 便捷方法 - 直接传入 AsyncIterable
const fullText = await subtitle.streamFromAsyncIterator(aiStream, { speaker: "助手" });
```

## 配置持久化

配置存储在 `~/.viben/overlay.yaml`，遵循项目 file-native 范式。

## 优先级

| 优先级 | 功能 |
|--------|------|
| P0 | 基础框架、弹幕、字幕 |
| P1 | 点击指示器、按键可视化、状态波浪 |
| P2 | 设置页面、配置持久化、Gateway 集成 |
| P3 | 扩展接口预留 (Live2D、Galgame 对话) |

## 降级策略

当性能下降时自动降级以保持流畅:

| 触发条件 | 降级措施 |
|----------|----------|
| FPS < 30 | 减少最大弹幕数至 200 |
| FPS < 30 | 禁用波浪粒子效果 |
| 内存 > 100MB | 清理对象池 |
