## 1. 概述

### 1.1 背景

Viben Desktop 应用需要集成语音交互能力，让用户能够通过语音与 AI 助手进行自然对话。语音交互将作为现有键盘/鼠标交互的补充，提供更便捷的使用方式。

### 1.2 目标

- 支持唤醒词激活语音助手
- 提供实时语音对话能力
- 通过视觉反馈（波浪动画、字幕）增强交互体验
- 在设置页提供完整的配置和测试功能

### 1.3 用户价值

- **解放双手**: 无需键盘输入，语音即可与 AI 交流
- **自然交互**: 像与真人对话一样与 AI 沟通
- **视觉反馈**: 炫彩波浪和实时字幕让交互过程更直观

## 2. 用户故事

### 2.1 首次配置

> 作为用户，我希望能够在设置页配置语音服务的 API Key，以便启用语音功能。

**验收标准**:
- 设置页有独立的「语音交互」区域
- 可以输入 Vocal Bridge API Key
- 可以输入 Porcupine Access Key
- 输入框支持显示/隐藏密钥

### 2.2 唤醒词激活

> 作为用户，我希望说出唤醒词后自动激活语音助手，无需手动点击。

**验收标准**:
- 支持配置唤醒词（默认"你好微本"）
- 检测到唤醒词后播放提示音
- 提示音后自动进入监听状态
- 可配置是否在应用启动时自动监听唤醒词

### 2.3 语音对话

> 作为用户，我希望在监听状态下与 AI 进行实时语音对话。

**验收标准**:
- 用户说话时顶部显示实时字幕
- AI 回复时通过语音播报
- 对话过程中显示炫彩波浪动画
- AI 长回复（≥400字符）时显示可滚动的文字弹窗

### 2.4 退出对话

> 作为用户，我希望能够通过多种方式退出语音对话。

**验收标准**:
- 可以通过语义表达退出意图（由 AI 判断）
- 静默超过设定时间后自动退出
- 按 Escape 键立即退出
- 退出时波浪动画平滑消失

### 2.5 测试功能

> 作为用户，我希望在设置页测试语音功能是否正常工作。

**验收标准**:
- 设置页有测试按钮
- 点击按钮进入监听状态
- 再次点击退出监听
- 测试时同样显示波浪和字幕效果

## 3. 功能需求

### 3.1 设置页 - 语音交互

#### 3.1.1 API 配置卡片

| 设置项 | 类型 | 说明 |
|-------|------|------|
| Vocal Bridge API Key | 密码输入框 | 语音服务 API 密钥 |
| Porcupine Access Key | 密码输入框 | 唤醒词检测服务密钥 |

#### 3.1.2 唤醒词设置卡片

| 设置项 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| 唤醒词 | 下拉选择 | "你好微本" | 激活语音助手的关键词 |
| 启动时自动监听 | 开关 | 关闭 | 应用启动后是否自动监听唤醒词 |
| 静默超时 | 滑块 | 30秒 | 无语音输入后自动退出的时间 |

#### 3.1.3 测试卡片

- 麦克风图标 + 状态文字
- 测试按钮（切换模式）
- 状态显示：点击开始说话 / 正在连接... / 正在监听...

### 3.2 语音交互流程

#### 3.2.1 激活方式

1. **唤醒词激活**: 检测到唤醒词 → 播放提示音 → 进入监听
2. **手动激活**: 点击测试按钮 → 进入监听

#### 3.2.2 对话状态

| 状态 | 波浪效果 | 字幕显示 | 说明 |
|-----|---------|---------|------|
| 监听中 | listening 样式 | 显示用户语音转文字 | 等待用户说话 |
| 处理中 | listening 样式 | 保持最后内容 | 等待 AI 响应 |
| AI 说话 | speaking 样式 | 用户字幕保持 | AI 正在回复 |

#### 3.2.3 退出方式

- **语义退出**: AI 判断用户表达了退出意图
- **超时退出**: 静默超过配置时间（默认30秒）
- **手动退出**: 按 Escape 键

### 3.3 视觉反馈

#### 3.3.1 波浪动画

- 位置：屏幕顶部
- 样式：多层叠叠、多彩渐变、灵动流畅
- 形状：中央凹陷，为字幕留出清晰可读空间
- 状态：listening（蓝色系）/ speaking（橙绿色系）

#### 3.3.2 用户字幕

- 位置：屏幕顶部，波浪凹陷区域内
- 内容：用户语音的实时转写文字
- 效果：流式显示，带闪烁光标

#### 3.3.3 AI 回复弹窗

- 触发条件：AI 回复 ≥400 字符
- 位置：用户字幕下方
- 内容：流式 Markdown 渲染，带闪烁光标
- 交互：
  - 支持滚动浏览
  - 支持选中复制
  - 支持代码高亮
  - 支持链接点击
- 消失方式：点击弹窗外部
- 用户说话时：透明度降至 30%，但保持显示

### 3.4 音效反馈

| 场景 | 音效 | 说明 |
|-----|------|------|
| 检测到唤醒词 | 提示音 | 短促的"叮"声 |
| 连接失败 | 错误音 | 表示出错 |

### 3.5 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| API Key 未配置 | Toast 提示配置 |
| 麦克风权限拒绝 | Toast 提示授权 |
| 网络连接失败 | Toast + 错误音效 |
| 语音服务错误 | Toast + 错误音效 |

## 4. 非功能需求

### 4.1 性能

- 唤醒词检测延迟 < 500ms
- 语音转文字延迟 < 1s
- 波浪动画保持 60fps

### 4.2 兼容性

- macOS 平台优先支持
- 需要麦克风硬件和权限

### 4.3 安全性

- API Key 本地加密存储
- 不上传原始音频到非必要服务

## 5. 开发阶段规划

### 第一阶段：基础功能

- 设置页 UI
- Vocal Bridge 集成

- Porcupine 集成
- 先用内置唤醒词测试
- 训练"你好微本"自定义模型

### 第三阶段：增强体验

- AI 回复弹窗（流式 Markdown）
- 多层炫彩波浪特效
- 音效系统
- 错误处理优化
