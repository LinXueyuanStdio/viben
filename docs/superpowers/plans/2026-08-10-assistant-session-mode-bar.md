# Assistant Session 模式栏 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `/assistant` Session Starter 底部模式栏改成紧凑的 Settings、repo 和 branch 分段选择器，并让有效 repo 选择成为进入 repo session 的唯一条件。

**Architecture:** `SessionStarter` 继续拥有 repo、branch、Vercel 与 Git 状态，从 `selectedOwner/selectedRepo` 派生 session 模式。`BranchSelectorCompact` 增加紧凑展示变体并复用现有数据与选择逻辑；repo popover 保留 repo、Vercel 与 Git 设置，branch popover 移到底栏独立触发。

**Tech Stack:** React 19、Next.js、TypeScript、Tailwind CSS v4、Radix Popover、SWR、Vitest、Testing Library

## Global Constraints

- 在当前工作区和当前会话内执行，不创建 worktree，不派子智能体。
- 编辑文件时使用绝对路径。
- 不增加头像或头像请求；Settings 图标仍导航到 `/settings/sandbox`。
- 未选择 repo 时始终显示 `New chat`，不显示 `New session`。
- 选中 repo 后显示 `username/reponame ⇅ > branch ⇅`，整行左对齐且视觉高度约 32px。
- repo popover 保留 Vercel 和 Git 设置；branch 仅由独立 branch popover 选择。
- 禁止 inline import type 和非例外动态 import。
- Tailwind v4 语义色变量不得用 `hsl()` 包裹。
- build/typecheck 只在 `apps/web` 目录运行。

- [ ] **Step 3: 从 repo 选择派生模式**

删除 `SessionMode` 和 `mode` state，增加：

~~~tsx
const hasRepoSelection = Boolean(selectedOwner && selectedRepo);
~~~

把 Vercel 加载、pending、显示条件、提交禁用和 submit payload 中的 `mode === "repo"` 全部改成 `hasRepoSelection`。`resetRepoSelection` 不再写 mode。

Popover 开关改为：

~~~tsx
const handleRepoPopoverChange = (open: boolean) => {
  if (open && isRepoModeDisabled) return;
  setRepoPopoverOpen(open);
  if (!open && !hasRepoSelection) resetRepoSelection();
};
~~~

因此仅打开 popover 不进入 repo session，关闭未选择的 popover 仍是 New chat；现有 `handleRepoSelect` 继续清空旧 branch 和 Vercel 选择。
