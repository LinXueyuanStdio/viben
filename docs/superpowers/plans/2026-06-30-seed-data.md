# 种子数据 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建 TypeScript 种子数据脚本，为动态广场、通知、历史记录、排行榜等页面填充演示数据，确保开发环境中不显示空态。

**Architecture:** 单个 TS 脚本通过 drizzle 实例直接插入数据。幂等设计（按唯一字段检查后插入）。通过 `pnpm db:seed` 运行。

**Tech Stack:** TypeScript, Drizzle ORM, tsx

## Global Constraints

- 仅用于开发/测试环境，不用于生产
- 幂等：重复运行不重复插入
- 覆盖：动态广场、通知、历史记录、排行榜的数据源
- 运行方式：`cd apps/web && pnpm db:seed`

```typescript
  ]

  for (let i = 0; i < demoNotifications.length; i++) {
    const dn = demoNotifications[i]
    const [existing] = await db
      .select()
      .from(notifications)
      .where(eq(notifications.id, `seed-notif-${i}` as any))
      .limit(1)

    if (existing) {
      console.log(`  ⏭  Notification #${i} already exists`)
      continue
    }
    await db.insert(notifications).values({
      id: `seed-notif-${i}`,
      userId: dn.userId,
      type: dn.type,
      body: dn.body,
      entityType: dn.entityType ?? null,
      entityId: dn.entityId ?? null,
      isRead: i < 3, // 前 3 条已读
      createdAt: dn.createdAt,
    } as any)
    console.log(`  ✅ Created notification #${i}`)
  }

  // =========================================================
  // 5. 历史记录（Browse History）
  // =========================================================
  const historySources = ["home", "moment", "search", "leaderboard"]
  for (let i = 0; i < 15; i++) {
    const page = createdPages[i % createdPages.length]
    const user = allUsers[i % allUsers.length]
    const daysAgo = Math.floor(Math.random() * 30)
    const source = historySources[i % historySources.length]

    const [existing] = await db
      .select()
      .from(browseHistory)
      .where(eq(browseHistory.id as any, `seed-history-${i}`))
      .limit(1)

    if (existing) {
      console.log(`  ⏭  History #${i} already exists`)
      continue
    }
    await db.insert(browseHistory).values({
      id: `seed-history-${i}`,
      userId: user.id,
      pageId: page.uid,
      source,
      createdAt: new Date(Date.now() - daysAgo * 24 * 3600 * 1000),
    } as any)
    console.log(`  ✅ Created history #${i}`)
  }
```

**注意：** `notifications` 和 `browseHistory` 表的字段名需对齐实际 schema。上述代码中的类型断言 `as any` 是为了兼容 schema 字段名差异，最终实现时请使用正确的字段名。
