# 工作空间对话输入框设计规范

## 概述

工作空间对话页面的输入框设计，参考微信的输入体验，提供丰富的功能按钮和灵活的交互方式。

## 布局结构

```
┌─────────────────────────────────────────────────────────────┐
│  [表情] [文件] [截图▼]           ...           [展开]        │  ← 工具栏（上方）
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                     输入区域                                 │  ← 可拖拽调整高度
│                     (Textarea)                              │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  [智能体▼] [模型▼] [工具] [技能] [上下文明细]    [发送]      │  ← 配置栏（下方）
└─────────────────────────────────────────────────────────────┘
```

## 功能详细

### 1. 工具栏（输入框上方）

位置：输入框顶部，水平排列

#### 1.1 表情按钮
- 图标：`Smile`
- 点击：打开表情选择器面板
- 功能：插入 emoji 到输入框光标位置

#### 1.2 文件按钮
- 图标：`Paperclip` 或 `File`
- 点击：打开文件选择对话框
- 支持：
  - 图片（jpg, png, gif, webp）
  - 文档（pdf, doc, docx, txt, md）
  - 代码文件（各种编程语言）
- 显示：已选文件列表（可删除）

#### 1.3 截图按钮（带下拉菜单）
- 图标：`Camera` 或 `Scissors`
- 默认行为：直接截图（不隐藏当前窗口）
- 下拉选项：
  - `直接截图` - 保持窗口可见截图
  - `隐藏窗口截图` - 先隐藏当前窗口再截图
- 截图后：自动插入到消息附件

#### 1.4 展开按钮
- 图标：`Expand` 或 `Maximize2`
- 位置：工具栏最右侧
- 点击：进入「写作模式」
  - 输入框扩展为全屏或半屏
  - 提供更大的编辑空间
  - 可能包含 Markdown 预览

### 2. 输入区域

#### 2.1 基本功能
- 多行文本输入 (Textarea)
- 支持 Markdown 语法
- 支持代码块高亮
- 支持 @ 提及

#### 2.2 高度调整
- 用户可拖拽调整输入框高度
- 拖拽手柄：输入区域顶部边缘
- 最小高度：80px（约3行）
- 最大高度：窗口高度的 50%
- 记住用户偏好（localStorage）

#### 2.3 快捷键
- `Enter` - 发送消息
- `Shift+Enter` - 换行
- `Cmd/Ctrl+Enter` - 发送消息（可配置）
- `Escape` - 退出写作模式

### 3. 配置栏（输入框下方）

位置：输入框底部，水平排列

#### 3.1 智能体选择器
- 图标：`Bot`
- 显示：当前选中的智能体名称
- 点击：打开智能体选择下拉菜单
- 列表：来自 `/settings/agents` 的智能体列表
- 默认：使用默认智能体

#### 3.2 模型选择器
- 图标：`Cpu` 或 `Brain`
- 显示：当前选中的模型名称（如 Claude 3.5）
- 点击：打开模型选择下拉菜单
- 分组：按提供商分组显示
- 关联：模型列表可能根据选中的智能体过滤

#### 3.3 工具按钮
- 图标：`Wrench` 或 `Tool`
- 显示：已启用工具数量徽章（如 "工具 (3)"）
- 点击：打开工具配置面板/对话框
- 功能：
  - 显示可用 MCP 工具列表
  - 勾选启用/禁用工具
  - 显示工具描述

#### 3.4 技能按钮
- 图标：`Sparkles` 或 `Zap`
- 显示：已启用技能数量徽章
- 点击：打开技能配置面板/对话框
- 功能：
  - 显示已安装技能列表
  - 勾选启用/禁用技能
  - 快速安装推荐技能

#### 3.5 上下文明细按钮
- 图标：`FileText` 或 `List`
- 显示：当前上下文 token 数（如 "12.5k tokens"）
- 点击：打开上下文明细面板
- 面板内容：
  - 系统提示词 token 数
  - 历史消息 token 数
  - 附件 token 数
  - 总计 token 数
  - 模型上下文限制
  - 可选：清理/压缩上下文

#### 3.6 发送按钮
- 图标：`Send` 或 `ArrowUp`
- 位置：配置栏最右侧
- 状态：
  - 正常：可点击发送
  - 禁用：输入为空或正在发送
  - 加载：发送中显示 spinner

## 交互细节

### 拖拽调整高度
1. 鼠标悬停在输入框顶部边缘，光标变为 `ns-resize`
2. 按住鼠标拖拽调整高度
3. 释放鼠标后保存高度到 localStorage
4. 最小高度：80px，最大高度：50vh

### 截图流程
1. 用户点击截图按钮（或下拉选择模式）
2. 如选择「隐藏窗口截图」，先最小化/隐藏窗口
3. 进入截图选区模式
4. 用户框选区域后自动截图
5. 恢复窗口，截图添加到附件列表

### 发送消息流程
1. 用户输入内容
2. 可选：选择智能体、模型、启用工具/技能
3. 可选：添加附件（文件、截图）
4. 点击发送或按 Enter
5. 内容发送到选中的智能体执行
6. 清空输入框，保留配置选择

## 样式指南

- 工具栏和配置栏背景：`bg-muted/50`
- 按钮样式：`ghost` variant，hover 时 `bg-muted`
- 下拉选择器：使用 shadcn/ui 的 `Select` 或 `Popover`
- 面板：使用 `Popover` 或 `Sheet` 组件
- 徽章：使用 `Badge` 组件显示数量

## 实现优先级

1. **P0 - 核心功能**
   - 基本输入框和发送
   - 智能体选择器
   - 模型选择器

2. **P1 - 重要功能**
   - 可调整高度
   - 文件附件
   - 工具/技能面板

3. **P2 - 增强功能**
   - 表情选择器
   - 截图功能
   - 写作模式
   - 上下文明细
