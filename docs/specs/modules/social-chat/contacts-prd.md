# 联系人功能 PRD

> 产品需求文档：Desktop 联系人页面

---

## 1. 功能概述

### 1.1 目标

为用户提供联系人管理功能，包含智能体、群聊、智能体团队的统一管理界面，采用类微信的左列表右详情布局。

### 1.2 用户价值

- **统一管理**：智能体、群聊、团队集中管理
- **快速访问**：从联系人直接发起对话
- **清晰分类**：可折叠分组，快速定位

---

## 3. 联系人列表

### 3.1 分组结构

```
▼ 智能体 (5)                    ← 可折叠分组
   ├─ [🤖] Claude 助手          ← 本地创建的智能体
   ├─ [🤖] 代码审查专家
   └─ [+] 创建智能体             ← 快捷入口

▼ 群聊 (3)                      ← 可折叠分组
   ├─ [👥] 开发团队
   ├─ [👥] 产品讨论组
   └─ [+] 创建群聊               ← 快捷入口

▼ 智能体团队 (2)                 ← 可折叠分组
   ├─ [⚙️] 自动代码审查流程
   ├─ [⚙️] 文档生成工作流
   └─ [+] 创建团队               ← 快捷入口
```

### 3.2 列表项结构

```
┌─────────────────────────────────────────────────┐
│ [图标]  名称                           [状态]   │
│         描述/成员数/节点数                      │
└─────────────────────────────────────────────────┘
```

### 3.3 分组交互

| 操作 | 触发方式 | 效果 |
|------|----------|------|
| 展开/折叠 | 点击分组标题 | 显示/隐藏分组内容 |
| 查看详情 | 点击列表项 | 右侧显示详情面板 |
| 快捷创建 | 点击 [+] | 打开创建对话框 |

## 8. 用户故事

### 8.1 查看智能体

```
作为用户
我想要查看我创建的所有智能体
以便我能够管理和使用它们

验收标准:
- 智能体分组显示本地创建的智能体
- 点击智能体显示详细信息
- 可以从详情页发起对话
```

### 8.2 管理群聊

```
作为用户
我想要管理我的群聊
以便我能够邀请智能体和成员参与讨论

验收标准:
- 可以查看群聊成员列表
- 可以邀请智能体加入群聊
- 可以修改群设置
```

### 8.3 查看团队执行

```
作为用户
我想要查看智能体团队的执行历史
以便我能够了解工作流的运行情况

验收标准:
- 显示最近的执行记录
- 可以查看执行详情
- 失败的执行有明确的错误信息
```

## 9. 非功能需求

### 9.1 性能

- 列表展开/折叠动画流畅 (< 200ms)
- 详情面板切换无闪烁

### 9.2 可用性

- 支持键盘导航（Tab/Enter/Escape）
- 分组状态保持（刷新后记住展开状态）
