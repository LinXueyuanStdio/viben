# 智能体团队 PRD

> 产品需求文档：智能体团队与工作流编排

---

## 1. 功能概述

### 1.1 目标

允许用户通过可视化工作流编排，组合多个智能体形成"团队"，实现自动化的复杂任务处理。

### 1.2 用户价值

- **自动化工作流**：将重复性任务编排为自动执行的流程
- **智能体协作**：让多个专业智能体各司其职、协同工作
- **可视化编排**：拖拽式操作，无需编程即可创建复杂流程

---

## 2. 核心概念

### 2.1 术语定义

| 术语 | 定义 |
|------|------|
| **智能体团队** | 由多个智能体和节点组成的工作流配置 |
| **节点** | 工作流中的一个步骤（智能体、触发器、逻辑控制等） |
| **连接** | 节点之间的数据流向 |
| **执行** | 工作流的一次运行实例 |

### 2.2 节点类型

```
┌─────────────────────────────────────────────────────────────┐
│                        节点类型                              │
├───────────────┬─────────────────────────────────────────────┤
│ 触发器节点     │ 启动工作流的条件                             │
│               │ - 手动触发                                   │
│               │ - 定时触发 (Cron)                            │
│               │ - Webhook 触发                               │
│               │ - 事件触发 (文件变更、消息等)                  │
├───────────────┼─────────────────────────────────────────────┤
│ 智能体节点     │ 调用智能体执行任务                           │
│               │ - 选择智能体                                 │
│               │ - 配置输入模板                               │
│               │ - 定义输出格式                               │
├───────────────┼─────────────────────────────────────────────┤
│ 逻辑节点       │ 控制流程走向                                 │
│               │ - 条件分支 (If/Else)                         │
│               │ - 循环 (For Each)                            │
│               │ - 并行 (Parallel)                            │
│               │ - 合并 (Merge)                               │
├───────────────┼─────────────────────────────────────────────┤
│ 工具节点       │ 执行特定操作                                 │
│               │ - HTTP 请求                                  │
│               │ - 代码执行                                   │
│               │ - 数据转换                                   │
│               │ - 文件操作                                   │
├───────────────┼─────────────────────────────────────────────┤
│ 输出节点       │ 工作流的结果处理                             │
│               │ - 发送消息                                   │
│               │ - 保存文件                                   │
│               │ - 调用 API                                   │
└───────────────┴─────────────────────────────────────────────┘
```

### 3.2 画布交互

| 操作 | 方式 | 效果 |
|------|------|------|
| 添加节点 | 从面板拖拽到画布 | 创建新节点 |
| 连接节点 | 从输出端口拖拽到输入端口 | 创建连接线 |
| 选中节点 | 点击节点 | 右侧显示属性面板 |
| 移动节点 | 拖拽节点 | 调整位置 |
| 删除节点 | Delete 键 / 右键菜单 | 移除节点及其连接 |
| 缩放画布 | 滚轮 / 工具栏按钮 | 放大/缩小视图 |
| 平移画布 | 空格 + 拖拽 | 移动视图区域 |

### 3.3 节点设计

```
智能体节点:
┌─────────────────────────┐
│ ●─                 ─○   │ ← 输入/输出端口
│   🤖 代码分析            │
│   GPT-4                 │
│   ─────────────────     │
│   输入: {{diff}}        │
│   输出: JSON            │
└─────────────────────────┘

条件节点:
┌─────────────────────────┐
│ ●─                      │
│   🔀 条件分支            │
│   if score > 80         │
│              ─○ true    │

└─────────────────────────┘
```

### 4.2 变量系统

变量可在输入模板中使用，支持的来源：

| 变量类型 | 语法 | 说明 |
|----------|------|------|
| 触发器数据 | `{{trigger.xxx}}` | 触发工作流时的输入 |
| 上游节点 | `{{节点名称.output}}` | 前置节点的输出 |
| 环境变量 | `{{env.xxx}}` | 预定义的环境变量 |
| 系统变量 | `{{system.xxx}}` | 时间戳、执行ID等 |

## 5. 执行与监控

### 5.1 执行状态

```
执行状态示意:

  ✓ 完成     → 节点成功执行
  ● 运行中   → 节点正在执行
  ○ 等待     → 节点等待上游
  ✗ 失败     → 节点执行出错
  ⊘ 跳过     → 条件不满足，跳过执行
```

### 5.2 执行视图

### 5.3 错误处理

| 错误类型 | 默认行为 | 可配置选项 |
|----------|----------|------------|
| 智能体超时 | 失败，停止流程 | 重试、使用默认值、跳过 |
| 格式错误 | 失败，停止流程 | 重试、人工干预 |
| 条件异常 | 失败，停止流程 | 走 false 分支 |

## 6. 用户故事

### 6.1 创建团队

```
作为用户
我想要创建一个自动代码审查的智能体团队
以便每次代码提交都能自动获得审查意见

验收标准:
- 可以通过可视化编辑器创建工作流
- 可以配置 Webhook 触发器接收 Git 事件
- 可以串联多个智能体进行分析和审查
```

### 6.2 编辑工作流

```
作为用户
我想要修改已有的工作流
以便优化团队的执行效果

验收标准:
- 可以打开已保存的工作流进行编辑
- 可以添加、删除、重新连接节点
- 保存后立即生效
```

### 6.3 监控执行

```
作为用户
我想要查看工作流的执行状态
以便了解团队的运行情况并排查问题

验收标准:
- 可以看到每个节点的执行状态
- 可以查看节点的输入输出日志
- 失败时有明确的错误信息
```

## 8. 非功能需求

### 8.1 性能

- 编辑器画布支持 50+ 节点流畅操作
- 工作流执行支持 10 分钟超时
- 并行节点支持最多 5 路并发

### 8.2 可靠性

- 执行状态持久化，支持断点续跑
- 单节点失败不影响其他并行分支

### 8.3 可用性

- 拖拽操作有明确的视觉反馈
- 连接线自动避障，减少交叉
