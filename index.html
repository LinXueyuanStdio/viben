Quick Install

curl -fsSL https://github.com/LinXueyuanStdio/viben/releases/latest/download/install.sh | bash

# Or with npx (Node.js)
npx viben

# Or with pip
pip install browse-mcp

Quick Start

Get up and running in minutes

1

Install

curl -fsSL https://github.com/LinXueyuanStdio/viben/releases/latest/download/install.sh | bash

Or: npx viben | pip install browse-mcp

2

Configure Claude Desktop

Add to claude_desktop_config.json 
{
  "mcpServers": {
    "browse-mcp": {
      "command": "browse-mcp"
    }
  }
}
3

Manage Agents

Use the desktop app to configure workspaces, manage AI agents, and orchestrate automation workflows.
