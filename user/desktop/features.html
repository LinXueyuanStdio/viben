Features

Viben Desktop provides a comprehensive set of features for content search and management.

Paper Search​

Multi-Source Search​

Search across multiple academic databases simultaneously:

  • arXiv - Preprints in physics, mathematics, computer science, and more
  • PubMed - Biomedical and life sciences literature
  • Semantic Scholar - AI-powered academic search
  • CrossRef - Scholarly metadata
  • DBLP - Computer science bibliography
  • OpenAlex - Open catalog of scholarly works

Advanced Filtering​

Refine your search results with:

  • Date range filters
  • Author filters
  • Publication type
  • Subject areas
  • Open access only

Search History​

  • View recent searches
  • Re-run previous queries
  • Export search history

Paper Management​

Download Papers​

  • Download PDFs directly from the app
  • Automatic file naming and organization
  • Configurable download location

Read Papers​

  • Extract and view paper content
  • Full-text search within papers
  • Copy text and citations

Collections​

  • Organize papers into collections
  • Tag and categorize
  • Export collections

MCP Integration​

Built-in MCP Server​

Viben Desktop includes the MCP server, allowing AI assistants to:

  • Search for papers on your behalf
  • Download and read paper content
  • Help with literature reviews

Configuration​

The Desktop App manages the MCP server automatically. Configure it for use with:

  • Claude Desktop
  • Continue.dev
  • Other MCP-compatible clients

See Client Configuration for setup instructions.

User Interface​

Dark Mode​

Full support for light and dark themes:

  • Automatic system theme detection
  • Manual theme toggle
  • Consistent styling across all components

Keyboard Shortcuts​

ActionmacOSWindows/Linux
New SearchCmd + KCtrl + K
SettingsCmd + ,Ctrl + ,
QuitCmd + QAlt + F4

Accessibility​

  • Screen reader support
  • Keyboard navigation
  • High contrast mode

Privacy & Security​

Local First​

  • All data stored locally on your machine
  • No account required
  • No telemetry or tracking

Secure Communication​

  • HTTPS for all API requests
  • No credentials stored in plain text

Data Location​

Your data is stored in platform-specific locations:

PlatformLocation
macOS~/Library/Application Support/com.viben.app
Windows%APPDATA%\com.viben.app
Linux~/.config/viben

Coming Soon​

Features planned for future releases:

  • Auto-update - Automatic app updates
  • Plugin System - Extend functionality with plugins
  • Citation Export - Export citations in various formats (BibTeX, RIS, etc.)
  • Paper Annotations - Highlight and annotate PDFs
  • Sync - Optional cloud sync for settings and collections

Feature Requests​

Have a feature suggestion? Open an issue on GitHub.
