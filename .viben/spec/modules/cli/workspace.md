# viben workspace

> 工作区操作。

## 命令

```bash
# 列出工作区
viben workspace list              # 列出所有已知工作区

# 当前工作区
viben workspace current           # 显示当前工作区信息
```

---

## 输出示例

**`viben workspace current` (Human)**:
```
Current Workspace:
  Path: /Users/xxx/projects/viben
  MCP:  filesystem, git (2 enabled)
  Skills: code-review, commit (2 enabled)
```
