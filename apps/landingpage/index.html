Browse MCP

Search, Download, and Read Academic Papers with AI

A powerful Model Context Protocol server that enables AI assistants to search across arXiv, PubMed, Semantic Scholar, and more. Unlock research for your AI workflows.

Get Started View on GitHub
Quick Install 
# Install via pip
pip install browse-mcp

# Or with uv (recommended)
uv pip install browse-mcp

# Run the MCP server
browse-mcp

Powerful Features

Everything you need for academic research with AI

Multi-Source Search

Search across arXiv, PubMed, Semantic Scholar, CrossRef, and OpenAlex in one unified interface.

Download PDFs

Automatically download papers from open access sources and manage your research library.

Read & Extract

Extract text, metadata, and references from papers. Let AI analyze and summarize research.

MCP Integration

Built on Model Context Protocol. Works with Claude, ChatGPT, and any MCP-compatible AI assistant.

Desktop App

Beautiful native desktop application with paper management, search history, and visual analytics.

Open Source

Fully open source under MIT license. Contribute, customize, and extend to your needs.

Quick Start

Get up and running in minutes

1

Install

pip install browse-mcp
2

Configure Claude Desktop

Add to claude_desktop_config.json 
{
  "mcpServers": {
    "browse-mcp": {
      "command": "browse-mcp"
    }
  }
}
3

Search Papers

Ask Claude to search for papers, download PDFs, or analyze research. The MCP server handles the rest.
