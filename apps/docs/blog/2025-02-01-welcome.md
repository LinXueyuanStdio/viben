欢迎来到 **Viben** —— 下一代 Agent Swarm 与代码进化平台！

Viben 通过多智能体协作和强化学习驱动的代码迭代，重新定义软件开发体验。

<!-- truncate -->

## 什么是 Viben？

Viben 是一个融合 **Agent Swarm（智能体集群）** 与 **Code Evolution（代码进化）** 理念的开发平台。它不仅仅是工具，而是一套完整的智能开发生态系统。

### 核心特性

#### 🧬 FileRL - 代码迭代优化

基于强化学习的代码进化引擎，通过持续迭代让代码自我优化：

- 自动化代码质量评估
- 智能重构建议
- 渐进式性能优化

#### 🤖 Multi-Agent - 智能体集群编排

多个专业智能体协同工作，各司其职：

- 代码生成智能体
- 代码审查智能体
- 测试生成智能体
- 文档生成智能体

#### 📋 Task System - XState 状态机驱动

基于 XState 的任务管理系统，让开发流程可视化、可追踪：

- 任务状态流转：`backlog → queue → in_progress → review → completed`
- 并发控制与后台执行
- Gateway 重启自动恢复

#### 💡 Idea Generation - 创意孵化

从灵感到实现的完整链路：

- 需求分析与拆解
- 技术方案生成
- 原型快速验证

#### 🔌 MCP Protocol - 生态集成

兼容 MCP (Model Context Protocol) 标准，无缝对接现有 AI 生态：

- 与 Claude 等 MCP 客户端深度集成
- 可扩展的工具集
- 开放的协议标准

## 开始使用

```bash
# 安装 Viben CLI
pnpm install -g viben

# 初始化项目
viben init

# 启动 Gateway
viben gateway start
```
