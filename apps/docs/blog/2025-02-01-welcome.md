Welcome to the **Viben** documentation site!

Viben is a Python-based MCP server that makes content search easy and accessible through Claude and other MCP-compatible clients.

<!-- truncate -->

## What is Viben?

Viben provides three main tools:

1. **browse_search** - Search papers across 19+ academic databases
2. **browse_download** - Download paper PDFs
3. **browse_read** - Extract and read text content from papers

## Getting Started

Install Viben with pip:

```bash
pip install browse-mcp
```

Then start the MCP server:

```bash
browse-mcp
```

Check out our [documentation](/docs/intro) to learn more!
