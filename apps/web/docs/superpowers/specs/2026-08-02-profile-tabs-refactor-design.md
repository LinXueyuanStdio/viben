# 用户资料页面 Tab 重构设计

## 概述

重构 `/{user_slug}` 用户资料页面的 tab 结构，新增 MCP 和技能 tab，深度重构 pages tab，合并 favorites 到 likes tab。

## 一、Tab 结构调整

| 当前 tab | 变更 | 说明 |
|----------|------|------|
| 概览 | 保留 | 不变 |
| 页面 | 重构 | 搜索+排序+创建按钮，leaderboard 列表样式 |
| 喜欢 | 重构 | 合并收藏内容，分为"收藏"区和"喜欢"区 |
| 收藏 | 移除 | 内容合并到"喜欢"tab |
| 动态 | 保留 | 不变 |
| 合集 | 移除 | 合集作为收藏夹复用到"喜欢"tab 的收藏区 |
| — | 新增 MCP | 用户发布的 MCP 包列表 |
| — | 新增 技能 | 用户发布的技能包列表 |

### Tab 标签常量映射

```
概览 → tab 参数无或 ?tab=
页面 → ?tab=pages
喜欢 → ?tab=likes
动态 → ?tab=moments
MCP  → ?tab=mcp
技能 → ?tab=skills
```

## 二、Pages tab 重构

### 布局

```
┌──────────────────────────────────────────────────────────┐
│  [🔍 搜索页面...]    [排序: 最新发布 ▼]    [+ 创建页面]  │
├──────────────────────────────────────────────────────────┤
│  列表项（RankItem 风格，去排名和评分列）                  │
│  ┌─────────────────────────────────────────────────────┐ │
│  │ [封面]  标题              描述     👁 views  👍 likes│ │
│  │  150px  作者 · 时间                 💬 comments     │ │
│  └─────────────────────────────────────────────────────┘ │
│  ...更多...                                              │
├──────────────────────────────────────────────────────────┤
│               < 1  2  3 ... N >                          │
└──────────────────────────────────────────────────────────┘
```

### 功能规格

- **搜索框**：本地过滤，按标题和描述搜索用户自己的页面
- **排序下拉框**：最新发布、最多浏览、最多喜欢
- **+ 创建页面**：链接到 `/pages/new`
- **列表样式**：采用 `/leaderboard` 的 `RankItem` 组件风格，水平卡片布局
  - 移除排名数字列
  - 移除评分列
  - 保留：封面图 | 标题+描述+作者+时间 | 浏览/喜欢/评论统计
- **分页**：底部分页导航
- **数据源**：`publishedPages` 表，按 `userId` 过滤，仅公开且审核通过的页面

## 三、MCP tab（新增）

### 布局

```
┌──────────────────────────────────────────────────────────┐
│  [🔍 搜索 MCP...]    [排序: 最新发布 ▼]    [+ 发布 MCP]  │
├──────────────────────────────────────────────────────────┤

│               < 1  2  3 ... >                            │
└──────────────────────────────────────────────────────────┘
```

### 功能规格

- **搜索框**：按名称/描述搜索

- **分页**：底部分页导航
- **数据源**：`mcpPackages` 表，按 `authorId` 过滤，仅已发布的包

## 五、Likes tab 重构（合并收藏）

### 布局

```
┌──────────────────────────────────────────────────────────┐
│  收藏                                                    │
│  ┌──────────────────────────────────────────────────────┐│
│  │  [页面]  [MCP]  [技能]          ← 内容类别 tab       ││
│  │──────────────────────────────────────────────────────││
│  │  全部收藏  │  ┌────────────────────────────────┐     ││
│  │  我的精选  │  │ [封面] 标题    描述   ⋯ 菜单  │     ││
│  │  技术文章  │  │  80px   作者·时间       [删除] │     ││
│  │  (合集列表)│  └────────────────────────────────┘     ││
│  │            │  ...leaderboard 样式 ...                ││
│  └──────────────────────────────────────────────────────┘│
│                                                          │
│  喜欢                                                    │
│  ┌──────────────────────────────────────────────────────┐│
│  │ [封面] 标题  描述    👁 views  👍 likes  💬 comments ││
│  │        作者 · 时间                                   ││
│  └──────────────────────────────────────────────────────┘│
│  ...leaderboard 样式 ...                                 │
└──────────────────────────────────────────────────────────┘
```

### 收藏区功能规格

- **类别 tab（第一行）**：页面、MCP、技能 — 切换不同类型收藏内容
  - 页面：来自 `communityBookmarks` 表中 `entityType = 'published_page'` 的记录
  - MCP：来自 `bookmarks` 表中 `entityType = 'mcp'` 的记录
  - 技能：来自 `bookmarks` 表中 `entityType = 'skill'` 的记录
- **左侧收藏夹列表**：
  - "全部收藏"（默认选中，显示该类别所有收藏）
  - 用户创建的合集名称列表，点击筛选该合集中的内容
  - 复用 `collections` 表数据
- **右侧内容列表**：
  - leaderboard 列表样式：封面图 | 标题+描述+作者+时间
  - 更多菜单（⋯）含**取消收藏/删除**按钮
- **数据源**：`communityBookmarks`（页面收藏）、`bookmarks`（MCP/技能收藏）、`collections`（合集）

### 喜欢区功能规格

- **内容**：用户点过赞的页面
- **列表样式**：leaderboard 样式
- **数据源**：`communityReactions` 表，`reactionType = 'like'`，`entityType = 'published_page'`

## 六、组件结构

### 涉及修改的文件

```
apps/web/app/(dashboard)/[user_slug]/page.tsx     — 主要数据获取 + tab 内容组装
apps/web/components/profile/profile-tabs.tsx       — Tab 定义和路由逻辑
apps/web/components/profile/profile-favorites.tsx  — 可能需要重写或大幅重构
```

### 可能新增的组件

```
apps/web/components/profile/profile-pages-list.tsx    — Pages 列表（搜索+排序+分页）
apps/web/components/profile/profile-mcp-list.tsx      — MCP 列表
apps/web/components/profile/profile-skills-list.tsx   — 技能列表
apps/web/components/profile/profile-likes-merged.tsx  — 合并后的喜欢+收藏区
```

### 复用组件

- `RankItem` / 类似 leaderboard 列表项样式 — 用于所有列表展示
- `VibenTabs` — 用于 tab 切换
- `SectionHead` — 用于区域标题
- `PageCard`（当前页面的卡片组件，可替换为 RankItem 风格）

## 七、API 影响

- 需要在 page.tsx 的 `Promise.all` 中新增 MCP packages 和 skill packages 的查询
- likes tab 的收藏区需要查询 `communityBookmarks` + `bookmarks` + `collections`
- 列表需要支持分页，可能需要改为客户端数据获取或调整服务端数据获取策略
