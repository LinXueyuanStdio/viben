通道 API

/api/channels - 消息通道管理端点

概述​

通道 API 提供消息通道的配置和管理功能，支持多种消息平台集成。

端点列表​

通道实例 CRUD​

方法路径说明
GET/api/channels列出所有通道
POST/api/channels创建通道
GET/api/channels/:id获取通道详情
PATCH/api/channels/:id更新通道
DELETE/api/channels/:id删除通道
POST/api/channels/:id/default设为默认通道

消息操作​

方法路径说明
POST/api/channels/send发送消息
POST/api/channels/test测试通道配置
POST/api/channels/send-test发送测试消息

详细说明​

GET /api/channels​

列出所有配置的通道实例。

响应:

{
  "channels": [
    {
      "id": "ch-telegram-1",
      "name": "My Telegram Bot",
      "type": "Telegram",
      "enabled": true,
      "is_default": true,
      "created_at": "2024-01-01T10:00:00Z"
    },
    {
      "id": "ch-discord-1",
      "name": "Discord Server",
      "type": "Discord",
      "enabled": true,
      "is_default": false
    }
  ]
}

POST /api/channels​

创建通道实例。

请求体:

{
  "name": "My Telegram Bot",
  "type": "Telegram",
  "config": {
    "bot_token": "123456:ABC-DEF..."
  }
}

通道类型配置:

Telegram​

{
  "type": "Telegram",
  "config": {
    "bot_token": "123456:ABC-DEF..."
  }
}

Discord​

{
  "type": "Discord",
  "config": {
    "bot_token": "MTIz...",
    "guild_id": "123456789"
  }
}

Feishu (飞书)​

{
  "type": "Feishu",
  "config": {
    "app_id": "cli_xxx",
    "app_secret": "xxx"
  }
}

WhatsApp​

{
  "type": "WhatsApp",
  "config": {
    "phone_number_id": "123456",
    "access_token": "xxx"
  }
}

Slack​

{
  "type": "Slack",
  "config": {
    "bot_token": "xoxb-xxx"
  }
}

Webhook​

{
  "type": "Webhook",
  "config": {
    "url": "https://example.com/webhook",
    "secret": "optional-secret"
  }
}

POST /api/channels/send​

发送消息到指定通道。

请求体:

{
  "channel_type": "Telegram",
  "config": {
    "bot_token": "123456:ABC-DEF..."
  },
  "chat_id": "123456789",
  "message": "Hello from Viben!",
  "parse_mode": "Markdown"
}
字段类型必需说明
channel_typestring✓通道类型
configobject✓通道配置
chat_idstring✓聊天/频道 ID
messagestring✓消息内容
parse_modestring否解析模式 (Markdown/HTML)

响应:

{
  "success": true,
  "message_id": "12345"
}

POST /api/channels/test​

测试通道配置是否有效。

请求体:

{
  "type": "Telegram",
  "config": {
    "bot_token": "123456:ABC-DEF..."
  }
}

响应:

{
  "valid": true,
  "bot_info": {
    "username": "my_bot",
    "name": "My Bot"
  }
}

错误响应:

{
  "valid": false,
  "error": "Invalid bot token"
}

POST /api/channels/send-test​

发送测试消息验证配置。

请求体:

{
  "channel_id": "ch-telegram-1",
  "chat_id": "123456789"
}

响应:

{
  "success": true,
  "message": "Test message sent successfully"
}

通道类型​

类型说明必需配置
TelegramTelegram Botbot_token
DiscordDiscord Botbot_token, guild_id
Feishu飞书机器人app_id, app_secret
WhatsAppWhatsApp Businessphone_number_id, access_token
SlackSlack Botbot_token
Webhook自定义 Webhookurl

通道配置存储​

通道配置存储在 ~/.viben/channels.yaml:

default: ch-telegram-1

channels:
  - id: ch-telegram-1
    name: My Telegram Bot
    type: Telegram
    enabled: true
    config:
      bot_token: "123456:ABC-DEF..."

  - id: ch-discord-1
    name: Discord Server
    type: Discord
    enabled: true
    config:
      bot_token: "MTIz..."
      guild_id: "123456789"
